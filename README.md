# AsterPhone ✦

SillyTavern 小手机插件（v0.2 预览版）。

## 安装到酒馆
酒馆 → 扩展 → 安装扩展 → 粘贴 `https://github.com/xxuxin0705/AsterPhone` → 安装。

打开手机的三个入口：
- **悬浮按钮**：默认是 iPhone 样式，按住可以拖动。12 种图标和大小在手机里的「设置 → 手机本体」换。
- **魔法棒菜单**：输入框左边的魔法棒 → AsterPhone 小手机。
- **连点三下**（默认关）：在「设置 → 手机本体」打开。

不想要悬浮按钮：酒馆「扩展」面板 → AsterPhone 小手机 → 取消「显示悬浮按钮」。
忘记锁屏密码：同一个面板里点「重置锁屏」，或在解锁界面用备用密码（4 位 0000 / 6 位 000000）。

## 现在能用的
- 锁屏（会动的壁纸、假指纹、数字密码）→ 桌面 → App，左右边缘滑动返回。
- **设置**：连接（酒馆当前连接 / OpenAI 兼容 / Claude / Gemini）、应用管理、通用提示词、外观、锁屏与密码、通知、手机本体、数据、关于。
- **聊天**：消息 / 联系人 / 动态 / 我；私聊「让 TA 回复」、长按菜单、多选、拍一拍、聊天设置、注入正文和注入记录。
- **日志**：报错标红，可一键复制。
- 和正文联动：读 `<astertime>` 剧情时间、读 `<asterphone from="名字">` 正文里发来的手机消息，并把标签从正文显示里藏起来。

下一轮：群聊、红包转账语音等特殊消息、翻译、主动消息、AI 智能加载联系人、资源库。

## 代码结构
- `index.js` / `style.css` —— 酒馆页面上的入口（悬浮按钮、魔法棒、扩展面板），手机装在一个 iframe 里。
- `phone/` —— 手机本体。`js/core/` 是公共零件（存储、导航、界面积木、壁纸、和酒馆通信），`js/apps/` 是各个 App。
- 数据存在浏览器的 IndexedDB（库名 `asterphone`）。API 密钥只存本机，导出时默认不带。

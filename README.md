# AsterPhone ✦

SillyTavern 小手机插件（v0.8.63 预览版）。

## 安装到酒馆
酒馆 → 扩展 → 安装扩展 → 粘贴 `https://github.com/xxuxin0705/AsterPhone` → 安装。

打开手机的三个入口：
- **悬浮按钮**：默认是 iPhone 样式，按住可以拖动。12 种图标和大小在手机里的「设置 → 手机本体」换。
- **魔法棒菜单**：输入框左边的魔法棒 → AsterPhone 小手机。
- **连点三下**（默认关）：在「设置 → 手机本体」打开。

不想要悬浮按钮：酒馆「扩展」面板 → AsterPhone 小手机 → 取消「显示悬浮按钮」。
忘记锁屏密码：同一个面板里点「重置锁屏」，或在解锁界面用备用密码（4 位 0000 / 6 位 000000）。

## 现在能用的
- 锁屏（会动的壁纸：拖动有水波纹；城堡里的花头单独抠出来随风摆，周围不动；不锁 / 上滑 / 指纹 / 数字密码 / 手势密码）→ 桌面 → App，左右滑动返回。
- **壁纸**：锁屏和桌面分开选；自带「月夜城堡」「水中月」两套，也能加自己的图片和 Live 图（视频，按住播放或一直循环）；可以随机锁屏、随机桌面。
- **时间**：锁屏默认内置苹果粗体 SF Pro Display Bold（也可以在「外观 → 时间 → 字体文件」导入别的字体，只存本机），日期永远显示年月日；可切中文 / English、24 / 12 小时制。
- **设置**：连接、应用管理、通用提示词、外观、锁屏与密码、通知、手机本体、数据、关于。
- **连接 · 插线板**：每个接口是一个带字符小脸的格子，每个格子的表情都不太一样：平时发呆（`·_·` `·ω·`…）；插上就是绿色笑脸（`^‿^` `◕‿◕`…）；插上了但还没填密钥是黄色问号脸（`?_?` `·_·?`…）；点了测试连不上是红色哭脸（`T_T` `ಥ_ಥ`…）。小脸的眼睛会一直看着插头（插头在右边就往右看，小问号冒在另一边）；插到没配置的接口不会先开心，直接歪头冒问号。线自然垂着、带一点弯；经过面板里的格子时会淡下去，像藏在格子底下，插头那一截保持清楚。底部切换「聊天 / 生图 / 语音 / 其他」，板子上只留那一类接口，下面换成那一根 ASCII 字符拼成的线，拎起来插进哪个格子就用哪个。插上就算接好（变笑脸），不会自动发请求；想确认能不能用，点格子进详情按「测试」——没保存也能测。
  - 长按格子 0.3 秒可以拖动排序，格子会浮起来跟着手指走。
  - 聊天类型：GPT / OpenAI 兼容、Claude、Gemini，还有酒馆里存的所有连接配置。
  - 其他 = 向量记忆用的接口：先配好了硅基流动（bge-m3）和智谱（embedding-3）。
  - 生图渠道先配好了：NovelAI、GPT / OpenAI 兼容、本地 SD、ComfyUI、硅基流动。
  - 语音渠道先配好了：MiniMax 国内 / 国际、OpenAI、Fish Audio、ElevenLabs、IndexTTS 本地、小米 MiMo、豆包 / 火山引擎；还可以加「第三方（OpenAI 格式）」。
  - 地址、默认模型、音色、官网都填好，填上密钥就能用，全部都能改。
  - 点格子打开接口详情：地址、多把密钥轮换、模型拉取；温度、推理深度、提示词缓存（Claude）；生图的尺寸和画师串；语音的音色和语速。
  - 右上角：接线方案（整套接法存起来一键换）、断线了怎么办（自动重试、聊天线断了改用酒馆当前连接）、列表模式。
  - 酒馆「连接配置」里存的每个配置（九十、好梦……）都会变成一个格子，可以直接插线用，不会切换酒馆自己正在用的连接；「酒馆当前连接」上写着现在是哪个配置。
  - 长按格子可以拖动排序；详情里可以置顶。
  - 背景是字符拼成的海，鱼和主页「水中月」的鱼同一个样子；白天米白、夜晚深海蓝。
- **聊天**：
  - 消息 / 联系人 / 动态 / 我；私聊和群聊，「让 TA 回复 / 让大家回复」
  - 特殊消息：语音、图片（可生图）、表情包、转账、红包、位置、名片、语音 / 视频通话
  - 长按菜单、引用、撤回、翻译（免费）、多选、拍一拍
  - 主动消息、离开期间补发、正文触发
  - AI 智能加载联系人、从世界书添加、新的朋友
  - 动态：发动态（可见范围）、生成角色动态、评论
  - 注入正文和注入记录
- **资源库**：5 套主题、自己写 / 导入 / 分享 CSS 皮肤、皮肤说明书。
- **日志**：报错标红，可一键复制。
- 和正文联动：读 `<astertime>` 剧情时间、读 `<asterphone from="名字">` 正文里发来的手机消息，并把标签从正文显示里藏起来。

## 代码结构
- `index.js` / `style.css` —— 酒馆页面上的入口（悬浮按钮、魔法棒、扩展面板），手机装在一个 iframe 里。
- `phone/index.html` —— 手机的外壳。
- `phone/core/` —— 所有 App 共用的零件：启动（main.js）、存储、页面导航、界面积木、壁纸、时间、AI 调用、和酒馆通信，以及公共样式 base.css。
- `phone/apps/<App名>/` —— 每个 App 一个文件夹，里面放它自己的代码和样式：
  - `lock/` 锁屏 · `home/` 桌面 · `settings/` 设置 · `log/` 日志 · `chat/` 聊天 · `library/` 资源库
  - 以后新 App（资源库、音乐……）也照这个样子加一个文件夹。
- `phone/assets/` —— 图片：壁纸、悬浮按钮图标。
- 数据存在浏览器的 IndexedDB（库名 `asterphone`）。API 密钥只存本机，导出时默认不带。自己加的壁纸也只存本机（键 `wall:<id>`），不进备份。

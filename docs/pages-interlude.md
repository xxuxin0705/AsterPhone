# 幕间（跑团 App）方案（2026-11-08 和作者定的）

代码、图都自己做。素材在 `phone/assets/interlude/`（出图交接单 `gpt-image-brief-interlude.md`，画风 A「雨夜伦敦」：雾蓝桌布、奶白纸、黄铜、深藏蓝绒，只有火漆和小骰子是红的）。

## 一、是什么
- 正文暂停，和联系人里的角色开一局《克苏鲁的呼唤》跑团。**整局不进正文、不进记忆**（念念铃、日记都看不到它）。
- 名字「幕间」：戏演到一半的休息时间，正文是戏，这里是幕间加演的一场。
- 以后：剧本杀（桌上的火漆信）、DND（旧地图）先摆着，点了提示「还没开放」。

## 二、开屏
- 打开 App：黑蓝底上一张牛皮纸，打字机打「案件编号 / 正文暂停。/ 以下发生的一切，不计入记忆。」，火漆印章「啪」盖下来（印上「幕间」），淡出到桌子。6 秒，右上角「跳过」；设置 → 应用管理 → 幕间里能关。
- 每局开局前：演员表（主演：你 / 特别出演：上桌的角色 / 友情出演：KP / 片名），点一下跳过。

## 三、桌子（入口页，不弹窗）
俯视的书桌，每样东西是一个选项：骰子盘（点一下抛着玩）、火漆信（剧本杀）、旧地图（DND）、档案袋（选本：三个内置本 / 随机生成 + 一句要求；气氛：正经 / 轻松 / 整活）、左边四把椅子（点空椅子请联系人坐下，头像出现在椅子上；再点让他起身）、丝绒托盘里八件意象小物件（拿起哪件就按它车卡：钥匙 / 怀表 / 乌鸦羽毛 / 药瓶 / 火柴盒 / 子弹壳 / 眼镜 / 口红）、火漆印章「开局」（有没打完的局就是「继续」）。
白天 / 夜里跟手机的深色模式（夜里台灯亮）。

## 四、车卡
一张牛皮纸档案表：名字、职业（可以自己填，不填由 KP 起）、意象、九项属性（「掷骰子」= 3D6×5 / (2D6+6)×5，抛骰子动画；「自己填」= 手动改）、血 / 理智 / 魔法 / 闪避；开局后 KP 填职业、背景、技能（职业技能最多 8 项、最高 75）。上桌的角色也各自掷属性、由 KP 定职业技能。

## 五、玩
- 竖屏：老照片场景铺满（18 张，AI 只能从这些地点里挑；换场景淡入）、人物牌（KP 剪影 / 角色头像）+ 名牌 + 对话框（点一下念下一段）。顶上：第几幕 / 第几回合、血、理智、疯狂症状、「推进」。
- **你动一下，大家动一轮**：发一句话（或选项、或掷了骰子）→ 一次 API → KP 叙述 + 每个角色这回合说的做的 + 「接下来要你做什么」（自由 / 检定 技能·难度 / 对抗 / 理智检定 / 选择）。普通 / 困难 / 极难 / 对抗由 KP 判断（有后果才检定）。
- 骰子永远手机掷（rules.js），AI 只收结果；大成功 / 大失败三档在设置里选（规则书 01/100、1～3/98～100、1～5/96～100）。也能主动掷（🎲 选技能），结果随下一句一起发给 KP。
- 开局一次 API 生成骨架：标题、3～5 幕（目标 / 地点 / 出口）、真相、好坏结局、人物卡、开场白（先接正文一两句）。每幕最多 8 回合，到了 KP 必须推到出口；最后一幕用完必须给结局。
- 理智：掉 5 点以上临时发疯（1D10 症状，持续几回合，写进 KP 的提示词里）；血 / 理智归零由 KP 处理。不能重掷（作者定的）。
- 要等的都能取消；退出再进来还在等同一次。失败只提示结果，原因进日志。

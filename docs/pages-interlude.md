# 幕间（跑团 App）方案（2026-11-08 和作者定的）

代码、图都自己做。素材在 `phone/assets/interlude/`（出图交接单 `gpt-image-brief-interlude.md`，画风 A「雨夜伦敦」：雾蓝桌布、奶白纸、黄铜、深藏蓝绒，只有火漆和小骰子是红的）。

## 一、是什么
- 正文暂停，和联系人里的角色开一局《克苏鲁的呼唤》跑团。**整局不进正文、不进记忆**（念念铃、日记都看不到它）。
- 名字「幕间」：戏演到一半的休息时间，正文是戏，这里是幕间加演的一场。
- 以后：剧本杀（桌上的火漆信）、DND（旧地图）先摆着，点了提示「还没开放」。

## 二、开屏（2026-11-08 作者定的）
- 打开 App：作者给的「通天塔」背景上，一张羊皮卷从上往下展开 → 羽毛笔一行行写下一句开屏语（楷书，深蓝的字、鎏金的边，标点不开头）→ 落款「——致调查员」→ 火漆「啪」盖在左下（印上「幕间」）→ 整张纸从左下角烧起来，灰往右上飘散 → 露出书桌。约 10 秒，右上角能跳过。
- 开屏语七句轮着用（作者挑的；不要「解释这个 App 是干嘛的」那种，要留白、对着「你」说、把大的东西说得轻）；字体玄冬楷书 / 千图笔锋手写体随机。设置 → 应用管理 → 幕间：开屏开关、开屏字体（两款或随机）、开屏语（每句能关掉）。
- 每局开局前：演员表（主演：你 / 特别出演：上桌的角色 / 友情出演：KP / 片名），点一下跳过。

## 三、书桌（2026-11-08 作者改的：照 Toska「窗台」的玩法）
- 一张斜着往下看的 2.5D 侦探事务所书桌（GPT 画的），一屏铺满、不拖（2026-11-08 作者改的；两边裁掉一点，靠边两把椅子上的头像往里挪）；夜里台灯亮（跟手机深色模式，点台灯能自己开关）。
- 桌上的东西钉着小玻璃标注；点一下镜头推过去，下面浮出玻璃标签：椅子（选谁上桌：多选，最多 5 个，头像坐到椅子上）、档案袋（选本 + 气氛）、调查员卡（看卡 / 车卡）、骰子盘（掷着玩）、台灯（开关灯）、旧地图（DND，还没开放）、火漆信（剧本杀，还没开放）。点空处或「退回」镜头拉回来。
- 底下一条：上桌的人 +「开局」（有没打完的局就是「继续《…》」）。
- 原来那些意象小物件（钥匙、怀表…）作者说没用，删了。

## 四、车卡（2026-11-08 作者改的：先选人，AI 一次批量车，再微调；卡跟着人存）
- 点「开局」进调查员页（作者给的钉着图钉的档案纸：拍立得里是头像，名字职业写在右上，其余在纸上滚）：上面一排头像（你 + 上桌的人），没卡的人亮个小红点；进来就把没卡的人一起让 AI 车（一次 API），也能点「AI 车卡」。
- AI 照正文最近的剧情、各自的人设来写：名字、年龄、性别、住地、职业（从常见职业里挑最贴的）、背景四项（身份 / 关键经历 / 目标 / 秘密）、技能。属性由手机掷（3D6×5，体型 / 智力 / 教育 (2D6+6)×5），AI 不改。
- 每一格都能改：职业点一下从常见职业里换（问要不要按职业重新分技能）或自己写；属性点数字改，「重掷」「天命五选一」；每项旁边写着半值 / 五分之一值；血、理智、魔法、移动力自动算；技能 −/+ 每次 5 点，最高 80，上面显示「技能点 已用 / 教育×4+智力×2」，超了标红；没加点的技能收在「其余技能」里。
- 卡和人是一对多：一个人可以有好几张卡（换卡 → 选一张 / 新车一张 / 删除），下次上桌默认用上次那张。
- 卡都齐了才出现「开局」：一次 API 写这一局的骨架（不再写卡）。

## 骰子（2026-11-08 作者改的：不要代码画的，用 GPT 的图）
- 两颗十面骰：冰蓝水晶的十位、深蓝星空的个位（作者给的翻滚图）。抛：从右下角划弧飞进来，空中轮着换翻滚图、一边转，落地弹两下，三声「嗒」，下面用深蓝鎏金的大字亮出点数。
- 每一面朝上的静止图 20 张也是作者给的，停下来那一面就是掷出的点数。

## 五、玩
- 竖屏：老照片场景铺满（18 张，AI 只能从这些地点里挑；换场景淡入）、人物牌（KP 剪影 / 角色头像）+ 名牌 + 对话框（点一下念下一段）。顶上：第几幕 / 第几回合、血、理智、疯狂症状、「推进」。
- **你动一下，大家动一轮**：发一句话（或选项、或掷了骰子）→ 一次 API → KP 叙述 + 每个角色这回合说的做的 + 「接下来要你做什么」（自由 / 检定 技能·难度 / 对抗 / 理智检定 / 选择）。普通 / 困难 / 极难 / 对抗由 KP 判断（有后果才检定）。
- 骰子永远手机掷（rules.js），AI 只收结果；大成功 / 大失败三档在设置里选（规则书 01/100、1～3/98～100、1～5/96～100）。也能主动掷（🎲 选技能），结果随下一句一起发给 KP。
- 开局一次 API 生成骨架：标题、3～5 幕（目标 / 地点 / 出口）、真相、好坏结局、人物卡、开场白（先接正文一两句）。每幕最多 8 回合，到了 KP 必须推到出口；最后一幕用完必须给结局。
- 理智：掉 5 点以上临时发疯（1D10 症状，持续几回合，写进 KP 的提示词里）；血 / 理智归零由 KP 处理。不能重掷（作者定的）。
- 要等的都能取消；退出再进来还在等同一次。失败只提示结果，原因进日志。

## 六、还没做（分期）
- 第二期：战斗轮（行动顺序、血条、怪物）、兵分几路（「与此同时」切镜头 + 顶上小标签）、角色当 KP、疯狂的画面效果。
- 第三期：记录回放、从某个节点开分世界（节点之后重新生成）。
- 第四期：剧本杀；DND。
- 场景不够时用生图线现画 / 自己往图库加图；没图用空相纸兜底。
- 立绘：现在用头像做人物牌；以后可以给每个联系人另传一张立绘。

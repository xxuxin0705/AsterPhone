# 论坛体：怎么写才有活人味

给以后专门写论坛提示词用的笔记。现在代码里还没照这个改。

几条前提：
- 要适合任何故事世界，不只是娱乐圈。古代、修仙、校园、末日、异世界……都得能用。
- 提示词里的例子只用中性的、编出来的，不用现实里的梗和网站名，也不用任何人自己故事里的人名、地名、台词。
- 黑话、外号要从故事世界自己长出来，不从现实搬。

---

## 一、围观帖（别人发的、大家围观的帖）

### 帖子不只是八卦
发帖的理由五花八门：求助、吐槽、晒东西、问路、找人、转让、闲聊、八卦。刷一页不该全是吃瓜。

### 长短很不齐
- 大多数楼层就一两行。
- 很多楼只有「？」「……」或一个表情。
- 偶尔冒出一层很长的考据楼。

### 是随手打的，不是作文
少标点、半句话、错别字、拖长的语气词（「啊啊啊」「嗯——」）、口头禅、方言。不讲究修辞。

### 每个人立场不一样
不是人人都在抖机灵。按对这件事的态度分：
- 护着当事人的
- 看不惯别人下结论、阴阳怪气的
- 纯吃瓜的
- 自称知情、拿资历压人的
- 较真、要证据的
- 没看懂、在问发生了什么的

语气也分：有的认真，有的着急，有的冷淡。

### 楼层之间会互动
互怼、复读、接梗、歪楼；楼主会「二编」补充或者改口。

### 消息是一点点漏出来的
不是一开始就全说清楚。中间有人质疑、有人翻旧账、可能反转。

### 黑话和外号
从故事世界里长出来，同一个东西前后叫法要一致。

### 平台痕迹（要改代码，还没定）
被折叠、已删除的灰色楼层，管理员出来说话。

## 二、楼主自己讲事的帖（用户自己发的帖、树洞）

- **第一波大多是凑热闹**：抢沙发、刷「哈哈哈」、开玩笑、「蹲后续」。认真给建议的只有少数几个。
- **楼主挑着回**：不是每层都回；被质疑会急、会辩解；楼里吵起来了会出来劝或者说两句。
- **长短对比明显**：楼主一回就很长，网友都很短，中等长度的很少。
- **楼主激动时打字乱**：重复的词、「！？」混着用、说着说着突然岔开。
- **催更循环**：网友催更 → 楼主回一段 → 大家起哄，有时会接龙。
- **气氛会变**：楼主说到认真的地方，大家从起哄转成关心。
- **给楼主起外号**：有时会有，不是每次都有。

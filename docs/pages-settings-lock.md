## 一、锁屏（App 编号 `lock`）

### L1 锁屏主界面 `lock-main`
- 背景：锁屏壁纸，铺满整块屏幕。
- 顶部状态栏。
- 大时间 `as-lock-clock`（80pt 细体），下面一行日期 `as-lock-date`。时间按设置显示现实时间或剧情时间；显示剧情时间时，日期前面多一颗小星星 ✦，表示「这是剧情里的时间」。
- 中部：通知卡片堆 `as-lock-notice`（最多显示 3 条，例如「XX：在吗？」），没有通知时不显示。
- 底部中间：指纹图标 `as-lock-finger`，下面一行小字提示「按住指纹解锁」。
- 底部右下角小字：「使用密码」（设置了密码时才显示）。

### L2 指纹按住中 `lock-main`（状态）
- 指纹图标外圈出现一圈强调色进度环，随按住时间填满（约 0.6 秒）。
- 填满 → 指纹图标短暂变成对勾 → 解锁进入桌面。
- 说明：这是「假指纹」，只要按住就能解锁，不做真实识别。

### L3 数字密码 `lock-pin`
- 顶部提示「输入密码」。
- 4 个或 6 个圆点 `as-lock-pin-dots`（随密码位数），已输入的点填成强调色。
- 3×4 数字键盘 `as-lock-keypad`：1–9、0，左下「取消」，右下「删除」。
- 底部小字按钮「忘记密码？」。
- 出错状态（`is-error`）：圆点变红并左右抖动一下，提示「密码错误」。

### L4 手势密码 `lock-pattern`
- 顶部提示「绘制解锁图案」。
- 3×3 圆点阵 `as-lock-pattern`。
- 画的过程中：经过的点亮起强调色，点之间连成线。
- 出错状态：线和点变红，提示「图案错误」，0.8 秒后清空。
- 底部小字按钮「忘记密码？」。

### L5 备用密码 `lock-backup`
从「忘记密码？」进入。**备用密码跟着解锁方式走，用同一种形式输入，不会从手势突然跳成数字：**

| 解锁方式 | 备用密码 | 备用页面长什么样 |
|---|---|---|
| 数字密码 4 位 | `0000` | 和 L3 一样的键盘，标题改成「输入备用密码」 |
| 数字密码 6 位 | `000000` | 同上 |
| 手势密码 | **Z 字形**（左上 → 右上 → 中心 → 左下 → 右下，经过 1-2-3-5-7-8-9 七个点） | 和 L4 一样的点阵，标题改成「绘制备用图案」，点阵下方淡淡地提示一个小 Z |
| 指纹 | 不需要（按住就能开） | — |

- 酒馆扩展面板里另有「重置锁屏」按钮兜底。

## 二、设置（App 编号 `settings`）

### 结构总览
```
设置首页
├─ 连接（API 钥匙柜）
│   └─ 新建 / 编辑连接
├─ 应用管理
│   └─ 某个应用的详情（以聊天为例）
│       └─ 提示词编辑
├─ 通用提示词
│   └─ 提示词编辑
├─ 外观
│   └─ 状态栏
├─ 锁屏与密码
├─ 通知
├─ 手机本体
├─ 数据
└─ 关于
```
**铁律：一样东西只有一个家。** 应用详情里显示「跟随全局」时，旁边放小箭头，点一下跳到它真正的家。

---

### S0 设置首页 `settings-home`
- 大标题「设置」。
- 列表组 1：连接、应用管理、通用提示词
- 列表组 2：外观、锁屏与密码、通知
- 列表组 3：手机本体、数据、关于
- 每一行：左边彩色小图标，中间名称，右边箭头；部分行右边显示当前值（例如外观显示「日间」）。

### S1 连接 `settings-connections`
- 顶栏标题「连接」，右上「+」新建。
- 分段选择：**文字 / 生图 / 语音**（三类各自一套连接）。
- 列表：
  - 第一条固定为「酒馆」（不可删除，只在「文字」里有）。点开挑用酒馆的哪个连接配置，默认「跟着酒馆走」。酒馆里的配置不再自动各占一个格子（v0.8.287，作者定的）；要两根线各用一个配置时，「添加接口 → 酒馆里的某个配置」自己加，能删。以前插着线的配置格子留下当自己加的。
  - 其余是用户保存的连接，每条显示：名称、渠道类型、模型名。
  - 当前全局默认的那条，右侧有强调色对勾。
- 左滑一条：出现「复制」「删除」。
- 空状态（例如「生图」里还没有连接）：插画 + 「还没有生图连接」+「新建连接」按钮。

### S2 新建 / 编辑连接 `settings-connection-edit`
- 顶栏：左「取消」，标题「新建连接」或连接名，右「保存」。
- 表单：
  - 名称
  - 渠道类型（点一下弹出底部抽屉选择，见 S2b）
  - 地址
  - 密钥（默认显示成圆点，右侧小眼睛切换显示）
  - 模型（下拉选择）+ 旁边「拉取模型列表」小按钮
- 「测试连接」按钮，三种状态都要画：
  - 测试中（按钮变成胶囊加载）
  - 成功（绿色对勾 +「连接正常」）
  - 失败（红色 +「连接失败：原因」+「查看日志」）
- 底部：「设为默认」「复制此连接」、红色「删除连接」（编辑时才有）。
- ✚ 一行说明：「密钥只保存在本机，导出数据时默认不包含密钥。」

### S2b 渠道类型选择 `settings-connection-edit`（底部抽屉状态）
- 底部抽屉，标题「渠道类型」。
- 文字类示例：OpenAI 兼容、Claude、Gemini、自定义。
- 生图类、语音类的渠道列表待定（先画文字类）。
- 当前选中项右侧有对勾。

### S3 应用管理 `settings-apps`
- 顶栏标题「应用管理」。
- 列表：聊天、资源库、日志（每行：应用图标 + 名称 + 一行小字，如「文字：跟随全局」）。

### S4 应用详情（以聊天为例）`settings-app-detail`
- 顶栏标题「聊天」。
- 列表组「使用的连接」：文字、生图、语音，每行右侧显示「跟随全局 →」或具体连接名。
- 列表组「功能提示词」：聊天回复、群聊、动态生成、评论生成、主动消息、离开期间补发、AI 智能加载联系人、世界书拆人。每行：开关 + 箭头（进入 S5 编辑）。
- 列表组「聊天默认设置」（这个 App 特有，每个聊天还能在聊天设置里单独改）：
  - 新聊天默认联动方式：跟随正文 / 仅线上聊天（分段选择）。
  - 主动消息：定时来找你的间隔（仅线上；联动方式与时间里设）。
  - 群里有人转去私聊时：群请求顺便写好 / 单独生成。
  - 角色配图生图（开关，默认关；关着显示图片描述卡）。
- 列表组「注入正文」：
  - 注入默认表 →（每种消息类型一个「写进正文」开关，默认值见聊天文档第八节）。
  - 注入位置：Chat History（默认）/ 人设卡和世界书附近；深度（默认 2~4）。
- 列表组底部：红色「清空聊天的全部数据」。

### S5 提示词编辑 `settings-prompt-edit`
- 顶栏：标题为提示词名称（如「聊天回复」），右「保存」。
- 顶部一行：启用开关。
- 大号多行编辑框（`as-textarea`），里面是提示词文本。
- 编辑框下方「可用变量」：一排标签片 `{{char}}` `{{user}}` `{{time}}`，点一下插入到光标处。
- 底部：「恢复默认」（文字按钮）。

### S6 通用提示词 `settings-prompts`
- 顶栏标题「通用提示词」。
- 列表组「全局」：文风、消息语气、回复长度（每行开关 + 箭头进 S5）。
- 列表组「暗号」：
  - 时间标签（开关 + 箭头）。说明：「让 AI 在正文里输出剧情时间。如果你的预设已经在输出时间，可以关掉这一条。」
  - 标签名称（输入框，默认 `astertime`，即正文里写成 `<astertime>…</astertime>`），可改成其他角色卡里已有的时间标签名。
  - 正文消息标签（开关 + 箭头）：让正文里「TA 给你发了消息」同步到手机。
- 说明：暗号的具体格式在聊天文档里定。

### S7 外观 `settings-appearance`
- 顶栏标题「外观」。
- 当前主题：一张预览缩略图 + 主题名 +「去资源库」按钮。
- 模式：分段选择「日间 / 夜间 / 跟随系统」。
  - 夜间时手机告诉浏览器「这页是暗色的」（根元素 color-scheme: dark）：不然开着「网页深色主题」的浏览器会再自动调暗一遍，把浅色头像当图标反色、输入框变灰（v0.8.242，作者截图）。只靠 prefers-color-scheme 不够：有的浏览器在 iframe 里不报系统是暗色。
- 字体：当前字体名 + 箭头。
- 字号：滑块 + 上方一行实时预览文字。
- 壁纸：两张并排缩略图「桌面壁纸」「锁屏壁纸」，点击更换。
- 状态栏：箭头进入 S7b。

### S7b 状态栏 `settings-statusbar`
- 全局：显示状态栏（开关）。
- 按应用：锁屏、桌面、设置、聊天、资源库、日志，每行一个开关（跟随全局时显示灰色「跟随全局」）。

### S8 锁屏与密码 `settings-lock`
- 锁屏开关（**默认关**：打开手机直接进桌面）。
- 解锁方式：无（上滑解锁，**开启锁屏后的默认**）/ 指纹（按住即解锁）/ 数字密码 / 手势密码（单选列表，当前项有对勾）。
- 数字密码位数：4 位 / 6 位（选数字密码时显示）。
- 设置密码 / 修改密码。
- 说明一行：「忘记密码时，可在解锁界面使用备用密码：数字密码为 0000 / 000000，手势密码为 Z 字形。」

### S9 通知 `settings-notify`
- 新消息横幅（开关）。
- 提示音：开关 + 「选择音效」箭头 + 音量滑块。
- 免打扰时段：开关 + 开始时间、结束时间。
- 桌面图标未读红点（开关）。

### S10 手机本体 `settings-device`
- 时间来源：分段选择「现实时间 / 剧情时间」。选剧情时间时，下面出现「读不到剧情时间时：手动设定」+ 时间选择。
- 窗口大小（电脑上生效）：自动 / 手动 + 滑块。
- 连点三下开关手机（开关，默认关）。说明：「开启后，在酒馆页面空白处连点三下打开手机，在手机空白处连点三下关闭。」
- ✚ 悬浮按钮：大小滑块、位置（可拖动）。

### S11 数据 `settings-data`
- 存储占用：一条横向占比条（聊天 / 资源库 / 日志 / 其他）+ 总大小。
- 导出数据：箭头 → 底部抽屉选「全部 / 选择应用」+「包含密钥」开关（默认关）。
- 导入数据。
- 红色「清空全部数据」。

### S11b 清空确认弹窗 `settings-data`（弹窗状态）
- 弹窗标题「清空全部数据？」，说明「此操作无法撤销」。
- 输入框，提示「请输入 确认」。
- 按钮：取消 / 清空（红色，输入正确前是禁用状态）。

### S12 关于 `settings-about`
- 顶部：Aster 图标 + 名称 + 版本号。
- 检查更新：两种状态都画 —「已是最新版本」/「发现新版本 vX.X」+「更新」按钮。
- 打开日志：箭头（跳转到日志 App）。

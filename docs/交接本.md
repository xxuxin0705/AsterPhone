## 作者这次新定的规矩 / 口味
- 一次点击只调一次 AI；只有写断了且开了自动补写，或作者自己再点，才多调。
- 提示词、界面提示、代码注释里不准用作者故事里的人名 / 地名 / 台词当例子（可能开源）。旧注释里还有，以后清。
- 生成类按钮（观星、问缘这类）点了先弹窗说明这是干什么的，确认才找 AI。
- 能选就别让人打字：人、日期、上级地点都用点选 / 滚轮；日期一律用 `ui.js` 的 `dateField`（年月日三列滚轮）。
- 滚动的纸 / 面板，顶上一条（名字、收起、操作按钮）要钉住。
- 抽屉里的「删除」和「取消 | 保存」放同一行（删除在最左）。
- 生成结果不直接盖掉：先给作者挑（问缘 / 观星的「挑一版」页，逐行选原来的 / 新的）。
- 关系词自由写，四个字以内；常用词里有「挚友」。
- 动效要像真的：沙漏点进沙里要空一下再塌，按住能一路划；出沙变快要整条时间轴一起快。

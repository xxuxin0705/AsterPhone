# Aster 设计规范 v0.1（草案）

> Aster（小星星）是一个 SillyTavern 小手机插件。本文件是**唯一的法官**：
> 写代码的、画图的，所有模型都以它为准；图和本文件冲突时，听本文件的。

---

## 0. 三层分工

| 层 | 管什么 | 谁能改 |
|---|---|---|
| 框架 | 数据怎么存、AI 怎么调、页面怎么开关、返回怎么走 | 只有我们 |
| 设计规范（本文件） | 门牌号（类名）、调色盘（变量）、公共积木、动效、交互规则 | 只有我们，且门牌号公开后**永不改名** |
| 皮肤 | 具体长什么样 | 任何人（通过资源库导入 CSS） |

---

## 1. 画布与尺寸

- **基准画布**：390 × 844（逻辑尺寸）。设计图统一导出为 **1170 × 2532 像素**（3 倍）。
- **单位**：本文件里所有尺寸都写成 **pt**，1pt = 屏幕宽度 ÷ 390。
  屏幕宽，所有东西等比放大；屏幕窄，等比缩小，比例永远不变。
- **手机上**：铺满整个屏幕。
- **电脑上**：一个固定比例（390:844）的手机窗口，可以拖动调整大小。
- **安全区**：背景和壁纸铺满整块屏幕（包括刘海后面）；按钮、文字要避开刘海和底部手势条，不被挡住。
- **最小可点区域**：44 × 44pt。

## 2. 门牌号规则（类名）—— 公开约定，永不改名

### 2.1 前缀
所有类名、变量、标识统一以 `as-` 开头，避免和酒馆或其他插件撞名。

### 2.2 App 编号
| App | 编号 |
|---|---|
| 锁屏 | `lock` |
| 桌面 | `home` |
| 设置 | `settings` |
| 聊天 | `chat` |
| 资源库 | `library` |
| 日志 | `log` |

### 2.3 页面
每个页面的最外层都带两个标记，皮肤靠它们精确定位到「某个 App 的某一页」：

```html
<section class="as-page" data-as-app="settings" data-as-page="settings-connections">
```

页面编号格式：`{app}-{页面名}`，例如 `settings-home`、`lock-pin`。完整页面编号见各 App 的页面清单文档。

### 2.4 零件
- **公共积木**（所有 App 共用）：`as-{积木名}`，例如 `as-btn`、`as-list-item`。
- **App 专属零件**：`as-{app}-{零件名}`，例如 `as-lock-clock`、`as-settings-conn-card`。
- **变体**：`--变体名`，例如 `as-btn--primary`、`as-btn--danger`。
- **内部小部件**：`__部件名`，例如 `as-list-item__title`、`as-list-item__value`。

### 2.5 状态（同样公开、永不改名）
| 状态 | 类名 | 什么时候出现 |
|---|---|---|
| 按下 | `is-pressed` | 手指按住时 |
| 选中 / 当前 | `is-active` | 当前页、当前选项、开关打开 |
| 禁用 | `is-disabled` | 不能点 |
| 加载中 | `is-loading` | 等待 AI / 网络 |
| 展开 | `is-open` | 抽屉、弹窗、下拉打开时 |
| 隐藏 | `is-hidden` | 被设置隐藏（如状态栏） |
| 出错 | `is-error` | 密码错误、连接失败 |
| 成功 | `is-success` | 测试连接成功等 |

### 2.6 文案编号（同样公开、永不改名）
CSS 适合换样子和图标，不适合换文字。所以每一处**可以被皮肤替换的文字**都有一个文案编号，格式 `{app}.{位置}.{名字}`，例如：
- `chat.tab.moments` → 默认「动态」，微信皮肤可以改成「朋友圈」，QQ 皮肤改成「QQ空间」。

### 2.7 改名纪律
- 已公开的类名、文案编号**不删除、不改名**。确实要换，就新增新名字，旧名字继续保留并标注「已弃用」。

## 3. 调色盘（CSS 变量）

所有颜色、圆角、间距、字号、阴影、动效时长**一律用变量**，代码里不准写死数值。
皮肤只要改这些变量，整个手机就跟着变。

### 3.1 颜色（v0.8.319 起：清透六色）
**很淡的底色打底、白色毛玻璃面板、大圆角、按下去有"果冻"感**。颜色都是高亮度、低饱和，不用鲜艳的蓝。
每套主题只定三个颜色：**底色、字色、强调色**（日间、夜间各一组，写在 `core/skin.js` 的 `THEMES`），其余都在 `base.css` 里从这三个算出来。夜间是同一个色相压暗（不是黑）。
六套：冰雾浅蓝 `#EAF5FA`（默认）、清透薄荷 `#D7FAF4`、柔雾粉 `#FCE9EF`、浅雾紫 `#E9DFF8`、奶黄浅色 `#FFF9CC`、柔叶浅绿 `#DCF1E0`。下表是默认那套。

| 变量 | 用途 | 日间 | 夜间 |
|---|---|---|---|
| `--as-color-bg` | 页面底色（主题给） | `#EAF5FA` | `#1d262b` |
| `--as-color-bg-grad` | 页面渐变（算出来） | 上面掺白 → 底色 | 底色略亮 → 略暗 |
| `--as-color-surface` | 玻璃面板（卡片、列表组、底栏） | `rgba(255,255,255,.6)` | `rgba(255,255,255,.10)` |
| `--as-color-surface-2` | 次级底色、输入框、分段选择的槽 | `rgba(255,255,255,.4)` | `rgba(255,255,255,.08)` |
| `--as-color-surface-solid` | 需要不透的地方（弹窗、抽屉、菜单）（算出来） | 底色掺 65% 白 | 底色掺 9% 白 |
| `--as-color-glass-line` | 玻璃的描边 | `rgba(255,255,255,.8)` | `rgba(255,255,255,.18)` |
| `--as-color-gloss` | 面板顶部的高光 | `rgba(255,255,255,.55)` | `rgba(255,255,255,.14)` |
| `--as-color-text` | 主文字（主题给） | `#293942` | `#f1f8fc` |
| `--as-color-text-2` / `--as-color-border` | 次要文字 / 分割线（算出来） | 字色的 60% / 9% | 同左 |
| `--as-color-accent` | 强调色：主按钮、开关、选中、我的气泡（主题给） | `#4c7d9a` | `#a8cce1` |
| `--as-color-accent-2` | 强调色的亮端（算出来） | 强调色掺 20% 白 | 同左 |
| `--as-color-on-accent` | 强调色上的文字 | `#ffffff` | 等于底色 |
| `--as-color-aurora` | 页面右上角的一团光 | `rgba(255,255,255,.7)` | `rgba(255,255,255,.05)` |
| `--as-color-danger` | 删除、清空、错误 | `#e5484d` | `#ff6b70` |
| `--as-color-success` | 成功 | `#22a06b` | `#3dd68c` |
| `--as-color-mask` | 弹窗背后的遮罩 | `rgba(14,60,96,.28)` | `rgba(2,14,28,.55)` |
| `--as-blur` | 玻璃的模糊度 | `22px` | `22px` |

规则：
- 主按钮、开关打开、我的气泡都是「亮端 → 强调色」的竖向渐变，上面压一层白色高光（`.as-btn::before`）。
- 不用黑色、不用灰色平面、不用霓虹色；文字在玻璃上用主题的字色（日间是深一档的灰蓝，夜间近白）。
- 强调色一屏只给最重要的那一个东西。
- 锁屏和桌面浮在壁纸上的卡片用另一套 `--card` / `--ink` 变量（见 base.css），和 App 内部分开。

### 3.2 圆角
| 变量 | 数值 | 用在 |
|---|---|---|
| `--as-radius-s` | 10pt | 小标签、输入框内部小块 |
| `--as-radius-m` | 16pt | 按钮、输入框 |
| `--as-radius-l` | 22pt | 卡片、列表组 |
| `--as-radius-xl` | 30pt | 底部抽屉、弹窗 |
| `--as-radius-full` | 999pt | 胶囊、圆形 |

### 3.3 间距
`--as-space-1` 4pt · `--as-space-2` 8pt · `--as-space-3` 12pt · `--as-space-4` 16pt · `--as-space-5` 20pt · `--as-space-6` 24pt · `--as-space-8` 32pt
页面左右边距统一 16pt。

### 3.4 文字
| 变量 | 字号 / 粗细 | 用在 |
|---|---|---|
| `--as-font-caption` | 12pt / 常规 | 小注释、时间戳 |
| `--as-font-footnote` | 13pt / 常规 | 列表组标题、说明文字 |
| `--as-font-body` | 15pt / 常规 | 正文、列表项 |
| `--as-font-headline` | 17pt / 中粗 | 顶栏标题、按钮 |
| `--as-font-title` | 22pt / 粗 | 页面小标题 |
| `--as-font-large` | 34pt / 粗 | 页面大标题 |
| `--as-font-clock` | 80pt / 细 | 锁屏大时间 |

字体：默认用系统字体（苹方、鸿蒙、MiSans 等，跟着手机走）。用户可在设置里换字体、整体调大调小。数字用等宽数字，滚动时不抖。

### 3.5 阴影
- 日间：玻璃面板用 `0 10px 30px rgba(14,80,130,.12)`，加 `--as-color-glass-line` 描边。
- 夜间：`0 10px 30px rgba(0,10,25,.3)`，描边同上但更淡。

### 3.6 动效变量
| 变量 | 数值 | 用在 |
|---|---|---|
| `--as-dur-fast` | 120ms | 按下反馈 |
| `--as-dur-base` | 240ms | 开关、淡入淡出 |
| `--as-dur-page` | 360ms | 页面进出 |
| `--as-ease-standard` | `cubic-bezier(.2,.8,.2,1)` | 一般过渡 |
| `--as-ease-spring` | `cubic-bezier(.34,1.4,.64,1)` | 带一点点回弹 |

| 积木 | 类名 | 说明 |
|---|---|---|
| 状态栏 | `as-statusbar` | 高 44pt。左：时间（现实或剧情时间）；右：网络、电量、**关闭手机按钮**。可隐藏 |

| 轻提示 | `as-toast` | 底部的小提示条，例如「已保存」。出错时带「查看日志」按钮 |
| 红点 / 角标 | `as-badge` | 未读数，数字变化时滚动 |

## 5. 动效规则

1. **从哪来，回哪去**：点开的东西从它原来的位置长出来，关闭时缩回原位。
2. **用弹簧，不用匀速**：抽屉、弹窗、页面切换都带一点自然的减速或回弹。
3. **一按就有反馈**：所有能点的东西，按下时缩到 0.96 倍（`--as-dur-fast`），松手弹回。
4. **数字变化要滚动**：未读数、时间等数字像码表一样翻动。
5. **贵的效果省着用**：发光、模糊、粒子，一屏最多一处，只留给「特别时刻」（例如来电、AI 正在生成）。
6. **只动「位置、大小、透明度」**：这三样手机跑得动，其他属性尽量不做动画。
7. 手机系统开启了「减少动态效果」时，自动改成淡入淡出。

页面切换：新页面从右边滑入，旧页面向左挪一点并变暗；返回时反过来。

### 5.1 小巧思清单
主题是「小星星」，所以小巧思尽量和星光有关，但**一屏最多一个会发光的东西**。
标 ★ 的是「特别时刻」，允许用发光 / 粒子。

**全局**
- 从桌面点开 App：App 从图标的位置长出来；关闭时缩回图标。
- 横幅通知：从顶部带一点回弹落下，往上一划就收走。
- 未读数字：变化时像码表一样滚动。
- AI 正在生成的那一块：边框有一圈缓慢转动的暖橙光晕（★）。

**锁屏**
- 时钟：分钟变化时数字向上滚动翻页。
- 指纹按住：进度环沿圆圈填满；解锁瞬间迸出一小撮星星碎屑（★），壁纸从微微放大+模糊恢复清晰，像镜头对焦。
- 数字密码：每按一个数字，对应的小圆点「噗」地填满（轻微放大再回弹）；输错时整排圆点左右摇头。
- 手势密码：手指划过的线带一点拖尾；图案正确时，经过的点按顺序依次亮一下，像星座连线（★）。

**设置**
- 开关：圆钮滑过去时带一点点回弹。
- 日间 / 夜间切换：从你点的位置开始，一个圆圈向外扩散，新颜色跟着圆圈铺满屏幕。
- 字号滑块：上方预览文字跟着手指实时变大变小。
- 测试连接：按钮缩成胶囊，里面四根小竖条一起一伏（全插件等待都是这个样子；AI 智能加载用整条波浪条，带「已想到几人」） → 成功时画出一个对勾 / 失败时左右摇头。
- 存储占用条：进入页面时从左往右长出来。
- 清空确认：输入正确「确认」前，「清空」按钮是灰的；输对的瞬间亮起。
- 彩蛋：在「关于」页连点 Aster 图标 7 次，下一场小小的流星雨（★）。

**聊天**
- 「发送」变「让 TA 回复」：按钮像水滴一样变形，图标换成一颗小星星。
- 「对方正在输入…」：三个小点轮流跳动。
- 新消息：气泡从下方带一点回弹冒出来；多条消息一条一条出现。
- 拍一拍：被拍的头像左右晃两下。
- 贴表情：表情从小弹到大落在气泡角上；同一个表情再有人贴，数字滚动 +1。
- 撤回：气泡缩小淡出，原地变成一行灰字。
- 红包：点开时封口翻转。
- 续火花：火苗图标轻轻摇曳；天数升级换图标时闪一下。
- 来自剧情的消息：角落一颗小星星 ✦。
- 动态点赞：爱心先缩一下再弹大，周围冒出几粒小光点。
- 动态下拉刷新：顶部一颗星星旋转。

## 6. 交互规则

### 6.1 返回
- 手指从屏幕左右边缘往里滑 → 返回上一页。页面**跟着手指走**，滑过三分之一或甩得够快就完成返回，否则弹回。
- 起滑区域离屏幕最边缘留一小段距离，避免触发浏览器自己的后退。
- 安卓系统自带的返回键 / 返回手势，同样等于「小手机里返回一步」。
- 返回的层级：子页面 → 上一页 → App 首页 → 桌面 → **在桌面再返回一次 = 关闭手机**。

### 6.2 打开 / 关闭手机
- 打开：酒馆页面上的悬浮按钮。
- 关闭：状态栏右上角的关闭按钮；或在桌面上再返回一次。
- 可选：在设置里勾选「连点三下开关手机」（**默认关闭**）。开启后，在酒馆页面任意空白处连点三下打开手机，在手机屏幕空白处连点三下关闭。

### 6.3 状态栏
- 时间可选现实时间或剧情时间。
- 是否显示：可以按主题设，也可以按每个 App 单独设。

### 6.4 头像手势（全手机统一）
- 单击任何人的头像 → 资料页。
- 聊天里双击头像 → 拍一拍（单击因此会等约 0.25 秒确认不是双击）。
- 群聊里长按头像 → @TA。
- 点自己的头像 → 我的主页。

### 6.5 出错
- 出错时弹轻提示，带「查看日志」按钮，直接跳到日志 App 里那条记录。

## 7. 皮肤规则

- 皮肤以**皮肤包**的形式存在，里面装三样：CSS（样子）、图片（图标、背景）、文案替换表（名字，见 2.6）。
- 皮肤只能通过**公开的门牌号**（第 2 节）、**变量**（第 3 节）和**文案编号**（2.6）来改。
- 皮肤的作用范围：整套主题 / 某个 App / 某个 App 的某一页（第一版只留口子，先做一套固定样式）。
- 导入、试用、套用、恢复默认都在**资源库**里。
- **恢复默认的按钮不受任何皮肤影响**；酒馆扩展面板里另有一个「紧急恢复」按钮作为双保险。

## 8. 全手机通用规矩

1. **一样东西只有一个家**：每个设置只在一个地方真正保存；别处只放「跟随全局 →」或快捷入口，点一下跳回它的家。
2. **越具体越优先**：本聊天 / 本群 ＞ 应用设置 ＞ 全局默认（头像、名字、时间、外观、API 等都适用）。
3. **没改过就跟随，改过就独立**：从酒馆加载来的内容，在 Aster 里没动过就跟着酒馆更新；改过就归 Aster，旁边标「已独立」+「重新跟随酒馆」。
4. **不花冤枉钱**：翻译、表情包识别必须免费；主动消息不设次数上限（作者定的：正文提到就来，仅线上按间隔定时来）；能手动触发的默认手动触发。
5. **同一排的图标按钮一样大、上下对齐**：比如锁屏播放卡片的「红心 / 上一首 / 暂停 / 下一首」，图标同一个尺寸，按钮盒子一样大、图标在盒子正中；不要中间那个特别大、红心特别小。

## 9. 给画图模型的通用要求

1. 画布 **1170 × 2532**，只画屏幕内容，**不要画手机外壳**，平面截图的样子。
2. 界面文字用**简体中文**，放真实合理的内容，不要乱码或假字。
3. 每页都带顶部状态栏（时间、网络、电量、右上角关闭按钮），除非该页注明隐藏。
4. 严格使用第 3 节的颜色、圆角、字号；同一种积木在不同页面里必须长得一样。
5. 一张图只画一个页面的一种状态；需要多个状态的，分开画。
6. 默认画**日间**；清单里标注「+夜间」的，再画一张夜间版。
7. 图片存放路径和文件名，按页面清单文档里写的来。
8. 长页面（设置项很多的页面）可以画成两屏高（1170 × 5064）。

## 10. 做设计的方法（学自《网页灵感与实现 · 常用网站推荐手册》乖乖 × Sol v1.0）

### 10.1 顺序：先气质，再机制，最后零件
1. **先找气质**：这一页像什么、什么情绪、信息有多密。先定「像什么」，不先挑「哪个最好看」。
2. **再找机制**：滚动、按住、拖动、粒子、3D、转场……记下**什么时候触发、怎么互动**。
3. **最后找零件**：组件、图标、动画素材、字体。统一风格，再看授权和手机上跑不跑得动。

### 10.2 四条原则
1. **参考「语言」，不复制「皮肤」**：从别人的作品里拆出构图、节奏、材质、光线、交互，再按 Aster 的样子重做。不照搬整套长相（例：别人把连接做成银行卡，我们就不做银行卡）。
2. **一屏一个主效果**：每屏只设一个视觉主角。效果叠多了不是高级，是吵（和第 5 节第 5 条一致）。
3. **动效要在真机上看**：截图看不出动效好不好，参考要有录屏或链接，做完要在手机上看一遍。
4. **动手前先看授权和性能**：代码看仓库 License，字体看网页嵌入 / 商用授权，图标和 Lottie 一个一个看许可。上线前检查性能、无障碍（键盘、焦点、读屏）、手机降级和「减少动态效果」。

### 10.3 难度分级（评估一个效果值不值得做）
- **易**：挑一个、小改就能用（CSS 小动画、图标、字体）。
- **中**：要按 Aster 的写法改造（别人是 React 组件 → 我们是原生 JS，要重写）。
- **高**：要 Canvas / WebGL 工程化（壁纸、粒子、3D）。必须能暂停、能降级、手机不卡。

### 10.4 作者丢参考过来时，按这张单子问清楚
| 问题 | 例子 |
|---|---|
| 页面链接 / 录屏 | 小红书链接、录屏 |
| 最喜欢的具体部分 | 「卡片叠在一起、点一张抽出来」 |
| 喜欢的是布局、颜色、字体、材质，还是动效 | 材质 + 动效 |
| 动效什么时候触发 | 点击 / 按住 / 滑动 / 自己动 |
| 必须保留的感觉 | 「有收藏感」 |
| 可以换掉的元素 | 「银行卡的样子可以换」 |
| 放进哪个 App / 哪一页 | 设置 → 连接 |
| 手机上必须好用吗 | 必须（酒馆用户大多用手机） |

### 10.5 去哪找（按用途）
| 用途 | 网站 | 对 Aster 的用法 |
|---|---|---|
| 整页气质 | Dribbble、Norrly、MotionSites | 先做情绪板，看构图和节奏，不直接照抄 |
| 设置页小控件 | UIverse | 开关、输入框、按钮可以拿来改；复制前查作者许可、焦点状态、暗色模式 |
| 精致组件 | Magic UI、Animata、React Bits、Aceternity UI | 都是 React，要用原生 JS 重写；一次只选 1～2 个主效果，避免「模板站」痕迹 |
| 小动作 | Devsnap CSS Animations | 按钮、加载、卡片的微动效 |
| 前沿效果 | Codrops、CodePen | 找「效果名 + 原理 + demo」；CodePen 当原型，不当成品代码；复杂的先评估手机性能 |
| 粒子 / 3D | OpenProcessing、three.js | 只给壁纸这类「特别时刻」用，必须可暂停、可降级 |
| 图标 | SVG Repo | 统一线宽、圆角、视图框（viewBox）再进项目 |
| 小动画素材 | LottieFiles | 只用在小面积 UI（加载、反馈），看循环有没有缝、能不能改色、文件多大 |
| 字体 | Google Fonts、Fontshare、Font Squirrel、Fonts In Use、Typewolf、FontVS | 看字号、字距、搭配；查网页授权；中文另配 CJK 字体 |

### 10.6 记下的待办
- **字体自己托管**：手册建议，为了国内访问和隐私，网页字体放进自己的仓库，不从 Google Fonts 现拉。Aster 现在的 Cormorant Garamond、Noto Serif SC、Nunito、Inter 都是从 fonts.googleapis.com 加载的，国内不开 VPN 可能加载不出来 → 以后改成放进 `phone/assets/fonts/`（这几款都是开源字体，可以放）。
- 锁屏时钟内置的 SF Pro Display Bold 是作者决定放进仓库的，只裁了数字和英文字母。

### 10.7 布局怎么挑（学自小红书「AI 做网页的 10 种布局」）
作者不用记这些名字：**做设计时由 AI 自己按内容挑一种**，在方案里用一句大白话说明「用的是哪种、为什么」。不要只凭「高级、简洁」去猜。
| 布局 | 什么时候用 | Aster 里的例子 / 打算 |
|---|---|---|
| 卡片式 | 一条一条的同类东西 | 歌单、聊天列表、设置项 |
| 网格 | 要按列对齐的东西 | 桌面图标、「我的」页四格统计 |
| 一排对齐（Flexbox） | 一行按钮、图标 | 取消 \| 保存；同一行图标一样大、居中（第 8 节） |
| 全出血 | 背景就是主角 | 锁屏壁纸、播放页、下雨天皮肤 |
| 瀑布流 | 高矮不一的图片，不想裁 | 以后的动态、资源库图片 |
| 便当盒 Bento | 靠格子大小分主次 | 以后桌面小组件（重要的占 2×2，次要的 1×1） |
| 分屏、侧边栏、仪表盘、响应式 | 电脑大屏用的 | 小手机屏幕太窄，一般不用；尺寸变化交给 `holdSize` |

## 11. 作者定下的两条硬规矩

### 11.1 能抠图就抠图，能不自己画就不自己画
- 要图的时候，顺序是：**现成的图抠出来用 → 现有素材复用（比如主页「水中月」里的鱼形）→ 开源素材（先看授权）→ 实在没有，才用代码画。**
- 用代码手画插画（SVG 画山、画树、画小动物）效果通常不如图，作者不喜欢。v0.6.0 连接页的「森林剪影」就是反例，已经换掉。
- 字符画（ASCII）是例外：它本来就是「用字符拼」的风格，但拼的形状也尽量来自现有素材。

### 11.2 能不整页刷新，就不整页刷新
- 点一下、拖一下、保存一下，只改**变了的那一小块**：改文字、改一个类名、加或删一个元素、挪一下位置。不要把整个列表 `innerHTML = ''` 再重建。
- 整页重建在手机上会「闪一下」，作者能看出来。
- 状态变化（比如拎起一根线让别的格子变暗）只在**真的开始拖**之后才发生，点一下不该让画面跳。
- 动画层（canvas）没东西在动的时候就别每帧重画。

## 12. 中文字体怎么选（学自开源 skill「chinese-font-selector」，MIT）

**先看授权，再谈好看。**
- **T0 开源（OFL，商用、嵌进网页都放心）**：思源黑体、思源宋体、得意黑、霞鹜文楷、霞鹜新晰黑、未来荧黑、朱雀仿宋、汇文明朝体。
- **T1 厂商声明免费商用（用前再去官网确认一次）**：阿里巴巴普惠体、MiSans、OPPO Sans、HarmonyOS Sans、站酷系列、庞门正道标题体、优设标题黑。
- **T2 别默认用**：文泉驿（GPL）、汉仪（大多收费）、系统自带字体（微软雅黑、苹方、SF Pro 等，不能提取出来嵌进网页或分发）、找不到授权声明的一律不用。
- 本项目内置的 SF Pro Display Bold 属于 T2，是作者明确要求、自己承担风险放进去的；以后新加内置字体只用 T0。

**按气质挑：**
- 屏幕 / UI：MiSans、HarmonyOS Sans、思源黑体。
- 文艺、温润：霞鹜文楷（正文）+ 思源宋体粗（标题）。
- 活泼标题：得意黑。力量标题：站酷高端黑、庞门正道。
- 复古 / 民国：汇文明朝体。

**排版规矩：**
- 中英混排：`font-family` 里英文字体写在前，中文写在后（思源黑体配 Inter / SF Pro，思源宋体配 Source Serif / Cormorant，霞鹜文楷配 Lora）。
- 中文不要用斜体（浏览器硬拗出来的斜体很丑），强调用字重或颜色。
- 正文行距 1.5–1.8，标题 1.2–1.3；中文正文不加字距，标题可以加 0.02–0.05em。
- 全角标点；省略号用「……」；标点不出现在行首。
- 网页里放中文字体要子集化或用分片 CDN（「中文网字计划」），整套中文字体 3–10MB，直接加载会卡。

## 13. 不许闪屏（作者多次强调）
- 点一个选项，只更新那个选项相关的元素，不重画整页。
- 必须重画时：旁边画好 → 图片解码完 → 一次换上。
- 每次改完界面都要用连续截图检查有没有空白帧。

## 14. 视觉对齐（学自小红书「逸风的 UI 研究」的视频《视觉对齐 · Optical alignment》）
几何上对齐了，人眼看着还是歪的，要按眼睛的感觉再挪一点。改完任何界面都过一遍（作者要求全手机都用上）：
1. **同一列的东西站成一条线**：标题、列表文字、卡片边、按钮边、返回箭头的尖，都落在页面边距那条线上（16px）。看的是「看得见的边」，不是按钮的框：返回按钮的框比箭头大，所以整体往左挪了 6px，让箭头的尖对上内容。
2. **上下两块一样宽**：桌面小组件和下面一排图标，最左、最右的图标边贴齐小组件的边。
3. **该居中的按眼睛居中**：不对称的图形按「分量」居中——播放三角往右挪一点（约宽度的十分之一，`play` 图标已经这样画了），星星、下载这类上轻下重的往上提一点；文字和图标并排时看字的中线，不看行高。
4. **大字号的边**：大数字、大标题自带左边留白，和下面的小字对不齐时，用负的 margin 抵掉。
5. **怎么检查**：截两倍图，在页面边距（16px）和中线上画竖线，看该在线上的东西是不是都在线上；差 2px 以内算对齐。

# Aster 设计规范 v0.1（草案）

> Aster（小星星）是一个 SillyTavern 小手机插件。本文件是**唯一的法官**：
> 写代码的、画图的，所有模型都以它为准；图和本文件冲突时，听本文件的。

---

## 0. 三层分工

| 层 | 管什么 | 谁能改 |
|---|---|---|
| 框架 | 数据怎么存、AI 怎么调、页面怎么开关、返回怎么走 | 只有我们 |
| 设计规范（本文件） | 门牌号（类名）、调色盘（变量）、公共积木、动效、交互规则 | 只有我们，且门牌号公开后**永不改名** |
| 皮肤 | 具体长什么样 | 任何人（通过资源库导入 CSS） |

---

## 1. 画布与尺寸

- **基准画布**：390 × 844（逻辑尺寸）。设计图统一导出为 **1170 × 2532 像素**（3 倍）。
- **单位**：本文件里所有尺寸都写成 **pt**，1pt = 屏幕宽度 ÷ 390。
  屏幕宽，所有东西等比放大；屏幕窄，等比缩小，比例永远不变。
- **手机上**：铺满整个屏幕。
- **电脑上**：一个固定比例（390:844）的手机窗口，可以拖动调整大小。
- **安全区**：背景和壁纸铺满整块屏幕（包括刘海后面）；按钮、文字要避开刘海和底部手势条，不被挡住。
- **最小可点区域**：44 × 44pt。

## 2. 门牌号规则（类名）—— 公开约定，永不改名

### 2.1 前缀
所有类名、变量、标识统一以 `as-` 开头，避免和酒馆或其他插件撞名。

### 2.2 App 编号
| App | 编号 |
|---|---|
| 锁屏 | `lock` |
| 桌面 | `home` |
| 设置 | `settings` |
| 聊天 | `chat` |
| 资源库 | `library` |
| 日志 | `log` |

### 2.3 页面
每个页面的最外层都带两个标记，皮肤靠它们精确定位到「某个 App 的某一页」：

```html
<section class="as-page" data-as-app="settings" data-as-page="settings-connections">
```

页面编号格式：`{app}-{页面名}`，例如 `settings-home`、`lock-pin`。完整页面编号见各 App 的页面清单文档。

### 2.4 零件
- **公共积木**（所有 App 共用）：`as-{积木名}`，例如 `as-btn`、`as-list-item`。
- **App 专属零件**：`as-{app}-{零件名}`，例如 `as-lock-clock`、`as-settings-conn-card`。
- **变体**：`--变体名`，例如 `as-btn--primary`、`as-btn--danger`。
- **内部小部件**：`__部件名`，例如 `as-list-item__title`、`as-list-item__value`。

### 2.5 状态（同样公开、永不改名）
| 状态 | 类名 | 什么时候出现 |
|---|---|---|
| 按下 | `is-pressed` | 手指按住时 |
| 选中 / 当前 | `is-active` | 当前页、当前选项、开关打开 |
| 禁用 | `is-disabled` | 不能点 |
| 加载中 | `is-loading` | 等待 AI / 网络 |
| 展开 | `is-open` | 抽屉、弹窗、下拉打开时 |
| 隐藏 | `is-hidden` | 被设置隐藏（如状态栏） |
| 出错 | `is-error` | 密码错误、连接失败 |
| 成功 | `is-success` | 测试连接成功等 |

### 2.6 文案编号（同样公开、永不改名）
CSS 适合换样子和图标，不适合换文字。所以每一处**可以被皮肤替换的文字**都有一个文案编号，格式 `{app}.{位置}.{名字}`，例如：
- `chat.tab.moments` → 默认「动态」，微信皮肤可以改成「朋友圈」，QQ 皮肤改成「QQ空间」。

### 2.7 改名纪律
- 已公开的类名、文案编号**不删除、不改名**。确实要换，就新增新名字，旧名字继续保留并标注「已弃用」。

## 3. 调色盘（CSS 变量）

所有颜色、圆角、间距、字号、阴影、动效时长**一律用变量**，代码里不准写死数值。
皮肤只要改这些变量，整个手机就跟着变。

### 3.1 颜色
默认主题有日间、夜间两套，共用同一个强调色（暖橙，像星星的光）。

| 变量 | 用途 | 日间（奶白柔和） | 夜间（深色 + 亮色点缀） |
|---|---|---|---|
| `--as-color-bg` | 页面底色 | `#F6F3EE` | `#0F1013` |
| `--as-color-surface` | 卡片、列表组 | `#FFFFFF` | `#1A1B20` |
| `--as-color-surface-2` | 次级底色、输入框 | `#EFEAE3` | `#25262C` |
| `--as-color-text` | 主文字 | `#1E1C1A` | `#F3F3F5` |
| `--as-color-text-2` | 次要文字、说明 | `#7D776F` | `#9B9DA6` |
| `--as-color-border` | 分割线、描边 | `rgba(30,28,26,.08)` | `rgba(255,255,255,.08)` |
| `--as-color-accent` | 强调色：主按钮、开关打开、选中 | `#F2884B` | `#FF9A55` |
| `--as-color-on-accent` | 强调色上的文字 | `#FFFFFF` | `#1A0F08` |
| `--as-color-danger` | 删除、清空、错误 | `#E5484D` | `#FF5C61` |
| `--as-color-success` | 成功 | `#30A46C` | `#3DD68C` |
| `--as-color-mask` | 弹窗背后的遮罩 | `rgba(0,0,0,.25)` | `rgba(0,0,0,.55)` |

规则：一屏里强调色只用在「最重要的那一个东西」上，不要满屏都是橙色。

### 3.2 圆角
| 变量 | 数值 | 用在 |
|---|---|---|
| `--as-radius-s` | 8pt | 小标签、输入框内部小块 |
| `--as-radius-m` | 14pt | 按钮、输入框 |
| `--as-radius-l` | 20pt | 卡片、列表组 |
| `--as-radius-xl` | 28pt | 底部抽屉、弹窗 |
| `--as-radius-full` | 999pt | 胶囊、圆形 |

### 3.3 间距
`--as-space-1` 4pt · `--as-space-2` 8pt · `--as-space-3` 12pt · `--as-space-4` 16pt · `--as-space-5` 20pt · `--as-space-6` 24pt · `--as-space-8` 32pt
页面左右边距统一 16pt。

### 3.4 文字
| 变量 | 字号 / 粗细 | 用在 |
|---|---|---|
| `--as-font-caption` | 12pt / 常规 | 小注释、时间戳 |
| `--as-font-footnote` | 13pt / 常规 | 列表组标题、说明文字 |
| `--as-font-body` | 15pt / 常规 | 正文、列表项 |
| `--as-font-headline` | 17pt / 中粗 | 顶栏标题、按钮 |
| `--as-font-title` | 22pt / 粗 | 页面小标题 |
| `--as-font-large` | 34pt / 粗 | 页面大标题 |
| `--as-font-clock` | 80pt / 细 | 锁屏大时间 |

字体：默认用系统字体（苹方、鸿蒙、MiSans 等，跟着手机走）。用户可在设置里换字体、整体调大调小。数字用等宽数字，滚动时不抖。

### 3.5 阴影
- 日间：卡片用很淡的柔和阴影 `0 4pt 16pt rgba(0,0,0,.06)`。
- 夜间：不用阴影，改用 `--as-color-border` 描边区分层级。

### 3.6 动效变量
| 变量 | 数值 | 用在 |
|---|---|---|
| `--as-dur-fast` | 120ms | 按下反馈 |
| `--as-dur-base` | 240ms | 开关、淡入淡出 |
| `--as-dur-page` | 360ms | 页面进出 |
| `--as-ease-standard` | `cubic-bezier(.2,.8,.2,1)` | 一般过渡 |
| `--as-ease-spring` | `cubic-bezier(.34,1.4,.64,1)` | 带一点点回弹 |

## 4. 公共积木

每个积木都要画出 / 做出它的所有状态（见 2.5）。

| 积木 | 类名 | 说明 |
|---|---|---|
| 状态栏 | `as-statusbar` | 高 44pt。左：时间（现实或剧情时间）；右：网络、电量、**关闭手机按钮**。可隐藏 |
| 顶栏 | `as-navbar` | 高 52pt。左：返回；中：标题；右：一个操作按钮（可选） |
| 大标题 | `as-largetitle` | 一级页面顶部的大标题，往上滚动时缩进顶栏 |
| 列表组 | `as-list-group` | 圆角卡片包住一组列表项，上方可带小标题 `__header`、下方可带说明 `__footer` |
| 列表项 | `as-list-item` | 高 ≥52pt。左：图标（可选）；中：标题 + 副标题；右：值 / 开关 / 箭头 |
| 开关 | `as-switch` | 打开时是强调色 |
| 分段选择 | `as-segmented` | 2~4 个选项并排，例如「日间 / 夜间 / 跟随系统」 |
| 滑块 | `as-slider` | 字号、音量、窗口大小 |
| 按钮 | `as-btn` | 变体：`--primary`（强调色实心）、`--secondary`（浅底）、`--text`（纯文字）、`--danger`（红） |
| 输入框 | `as-input` | 单行。密钥输入框带「显示 / 隐藏」小眼睛 |
| 多行编辑框 | `as-textarea` | 提示词编辑用，高度可自动增长 |
| 标签片 | `as-chip` | 例如提示词里的变量 `{{char}}`，点一下插入 |
| 底部抽屉 | `as-sheet` | 从底部升起，可拖动，有档位，拉过头会回弹 |
| 弹窗 | `as-dialog` | 居中的确认框。危险操作的弹窗带「输入确认」输入框 |
| 横幅通知 | `as-banner` | 从顶部滑下的消息提醒 |
| 轻提示 | `as-toast` | 底部的小提示条，例如「已保存」。出错时带「查看日志」按钮 |
| 红点 / 角标 | `as-badge` | 未读数，数字变化时滚动 |
| 头像 | `as-avatar` | 圆形 |
| 空状态 | `as-empty` | 列表为空时的插画 + 一句话 + 按钮 |
| 加载 | `as-loading` | 胶囊形加载条；按钮加载时变形成胶囊 |

## 5. 动效规则

1. **从哪来，回哪去**：点开的东西从它原来的位置长出来，关闭时缩回原位。
2. **用弹簧，不用匀速**：抽屉、弹窗、页面切换都带一点自然的减速或回弹。
3. **一按就有反馈**：所有能点的东西，按下时缩到 0.96 倍（`--as-dur-fast`），松手弹回。
4. **数字变化要滚动**：未读数、时间等数字像码表一样翻动。
5. **贵的效果省着用**：发光、模糊、粒子，一屏最多一处，只留给「特别时刻」（例如来电、AI 正在生成）。
6. **只动「位置、大小、透明度」**：这三样手机跑得动，其他属性尽量不做动画。
7. 手机系统开启了「减少动态效果」时，自动改成淡入淡出。

页面切换：新页面从右边滑入，旧页面向左挪一点并变暗；返回时反过来。

### 5.1 小巧思清单
主题是「小星星」，所以小巧思尽量和星光有关，但**一屏最多一个会发光的东西**。
标 ★ 的是「特别时刻」，允许用发光 / 粒子。

**全局**
- 从桌面点开 App：App 从图标的位置长出来；关闭时缩回图标。
- 横幅通知：从顶部带一点回弹落下，往上一划就收走。
- 未读数字：变化时像码表一样滚动。
- AI 正在生成的那一块：边框有一圈缓慢转动的暖橙光晕（★）。

**锁屏**
- 时钟：分钟变化时数字向上滚动翻页。
- 指纹按住：进度环沿圆圈填满；解锁瞬间迸出一小撮星星碎屑（★），壁纸从微微放大+模糊恢复清晰，像镜头对焦。
- 数字密码：每按一个数字，对应的小圆点「噗」地填满（轻微放大再回弹）；输错时整排圆点左右摇头。
- 手势密码：手指划过的线带一点拖尾；图案正确时，经过的点按顺序依次亮一下，像星座连线（★）。

**设置**
- 开关：圆钮滑过去时带一点点回弹。
- 日间 / 夜间切换：从你点的位置开始，一个圆圈向外扩散，新颜色跟着圆圈铺满屏幕。
- 字号滑块：上方预览文字跟着手指实时变大变小。
- 测试连接：按钮缩成胶囊转圈 → 成功时画出一个对勾 / 失败时左右摇头。
- 存储占用条：进入页面时从左往右长出来。
- 清空确认：输入正确「确认」前，「清空」按钮是灰的；输对的瞬间亮起。
- 彩蛋：在「关于」页连点 Aster 图标 7 次，下一场小小的流星雨（★）。

**聊天**
- 「发送」变「让 TA 回复」：按钮像水滴一样变形，图标换成一颗小星星。
- 「对方正在输入…」：三个小点轮流跳动。
- 新消息：气泡从下方带一点回弹冒出来；多条消息一条一条出现。
- 拍一拍：被拍的头像左右晃两下。
- 贴表情：表情从小弹到大落在气泡角上；同一个表情再有人贴，数字滚动 +1。
- 撤回：气泡缩小淡出，原地变成一行灰字。
- 红包：点开时封口翻转。
- 续火花：火苗图标轻轻摇曳；天数升级换图标时闪一下。
- 来自剧情的消息：角落一颗小星星 ✦。
- 动态点赞：爱心先缩一下再弹大，周围冒出几粒小光点。
- 动态下拉刷新：顶部一颗星星旋转。

## 6. 交互规则

### 6.1 返回
- 手指从屏幕左右边缘往里滑 → 返回上一页。页面**跟着手指走**，滑过三分之一或甩得够快就完成返回，否则弹回。
- 起滑区域离屏幕最边缘留一小段距离，避免触发浏览器自己的后退。
- 安卓系统自带的返回键 / 返回手势，同样等于「小手机里返回一步」。
- 返回的层级：子页面 → 上一页 → App 首页 → 桌面 → **在桌面再返回一次 = 关闭手机**。

### 6.2 打开 / 关闭手机
- 打开：酒馆页面上的悬浮按钮。
- 关闭：状态栏右上角的关闭按钮；或在桌面上再返回一次。
- 可选：在设置里勾选「连点三下开关手机」（**默认关闭**）。开启后，在酒馆页面任意空白处连点三下打开手机，在手机屏幕空白处连点三下关闭。

### 6.3 状态栏
- 时间可选现实时间或剧情时间。
- 是否显示：可以按主题设，也可以按每个 App 单独设。

### 6.4 头像手势（全手机统一）
- 单击任何人的头像 → 资料页。
- 聊天里双击头像 → 拍一拍（单击因此会等约 0.25 秒确认不是双击）。
- 群聊里长按头像 → @TA。
- 点自己的头像 → 我的主页。

### 6.5 出错
- 出错时弹轻提示，带「查看日志」按钮，直接跳到日志 App 里那条记录。

## 7. 皮肤规则

- 皮肤以**皮肤包**的形式存在，里面装三样：CSS（样子）、图片（图标、背景）、文案替换表（名字，见 2.6）。
- 皮肤只能通过**公开的门牌号**（第 2 节）、**变量**（第 3 节）和**文案编号**（2.6）来改。
- 皮肤的作用范围：整套主题 / 某个 App / 某个 App 的某一页（第一版只留口子，先做一套固定样式）。
- 导入、试用、套用、恢复默认都在**资源库**里。
- **恢复默认的按钮不受任何皮肤影响**；酒馆扩展面板里另有一个「紧急恢复」按钮作为双保险。

---

## 8. 全手机通用规矩

1. **一样东西只有一个家**：每个设置只在一个地方真正保存；别处只放「跟随全局 →」或快捷入口，点一下跳回它的家。
2. **越具体越优先**：本聊天 / 本群 ＞ 应用设置 ＞ 全局默认（头像、名字、时间、外观、API 等都适用）。
3. **没改过就跟随，改过就独立**：从酒馆加载来的内容，在 Aster 里没动过就跟着酒馆更新；改过就归 Aster，旁边标「已独立」+「重新跟随酒馆」。
4. **不花冤枉钱**：翻译、表情包识别必须免费；所有自动行为共用一个每日自动请求上限；能手动触发的默认手动触发。

## 9. 给画图模型的通用要求

1. 画布 **1170 × 2532**，只画屏幕内容，**不要画手机外壳**，平面截图的样子。
2. 界面文字用**简体中文**，放真实合理的内容，不要乱码或假字。
3. 每页都带顶部状态栏（时间、网络、电量、右上角关闭按钮），除非该页注明隐藏。
4. 严格使用第 3 节的颜色、圆角、字号；同一种积木在不同页面里必须长得一样。
5. 一张图只画一个页面的一种状态；需要多个状态的，分开画。
6. 默认画**日间**；清单里标注「+夜间」的，再画一张夜间版。
7. 图片存放路径和文件名，按页面清单文档里写的来。
8. 长页面（设置项很多的页面）可以画成两屏高（1170 × 5064）。

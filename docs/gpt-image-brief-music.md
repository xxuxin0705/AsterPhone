# 给画图模型的交接单：音乐 App

用法：在 GPT 里开一个新对话，**先把「总说明」整段发过去**，再一张一张发下面的提示词（一次一张）。
画好的图存成提示词标题里的文件名，丢回给 Claude。

分三步，**第一步画完先停**，挑好风格再往下画：
1. 定调子：唱片（玻璃 / 黑胶 / 自定义背景）、八音盒、热成像的播放页（看好不好看、风格对不对）。
2. 其余页面：一起听、灵动岛和锁屏、首页。（下雨天等作者自己的设计）
3. 素材：透明底的零件图（唱片、唱臂、盒子……），写代码时直接抠来用。

---

## 总说明（先发这一段）

```
你要帮我画一个手机音乐 App 的界面设计图。它是一个「小手机」网页插件里的音乐 App，这些图会被照着还原成网页，所以要画得干净、精确、统一。

通用要求：
- 竖屏手机截图，比例 9:19.5（例如 1170×2532）。只画屏幕内容，不要手机外壳、不要手、不要桌面背景。
- 界面文字全部简体中文，清楚、不乱码。字体用系统无衬线（类似苹方）。
- 顶部状态栏：左边时间「21:20」，右边信号、Wi-Fi、电量，最右边一个小小的关闭按钮（细线圆圈里一个 ×）。
- 整体审美：轻盈、通透、带一点梦幻的柔光。材质偏玻璃、透明塑料、珍珠白、细碎闪光；颜色明亮、低饱和、干净，像高级的产品渲染图加一点插画质感。不要廉价霓虹、不要脏灰、不要赛博朋克。
- 播放页的背景跟着专辑封面变色：用封面的主色做很淡的渐变，上面像蒙了一层白雾。
- 专辑封面一律画抽象插画（风景、光影、几何），不要真实歌手照片，不要任何品牌 logo、水印。
- 示例内容（所有图保持一致）：
  - 歌名《晚风信箱》，歌手「白昼」。
  - 歌词当前句「把落日折进信封里」（前 4 个字已经变成强调色，后面还是灰色，表示唱到一半），下一句「寄给还没醒的你」（灰色）。
  - 进度 1:42 / 3:56。
  - 我叫「林晚」，一起听的对象叫「周叙白」。
- 播放页下半部分在所有皮肤里都一样：
  1. 歌词两行（居中）。
  2. 一排细线小图标：喜欢（心形）、一起听（两个耳机）、歌词（一个「词」字）、更多（三个点）。
  3. 细进度条，下面两端小字时间。
  4. 控制按钮：随机、上一首、播放/暂停（最大）、下一首、播放列表。
- 播放页顶部：左边向下的箭头（收起），中间两行「晚风信箱 / 白昼」，右边分享图标。
- 一张图只画一个页面。有动效的地方，画出动效进行到一半的那一瞬间。

先不用画，回复「明白」，我一张一张发给你。
```

## 第一步：定调子（画完先停）

第一批定了 4 个皮肤（见 `pages-music.md` 第四节）。下雨天作者之后自己设计，这里先不画。

### `design/music/M1-record-glass.png` —— 唱片（玻璃）
```
画播放页，皮肤「唱片」，玻璃材质。参考网易云音乐的播放页：
中间偏上一张半透明的玻璃唱片，正面俯视，占屏幕宽度大约 80%：唱片本身是浅灰白的半透明玻璃，有几圈很淡的同心纹路，外圈有一圈柔和的光晕；唱片中间是很大的圆形专辑封面（占唱片直径大约 2/3，冷蓝色调的海边黄昏插画）。
唱片上方正中一支白色的细唱臂：顶端一个小圆形转轴，细长的臂往右下弯，末端一个小方块形的唱头，针落在唱片右上方（正在播放）。
背景：从封面取的淡蓝灰色渐变，蒙一层白雾，干净。
唱片正在慢慢转。
```

### `design/music/M2-record-vinyl.png` —— 唱片（黑胶）
```
和上一张一样的布局，只把唱片换成黑胶：深黑色，带细密的纹路和一道柔和的弧形高光；中间圆形封面是琥珀暖色调的落日插画。
背景：从封面取的淡咖啡色 / 琥珀色渐变，蒙一层薄雾，温暖但干净。
```

### `design/music/M3-record-custom-bg.png` —— 唱片（自定义背景）
```
和第一张玻璃唱片一样，只是背景换成一张用户自己选的插画：浅蓝色的海浪拍岸，天上几只白色海鸥，水面有闪光，整张图铺满全屏，颜色稍微压暗一点让文字看得清。玻璃唱片半透明，能隐约透出后面的海浪。
```

### `design/music/M4-musicbox.png` —— 八音盒
```
画播放页，皮肤「八音盒」。
中间偏下一个复古八音盒，正面略俯视：奶白色和浅木色的盒身，边角有细细的金色描边；盒盖向后打开，盖子内侧一面小镜子；盒子中间一个小摆件（原创的小兔子或小星星，不要任何知名角色）正在缓缓转圈。
歌词「把落日折进信封里」的字正一个一个从八音盒里飘出来：前几个字已经飘到八音盒上方的空中，排成一行，微微发着暖光；后面几个字还在从盒子里往上飘的半路上，有点透明、带一点点闪光拖尾。
背景：从封面取的淡蜜桃色渐变，蒙一层柔光，有一点点暖色光晕。
（这个皮肤的歌词主要飘在空中，下方的两行歌词可以淡一点。）
```

### `design/music/M5-thermal.png` —— 热成像
```
画播放页，皮肤「X 光热成像」。
整页是黑白的：背景是很深的黑色，带一点点星星点点的颗粒和淡淡的烟雾感。
中间是一盒磁带，画成 X 光片的样子：黑白、半透明，能看到里面的两个磁带轮、齿轮、螺丝和磁带，边缘有细细的白色高光，几颗四角星形的小闪光。磁带略微倾斜。
磁带右边的轮子那里正在「发热」：一团热成像颜色（中心红黄、外圈绿、再外面蓝）从轮子中心晕开，其余部分都是冷冷的黑白。
歌词「把落日折进信封里」：前 4 个字是热成像的彩色渐变（蓝绿黄红），像被加热了；后面的字是灰白色。下一句「寄给还没醒的你」是更暗的灰色。
左上角一行小字：中文「正在播放」，旁边一行细的英文斜体「Now Playing」。底部中间一行很小的字「✦ TAPE 01 / 03 ✦」。
整页除了发热的那团和歌词，不要任何其他颜色。按钮、进度条都是白色细线。
```

**第一步到这里停。** 画完丢回来，挑满意的风格，不满意的说哪里不好再改。

## 第二步：其余页面（风格定好之后再画）

### 一起听
2026-11-02 定了只用一种：有线耳机一人一只。用的图是作者让 GPT 画的黑底「两个空圆圈 + 外侧各一只有线耳塞」，去掉黑底、切成左右两半，在 `assets/music/together-l.webp` / `together-r.webp`。别的几种（戴耳机、歌词、心跳、红线）作者看了不要了。

### `assets/music/categories.png` —— 搜索页的分类卡片（一张图画完，代码里切开）
2026-11-02 作者定的：不要渐变，两边（本地酒馆 / Tauri）统一用这张图；卡片上的字由代码写，图里不要字。
```
画一张竖图（1024×1536），纯白背景，上面整齐排着 12 张横向的圆角卡片：2 列 × 6 行，每张卡片宽高比大约 2.2:1，卡片之间留出清楚的白色空隙（方便之后切开），卡片之间不要重叠、不要阴影连在一起。

每张卡片是一幅独立的小插画，代表一种音乐风格。统一画风：干净、有氛围感的插画 / 概念图，像音乐 App 的歌单分类封面；色调柔和、有质感，每张有自己的主色但整体协调。每张卡片的左下角留一块比较简单、偏暗的区域（之后会在那里写白色的分类名），主体放在右边或中间。
所有卡片里都不要出现任何文字、字母、数字、招牌字、logo、水印，也不要真实的明星或知名动漫角色（人物只画原创的、背影或剪影）。

从左到右、从上到下依次是：
1. 华语：夜晚的城市街角，暖黄色路灯，窗台上一台老式收音机
2. 欧美：黄昏的公路，一辆复古汽车，后座放着一把吉他
3. 日语：夏天的电车站台，蓝天白云，屋檐下挂着风铃
4. 韩语：粉紫色的舞台灯光，星星点点，一支立麦
5. 粤语：下雨的夜晚，霓虹灯光映在湿漉漉的街上，远处一辆双层电车（招牌上不要字）
6. 二次元：动漫画风的夜空和流星，一个原创角色站在天台上的背影
7. 古风：水墨山水，竹林里摆着一张古琴
8. 说唱：街头涂鸦墙（只要色块图案，不要字），一双球鞋和一台音箱
9. 民谣：星空下的草地，篝火旁靠着一把木吉他
10. 摇滚：舞台上的电吉他，红色灯光和烟雾
11. 电子：蓝紫色的霓虹几何图形，一台合成器键盘
12. 轻音乐：清晨的窗边，一架钢琴，白纱窗帘被风吹起
```

## 第三步：素材（透明底，写代码时抠来用）

```
接下来画一些素材图，要求：
- 透明背景的 PNG（如果做不到透明，就用纯白背景，四周留出足够空白，方便抠图）。
- 每张只画一个物件，物件居中，四周留白。
- 不要文字、不要 logo、不要水印。
- 光照统一从左上方来，只保留物件本身的高光和很淡的接触阴影。
- 尺寸 1024×1024。
```

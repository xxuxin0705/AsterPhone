# 给画图模型的交接单：音乐 App

用法：在 GPT 里开一个新对话，**先把「总说明」整段发过去**，再一张一张发下面的提示词（一次一张）。
画好的图存成提示词标题里的文件名，丢回给 Claude。

分三步，**第一步画完先停**，挑好风格再往下画：
1. 定调子：5 个皮肤的播放页，各一张（看好不好看、风格对不对）。
2. 其余页面：一起听、灵动岛和锁屏、首页。
3. 素材：透明底的零件图（唱片、唱臂、盒子……），写代码时直接抠来用。

---

## 总说明（先发这一段）

```
你要帮我画一个手机音乐 App 的界面设计图。它是一个「小手机」网页插件里的音乐 App，这些图会被照着还原成网页，所以要画得干净、精确、统一。

通用要求：
- 竖屏手机截图，比例 9:19.5（例如 1170×2532）。只画屏幕内容，不要手机外壳、不要手、不要桌面背景。
- 界面文字全部简体中文，清楚、不乱码。字体用系统无衬线（类似苹方）。
- 顶部状态栏：左边时间「21:20」，右边信号、Wi-Fi、电量，最右边一个小小的关闭按钮（细线圆圈里一个 ×）。
- 整体审美：轻盈、通透、带一点梦幻的柔光。材质偏玻璃、透明塑料、珍珠白、细碎闪光；颜色明亮、低饱和、干净，像高级的产品渲染图加一点插画质感。不要廉价霓虹、不要脏灰、不要赛博朋克。
- 播放页的背景跟着专辑封面变色：用封面的主色做很淡的渐变，上面像蒙了一层白雾。
- 专辑封面一律画抽象插画（风景、光影、几何），不要真实歌手照片，不要任何品牌 logo、水印。
- 示例内容（所有图保持一致）：
  - 歌名《晚风信箱》，歌手「白昼」。
  - 歌词当前句「把落日折进信封里」（前 4 个字已经变成强调色，后面还是灰色，表示唱到一半），下一句「寄给还没醒的你」（灰色）。
  - 进度 1:42 / 3:56。
  - 我叫「林晚」，一起听的对象叫「周叙白」。
- 播放页下半部分在所有皮肤里都一样：
  1. 歌词两行（居中）。
  2. 一排细线小图标：喜欢（心形）、一起听（两个耳机）、歌词（一个「词」字）、更多（三个点）。
  3. 细进度条，下面两端小字时间。
  4. 控制按钮：随机、上一首、播放/暂停（最大）、下一首、播放列表。
- 播放页顶部：左边向下的箭头（收起），中间两行「晚风信箱 / 白昼」，右边分享图标。
- 一张图只画一个页面。有动效的地方，画出动效进行到一半的那一瞬间。

先不用画，回复「明白」，我一张一张发给你。
```

## 第一步：定调子（5 张，画完先停）

### `design/music/M1-glass.png` —— 玻璃唱片（默认皮肤）
```
画播放页，皮肤「玻璃唱片」。
中间一张半透明的玻璃唱片，正面俯视，占屏幕宽度大约 75%：一圈圈透明的同心纹路，边缘有彩虹色的折射，上面撒满细碎的星屑闪光；唱片正中是圆形的专辑封面（冷蓝色调的海边黄昏插画）。
右上角一支透明的玻璃唱针，细细的，针头落在唱片外圈（正在播放）。
背景：从封面里取的淡蓝色渐变，上面像蒙了白雾，很干净。
唱片正在慢慢转，画出转动中的一瞬间。
```

### `design/music/M2-vinyl.png` —— 黑胶唱片
```
画播放页，皮肤「黑胶唱片」。
中间一张深黑色黑胶唱片，正面俯视略带一点点透视，占屏幕宽度大约 75%：密密的纹路，被暖色灯光照出一道弧形高光；中间圆形标签是专辑封面（琥珀暖橙色调的落日插画）。
右上角一支精致的银色金属唱臂，针头落在唱片外圈。
背景：从封面取的淡琥珀色渐变，蒙一层奶白色的雾，整体温暖复古但干净，不要做旧脏污。
```

### `design/music/M3-cd.png` —— 透明 CD 盒
```
画播放页，皮肤「透明 CD 盒」。
中间一个 Y2K 风格的透明塑料 CD 盒，略微倾斜（像被手拿着往左转了 10 度），盒盖向左打开了一半，能看到透明塑料的厚度和边缘的高光反光。
盒子里一张镭射 CD，表面有彩虹色的镭射光泽，上面贴着 5～6 张可爱的小贴纸（星星、爱心、云朵、音符、小信封，都是原创图案，不要任何品牌和文字 logo），CD 中心是透明的圆环卡扣。
背景：从 CD 的粉紫色调取的淡色渐变，蒙白雾。
CD 正在盒子里慢慢转。
```

### `design/music/M4-musicbox.png` —— 八音盒
```
画播放页，皮肤「八音盒」。
中间一个复古八音盒，正面略俯视的角度：奶白色和浅木色的盒身，边角有细细的金色描边；盒盖向后打开，盖子内侧是一面小镜子；盒子中间立着一个小摆件（一只抽象的小兔子或一颗小星星，原创，不要任何知名角色），正在缓缓转圈；盒子前面能看到一部分黄铜滚筒和上面的小凸点。
盒子右侧，一条打孔纸带正被慢慢吐出来，纸带上印着当前这句歌词「把落日折进信封里」，字已经印出一半。
背景：从封面取的淡蜜桃色渐变，蒙一层柔光，有一点点暖色光晕。
（这个皮肤的歌词主要在纸带上，下方的两行歌词可以淡一点。）
```

### `design/music/M5-rain.png` —— 下雨天落字
```
画播放页，皮肤「下雨天落字」。
整个上半屏是一扇窗：夜里，窗外是虚化的城市灯光（冷蓝色和暖橘色的圆形光斑），玻璃上有大大小小的雨滴和往下流的水痕，玻璃边缘有一点雾气。
歌词「把落日折进信封里」的字像雨滴一样一个一个从上面落下来：前几个字已经落到窗台上排成一行，后面几个字还在半空中往下掉，掉落的字带一点水滴的透明感。
窗台下方左边放着一张小小的专辑封面（灰蓝色调的雨夜插画），像一张拍立得照片斜靠着。
整体安静、冷色调、带一点暖光点缀，干净不压抑。
```

**第一步到这里停。** 5 张画完丢回来，挑满意的风格，不满意的说哪里不好再改。

## 第二步：其余页面（风格定好之后再画）

### 一起听（每个皮肤一张）
```
画播放页「一起听」状态，皮肤用【填皮肤名】，其余和这个皮肤的播放页保持一致。
```

# 商业街 · 照相馆

## 商业街（apps/street/street.js）
- 从旧小手机 X_XPhone 原样搬过来：代码画的马卡龙小街，横着滑；大头贴、一番赏、烘焙店、娃娃机四家现在只有样子（点了「準備中」）。
- 最右边原来的「敬请期待」空铺换成照相馆（同样的画法：薄荷墙、屋顶一台大相机、橱窗里挂着一张立绘相框）；底下的导航多一格「照相馆」。
- 大头贴是大头贴，和立绘没关系。

## 照相馆（apps/street/studio.js、core/portrait.js）
- 挑一个联系人 → 参考图（默认用头像，可以换一张，也可以不用、只按描述画）+ 描述 → 画一张标准立绘（正面半身、白底）→ 「重画」或「用这张」。用这张时把白底去掉。
- 有了立绘再勾要哪些表情（张嘴、闭眼、O 型嘴、笑眼、生气、为难、脸红；默认勾张嘴和闭眼，也可以一个都不要），一个一个画；以后随时补。点已经有的表情，立绘上会亮一下给你看。
- 做法：让生图线照着立绘画「只改一处」的变体，在手机里比对两张图，把变了的那一小块抠出来存成小图 + 位置；播放时叠在立绘上换着显示 = 眨眼、说话动嘴、换表情，再加一点呼吸。
- 只有能「照着图改」的生图渠道能用：OpenAI / 第三方（edits 接口或聊天接口带图）、硅基流动的改图模型；别的渠道会直接说不行。
- 同一时间只做一件事；退出再进来还能看到进度和「取消」。
- 用到立绘的地方：幕间的人物牌（站着出来，会眨眼，念台词时动嘴，AI 给的表情会换上）。没做立绘的人还是头像。以后视频电话、电台也要用。

# 商业街 · 照相馆

## 商业街（apps/street/street.js）
- 从旧小手机 X_XPhone 原样搬过来：代码画的马卡龙小街，横着滑；大头贴、一番赏、烘焙店、娃娃机四家现在只有样子（点了「準備中」）。
- 最右边原来的「敬请期待」空铺换成照相馆（同样的画法：薄荷墙、屋顶一台大相机、橱窗里挂着一张立绘相框）；底下的导航多一格「照相馆」。
- 大头贴是大头贴，和立绘没关系。

## 照相馆（apps/street/studio.js、core/portrait.js）
- 挑一个人（列表最上面是你自己，下面是联系人）→ 参考图（默认用头像，可以从相册选一张，原图不裁；也可以不用、只按描述画）+ 描述 → 画一张标准立绘（正面半身、白底、竖图：OpenAI / 第三方 1024×1536，硅基流动 768×1024，其他 832×1216，不管这根线平时设的尺寸）→ 「重画」或「用这张」。用这张时把白底去掉。
- 有了立绘再勾要哪些表情（张嘴、闭眼、O 型嘴、笑眼、生气、为难、脸红；默认勾张嘴和闭眼，也可以一个都不要），一个一个画；以后随时补。点已经有的表情，立绘上会亮一下给你看。
- 做法：让生图线照着立绘画「只改一处」的变体，在手机里比对两张图，把变了的那一小块抠出来存成小图 + 位置；播放时叠在立绘上换着显示 = 眨眼、说话动嘴、换表情，再加一点呼吸。
- 只有能「照着图改」的生图渠道能用：OpenAI / 第三方（edits 接口或聊天接口带图）、硅基流动的改图模型、NAI；别的渠道会直接说不行。
- NAI 的做法不一样：
  - 立绘：参考图走 NAI 4.5 的「角色参考」（认人和画风，构图按提示词重新画，所以海报里的字、背景、裁掉的身子都不会照搬）；提示词用标签（正面半身、白底…）。不是 4.5 的模型会说要换 4.5。
  - 表情：用「局部重绘」只重画一小块，框外一点不动。第一次做表情前，在立绘上框一下眼睛（连眉毛）、再框一下嘴，记在立绘里；脸红重画两个框连起来那一片；框错了在表情列表最下面「眼睛和嘴的位置」重新框。
  - 中转站认不认角色参考、局部重绘，看中转站。
- 同一时间只做一件事；退出再进来还能看到进度和「取消」。
- 生图用默认的生图线（作者定的）。
- 用到立绘的地方：幕间的人物牌（站着出来，会眨眼，念台词时动嘴，AI 给的表情会换上）；电台讲故事时站在画面左边、出声时动嘴。没做立绘的人还是头像。以后视频电话也要用。

  - 框改成三个：左眼、右眼、嘴（只框眼睛本身，不用带眉毛；NAI 重画眼睛时自动往上带上眉毛）。框过的留在图上；框的那层不会被当成「滑动返回」。
- v0.8.196 「手机里画」改好看：不再画黑线和卡通嘴，改成照 Mesh Avatar Studio 不生图时「眼睛、嘴靠网格变形」的思路，用原画自己的线：
  - 闭眼 / 笑眼：拿原画的上睫毛那一条，眼睛抹平后把睫毛压扁挪到闭眼的位置（闭眼往下弯、笑眼往上拱），颜色粗细都是原画的。
  - 张嘴 / O 型嘴：原来的嘴线留着当上嘴唇，从它往下拉开一个嘴，里面用线色调深红、底下一点舌头，下嘴唇用同色细线。
  - 抹平：从四周的皮肤色按行按列渐变过去再磨匀；头发、眉毛这些深色的不当皮肤色用，也不抹掉。
- v0.8.197 「手机里画」的闭眼、笑眼、脸红改用贴纸：作者用 GPT 画了一批眼睛 / 腮红素材（白底），抠成透明的放在 `assets/portrait/`（closed / smile / blush 各左右一张）。眼睛先抹平再贴，贴纸按框好的眼睛大小缩放，跟着两只眼睛的连线转（头歪也对得上）；脸红贴在眼睛和嘴中间。原来「拿原画睫毛压扁」的做法去掉了。嘴还是用原画嘴线拉开。
- v0.8.198 作者看了改：
  - 笑眼不用带泪痕的那对了（作者打叉的两组不用），改成拿闭眼贴纸中间往上拱成弧。
  - 贴纸里的睫毛换成这个人自己的睫毛色（眼睛框里最深那一小撮的平均），眼泪、高光这些浅的、偏蓝的不换。
  - 脸红、闭眼的位置沿「脸的方向」挪（头歪着也左右对称）；抹眼睛左右不出框（框外可能是头发），贴纸小一点不出眼睛。
  - 新表情（手机里画、AI 画都有）：哭（闭眼 + 眼泪）、大哭（> < + 两道泪）、> <（笑到眯眼）、汗（眼睛外上方两滴汗）。幕间 AI 的表情多了 cry / wail / laugh / nervous；有眼睛类表情的时候不眨眼。
- v0.8.199 表情宫格（作者的主意）：一次生成就出全部表情。
  - 把立绘的脸部特写（两眼和嘴的中间为中心、边长约两眼外侧距离 1.3 倍的正方形）发给 GPT，让它画 4×3、12 格的表情宫格（第 1 格平常脸，后面依次：闭眼、张嘴、O 型嘴、笑眼、生气、为难、脸红、哭、大哭、> <、汗）。
  - 手机里按白色分隔线切格（找不到就按 4×3 均分）→ 每格先当它就是发出去的那块脸，在小图上试一点点缩放和挪动找最像的位置 → 拿要换的那块四周一圈比色差、整块校色 → 按区域抠（眼睛、嘴、整张脸），边上渐隐不留方框。只留勾了的。
  - 两种用法：AI 画（OpenAI 官方 / 第三方这类能照图改的线，一次调用）；「用自己的 GPT 画」：弹出脸部特写（长按存图）+ 复制提示词，画好的宫格上传回来切。NAI 还是一个个局部重绘。
  - 拿作者发来的 miko 宫格试过：12 格都对上了。
- v0.8.199 眼镜：手机里画时，表情列表里「眼镜」→ 框左右两片镜片。画闭眼 / 脸红这些时先存下镜片，贴完再盖回：镜框照原样，镜片里盖一层镜片色（取镜片下半圈的平均）。墨镜盖得重（闭眼隐约透出），透明镜片盖得轻。

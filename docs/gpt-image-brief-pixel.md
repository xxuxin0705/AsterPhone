# 给画图模型的交接单：幕间 · 像素战斗

战斗时，对话框上面那块变成一条横的像素小擂台：调查员站左边（脸朝右），怪站右边（脸朝左），回合制对打。
画风照《星露谷物语》。特效（刀光、枪火、伤害数字）由代码画（pixelfx，MIT），不用画；背景用场景照片由代码像素化，也不用画。

用法：在 GPT 里开一个新对话，**先把「总说明」整段发过去**，再一张一张发下面的提示词。
画好的图存成提示词标题里的文件名，丢回给 Claude，Claude 负责把它收拾成规整的像素格、切帧、换色。

分两步，**第一步画完先停**，看风格对不对再往下画：
1. 定调子：一个小人模板（短发）+ 一只怪（邪教徒）。
2. 其余：别的小人模板、别的怪。

---

## 总说明（先发这一段）

```
你要帮我画一个手机游戏里的像素小人和像素怪物，用在回合制战斗画面里。

画风（所有图都一样）：
- 像《星露谷物语》：真正的像素画，暖色、可爱但不幼稚，轮廓用深棕色（不要纯黑）。
- 每个像素是一个实心方块：不要抗锯齿、不要渐变、不要模糊、不要发光、不要阴影投在地上。
- 每个小人 / 怪物用的颜色不超过 16 种。
- 侧面朝向：小人一律脸朝右，怪物一律脸朝左。
- 透明背景（PNG）。不要任何文字、数字、logo、水印、格子线、边框。
- 不要任何真实的人、知名角色、知名品牌。

因为图很小，请「放大 8 倍画」：每个像素画成 8×8 的实心方块，所有方块对齐同一张网格。

换色用的固定颜色（非常重要，一定要用这几个色号，代码会把它们换成玩家挑的颜色）：
- 头发：#FF00FF（中间色）、#B000B0（暗部）、#FF80FF（亮部）
- 眼睛：#00FFFF
- 上衣：#00FF00（中间色）、#008000（暗部）、#80FF80（亮部）
- 下装（裤子 / 裙子）：#0000FF（中间色）、#000080（暗部）、#8080FF（亮部）
- 怪物的身体主色：#FF00FF（中间色）、#B000B0（暗部）、#FF80FF（亮部）
其他地方（皮肤、鞋子、轮廓、武器、怪物的眼睛和牙齿）用正常的颜色，不要用到上面这些色号。

先不用画，回复「明白」。
```

## 小人模板（每张一个发型 / 体型）

每张图：**1024×1024，分成 4 列 × 2 行，每格 256×256**，一格一帧，从左到右、从上到下：
1. 站着 1　2. 站着 2（呼吸，身体上下差 1 个像素）　3. 蓄力（往后收手）　4. 出手（手伸到最前面）
5. 收招　6. 挨打（往后仰）　7. 闪开（往后跳半步）　8. 倒地（侧躺）

小人本身是 **16×32 像素**（放大 8 倍后 128×256），站在每格正中间，脚踩格子的底边。倒地那帧躺平，也贴着底边。
出手那帧手里不拿东西（刀光、枪火由代码加），手伸到最前面。

## 怪物

普通大小的怪：**32×32 像素**（放大 8 倍后 256×256）。图 **1024×1024，4 列 × 2 行，每格 256×256**，前 6 格依次是：
1. 站着 1　2. 站着 2　3. 出手 1（蓄力）　4. 出手 2（扑 / 砍出去）　5. 挨打　6. 倒地
后 2 格空着。怪物脸朝左，脚（或身体底部）贴着格子底边。

大型怪：**48×48 像素**（放大 8 倍后 384×384）。图 **1536×1024，3 列 × 2 行，每格 512×512**，6 格顺序同上，怪物在格子正中、贴着底边。

身体主色一律用 #FF00FF 这一组（代码会换成 KP 给它定的颜色），眼睛、牙齿、武器用正常颜色。

```
怪物 32×32 像素、放大 8 倍画，脸朝左，站在每格正中、脚踩格子底边。
```

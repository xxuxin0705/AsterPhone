# 给画图模型的交接单：幕间 · 像素战斗（人模换装 + 怪物）

战斗时，场景照片下半部分变成像素擂台：调查员在左边斜着排（脸朝右），怪在右边斜着排（脸朝左），上面的离中间近、小一点（远处），下面的离两边近、大一点（近处），轮到谁谁走到中间出手。
画风照《星露谷物语》的 Q 版大头小人。动作（呼吸、出手、挨打、倒地）由代码做，特效（刀光、枪火、伤害数字）由代码画（pixelfx，MIT），**每样东西只画站着的样子**。
人物是「人模 + 换装」：先画男、女两个人模，再在人模身上一件一件画头发、衣服、表情、鞋子，Claude 用代码把每一件抠成单独的一层，玩家在商业街的服装店里搭配。

用法：在 GPT 里开一个新对话，**先把「总说明」整段发过去**，再一张一张发下面的提示词。
画好的图存成提示词标题里的文件名，丢回给 Claude，Claude 负责把它收拾成规整的像素格、抠成单独一层、换色。

分三步，**每一步画完先停**，看对不对再往下画：
1. 两个人模（男、女）。
2. 用人模试一件：一款头发、一套衣服、一个表情、一双鞋（Claude 先试抠，确认能对齐）。
3. 其余的头发、衣服、表情、鞋子，还有怪物。

---

## 总说明（先发这一段）

```
你要帮我画一个手机游戏里的像素小人（换装用）和像素怪物，用在回合制战斗画面里。

画风（所有图都一样）：
- 像《星露谷物语》的 Q 版小人：头大（头差不多占身高的一半）、身子小，眼睛有高光，配色柔和（奶茶色、雾粉、浅蓝这类），轮廓用深棕色（不要纯黑）。
- 真正的像素画：每个像素是一个实心方块，不要抗锯齿、不要渐变、不要模糊、不要发光、不要地上的影子。
- 每个小人 / 怪物用的颜色不超过 16 种。
- 透明背景（PNG）。不要任何文字、数字、logo、水印、格子线、边框。
- 不要任何真实的人、知名角色、知名品牌。

尺寸：小人本身是 16×32 像素。因为太小，请「放大 16 倍画」：每个像素画成 16×16 的实心方块，所有方块对齐同一张网格，所以小人在图上是 256×512。

每张小人图都是 1024×1024：左半边（512 宽）画正面，右半边（512 宽）画侧面（脸朝右）。小人站在每半边的正中间，脚踩在离图片下边 128 像素的那条线上。

换色用的固定颜色（非常重要，一定要用这几个色号，代码会把它们换成玩家挑的颜色）：
- 头发：#FF00FF（中间色）、#B000B0（暗部）、#FF80FF（亮部）
- 眼睛（瞳孔的颜色）：#00FFFF
- 衣服的主色：#00FF00（中间色）、#008000（暗部）、#80FF80（亮部）
- 衣服的第二颜色（裙子、裤子、外套里衬，没有就不用）：#0000FF（中间色）、#000080（暗部）、#8080FF（亮部）
- 鞋子的主色：#FFFF00（中间色）、#A0A000（暗部）、#FFFF80（亮部）
- 怪物的身体主色：#FF00FF（中间色）、#B000B0（暗部）、#FF80FF（亮部）
衣服上的花边、蝴蝶结、纽扣、格纹的细线这些细节用正常的颜色，保持不变；皮肤、轮廓、眼白、嘴也用正常的颜色。不要把上面这些色号用在别的地方。

先不用画，回复「明白」。
```

## 第一步：人模（画完先停）

人模就像服装店里的假人模特，但比例是 Q 版小人：**没有头发（光头）、脸上没有五官（眼睛、眉毛、嘴都不画）**，穿一身贴身的浅灰色打底（短袖、短裤），光脚。站姿：双手自然垂在身体两边，两脚稍微分开。

### `assets/interlude/px/base-f.png` —— 女生人模
```
画一个像素小人的人模（女生体型）：Q 版大头小身子，没有头发（光头），脸上没有五官，穿一身贴身的浅灰色短袖短裤打底，光脚，双手自然垂下，两脚稍微分开。
1024×1024 透明背景：左半边画正面，右半边画侧面（脸朝右）。小人 16×32 像素、放大 16 倍画，站在每半边正中间，脚踩在离下边 128 像素的线上。
```

### `assets/interlude/px/base-m.png` —— 男生人模
```
照上一张的样子和位置，画男生体型的人模：肩膀宽一点、腰直一点，其他（光头、没有五官、浅灰色打底、光脚、姿势、位置、大小）都一样。
```

## 第二步、第三步：在人模身上画一件东西

**每一张都要把对应的人模图一起发给 GPT**，用下面这个固定的说法，只改「穿上什么」那一句：

```
附件是我的像素人模。请在这个人模身上【穿上 / 加上：……】，用总说明里的换色色号。
别的地方一点都不要改：人模的位置、大小、姿势、轮廓、每一个像素都保持原样，正面和侧面都要画。只画这一件，不要顺手加别的东西（比如画头发时不要画五官、不要换衣服）。
```

男女各用自己的人模画一份（衣服、鞋子男女通用的，就各画一次）。文件名后面加 `-f` / `-m`，比如 `hair-bob-f.png`。

### 头发（头发全部用 #FF00FF 这一组）
- `hair-bob` —— 齐肩短发，有刘海
- `hair-long` —— 长直发，披到背
- `hair-ponytail` —— 高马尾
- `hair-twin` —— 双马尾
- `hair-bun` —— 头顶丸子头
- `hair-short` —— 男生短碎发
- `hair-buzz` —— 寸头
- `hair-wavy` —— 卷发，到肩膀
（第二步先画 `hair-bob`。想要别的发型直接加一行。）

### 衣服（主色用 #00FF00 这一组，裙子 / 裤子用 #0000FF 这一组，细节用正常颜色）
- `fit-uniform` —— 学生制服：西装外套 + 衬衫领口 + 领结 + 百褶裙（男生是长裤）
- `fit-sweater` —— 宽松毛衣 + 格子短裙（男生是休闲裤），毛衣领口露一点白衬衫
- `fit-coat` —— 及膝大衣，腰带，领口有毛边
- `fit-dress` —— 连衣裙，泡泡袖，胸前一个蝴蝶结
- `fit-hoodie` —— 连帽卫衣 + 工装裤
- `fit-detective` —— 侦探风：风衣 + 衬衫 + 吊带裤
（第二步先画 `fit-uniform`。）

### 表情（只画五官：眉毛、眼睛、嘴、脸红；瞳孔用 #00FFFF）
- `face-calm` —— 平常
- `face-smile` —— 笑（眼睛弯）
- `face-cool` —— 冷淡（半睁眼）
- `face-shy` —— 害羞（脸红）
- `face-angry` —— 生气（皱眉）
- `face-sad` —— 难过（下垂眼）
（第二步先画 `face-calm`。）

### 鞋子（主色用 #FFFF00 这一组）
- `shoe-sneaker` —— 运动鞋
- `shoe-loafer` —— 小皮鞋 + 白袜子
- `shoe-boot` —— 短靴
（第二步先画 `shoe-loafer`。）

## 怪物（第三步）

怪物不换装，**每只画一张，只画侧面站着的样子（脸朝左）**，身体主色用 #FF00FF 这一组（代码会换成 KP 给它定的颜色），眼睛、牙齿、武器用正常颜色。
普通大小的怪 32×32 像素、放大 16 倍画（512×512），大型怪 48×48 像素、放大 16 倍画（768×768）。都画在 1024×1024 透明背景的正中间，脚（或身体底部）踩在离下边 128 像素的线上。

```
画一张像素怪物：【描述】。身体主色用 #FF00FF 这一组颜色。
1024×1024 透明背景，只画侧面站着的样子，脸朝左。怪物【32×32 / 48×48】像素、放大 16 倍画，在图片正中间，脚踩在离下边 128 像素的线上。
```

普通大小（32×32）：
- `foe-cultist` —— 邪教徒：兜帽长袍、弯匕首、只露出发光的眼睛
- `foe-hound` —— 野狗 / 怪犬：四条腿、瘦长、龇牙
- `foe-deepone` —— 深潜者：鱼头人身、蹼爪、鳃
- `foe-ghost` —— 幽灵：飘着的人形，下半身是烟
- `foe-swarm` —— 虫群：一团飞虫聚成的形状
- `foe-ghoul` —— 尸鬼：佝偻、长爪、像狗的脸
- `foe-thug` —— 打手：普通人类、拿棍子

大型（48×48）：
- `foe-tentacle` —— 触手怪：地上冒出来的一团，好几条触手
- `foe-shoggoth` —— 修格斯：一大团黏糊糊的东西，身上很多眼睛和嘴

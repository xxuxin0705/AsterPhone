# 日记 App 方案（2026-11-05 和作者定的）

代码、图都自己做（sasshi、同页都是 AGPL，不借）。素材在 `phone/assets/diary/`。

## 一、是什么
- **角色的日记**：用 TA 自己的口吻、第一人称写。一个角色一本，躺在书桌上（白天 / 夜里跟着手机的深色模式换桌子，只靠 CSS 跟着变；桌子用原图，靠左上对齐，窗户不裁掉）。
- **翻开**（2026-11-05 作者要的，参考 sasshi 的书桌）：点一本 → 它从桌上立起来、封面绕书脊翻开 → 停在最新一篇；往左拖翻下一页，往右拖翻回上一页（拖过一小半就翻过去）；左上角返回 = 合上，书躺回桌上。手机上一次看一页，不做对开两页（太小看不清）。名字写在封面的小标签上。
- 本子：8 种封面、3 种纸（横线 / 点点 / 白纸）、什么时候写，都在本子的设置里，随时能换；能删（里面的日记一起删）。

## 二、什么时候写（每本单独选）
1. **跟着剧情**：每几楼写一篇（1 就是每楼都写）。轮到的那一楼，让正文 AI 在回复最后顺手写 `<asterdiary from="名字">…</asterdiary>`，不多花一次 API；换了 swipe 就换成新的那篇。
2. **只手动写**。
- （2026-11-05 作者改的：去掉了「值得写才写」。）
- 手动「写一篇」：写最近的事（正文 + 手机里和 TA 的聊天）/ 从念念铃挑几件事 / 选几层正文。用「文字」线，能取消，退出再进来按钮还是「取消」。写完不自动生图（2026-11-05 作者定的）：只写画面和生图提示词，点了「生图」才生。
- 写之前可以先放几张自己的照片（最多 4 张）：放了就不生图，第一张进大框，其余的贴成小邮票。

## 三、一页
- 年月日、星期、时间；天气贴纸（蜡笔那套，15 种）。
- 配图：不管自动写还是手动写，都只显示「画面」和「生图提示词」，点一下能生图 / 上传；有图了能重新生图 / 换一张 / 删除。
- 三种排版（参考手帐的「贴 + 便」）：拍立得在上 / 邮票贴在右边、字绕着走 / 小拍立得 + 便签；每篇默认按自己定一种，「…」里能换。
- **主题色**（2026-11-05 作者改的：只要淡淡的颜色、去掉压花）：AI 写的时候按剧情从主题色里挑一个（`主题色：名字`，二十四节气春季色 + Vainny 色卡），胶带、蕾丝、蕾丝小物、邮票框、便签都换成它的淡色；「…」→ 换主题色，能点现成的，也能自己调。天气、季节贴纸、拍立得、照片不换色。
- **贴纸**：顶上一条胶带、正文后面一个蕾丝小物、按季节天气贴的雪花（冬天 / 下雪）/ 樱花瓣（春天）/ 枫叶（秋天）、自己多放的照片。都能拖、两根手指缩放旋转（电脑上滚轮缩放、Shift + 滚轮旋转），点一下能删；动过就整页记住。「…」→ 加贴纸 / 多贴几张照片。配图那张大照片和排版绑着，不拖。
- **字体**：每本选一个。内置：小赖、悠哉、猫啃珠圆、千图笔锋手写、霞鹜文楷（中文网字计划，选中才下载）；资源库 → 字体里导入的也能选。

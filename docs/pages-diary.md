# 日记 App 方案（2026-11-05 和作者定的）

代码、图都自己做（sasshi、同页都是 AGPL，不借）。素材在 `phone/assets/diary/`。

## 一、是什么
- **角色的日记**：用 TA 自己的口吻、第一人称写。一个角色一本，摆在书桌上（白天 / 夜里跟着手机的深色模式换桌子）。
- 本子：8 种封面、3 种纸（横线 / 点点 / 白纸）、什么时候写，都在本子的设置里，随时能换；能删（里面的日记一起删）。

## 二、什么时候写（每本单独选）
1. **每次都写**：正文每一楼都写一篇（一楼一篇）。
2. **值得写才写**：正文里有 TA 想写的事才写。
3. **只手动写**。
- 1、2 都是让正文 AI 在回复最后顺手写 `<asterdiary from="名字">…</asterdiary>`，不多花一次 API；换了 swipe 就换成新的那篇。
- 手动「写一篇」：能从念念铃里挑几件事让 TA 写；不挑就按最近的正文 + 手机里和 TA 的聊天写。用「文字」线，写完接着配图；能取消，退出再进来按钮还是「取消」。

## 三、一页
- 年月日、星期、时间；天气贴纸（蜡笔那套，15 种）。
- 配图：自动写的只显示「画面」和「生图提示词」，点一下能生图 / 上传；有图了能重新生图 / 换一张 / 删除。手动写的写完自动生一张。
- 三种排版（参考手帐的「贴 + 便」）：拍立得在上 / 邮票贴在右边、字绕着走 / 小拍立得 + 便签；每篇默认按自己定一种，「…」里能换。
- 胶带、干花随手贴一样；同一篇每次贴得一样。

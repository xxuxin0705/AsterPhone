# 给画图模型的交接单：记忆 App「挂念」

用法：在 GPT 里开一个新对话，**先把「总说明」整段发过去**，再一张一张发下面的提示词（一次一张）。
画好的图存成提示词标题里的文件名，丢回给 Claude。

分两步，**第一步画完先停**，看好了再往下画：
1. 四季的树（同一棵树换季节）。树要当底图一直用，挂牌子的位置要对得上，所以**四张必须是同一棵树、同一个构图**。
2. 透明底的小零件：牌子、结、灯笼……写代码时抠出来挂到树上。

---

## 总说明（先发这一段）

```
你要帮我画一个手机 App 的素材图。这个 App 里，每个人物有一棵「许愿树」，树枝上挂着一块块祈福牌，每块牌子是一段回忆。这些图会被切下来放进网页，所以要干净、统一。

通用要求：
- 风格：真实摄影，不是插画。阳光明亮、颜色饱满清透、蓝天白云，像风光摄影师拍的四季树照片。不要阴沉、不要灰暗、不要滤镜感太重。
- 不要任何文字、水印、logo、人物、动物。
- 树的照片用竖屏手机比例 9:19.5（例如 1170×2532）。
- 透明底的零件：PNG，背景完全透明，零件居中，四周留一点空，不要阴影落在地上。

先不用画，回复「明白」，我一张一张发给你。
```

```

树枝向左右和上方舒展开，枝条之间要有空隙（之后要在枝上挂很多祈福牌）：至少有 6～8 根比较平、比较粗的横枝，分布在画面不同高度，枝下面留出空间。
夏天：满树嫩绿、透光的叶子，阳光从叶子缝里透下来，背景是晴朗的蓝天。树下是一片青草。
画面最下面 1/5 比较简单（草地），之后要放文字。
```

## 第二步：零件（透明底）

每张一个零件，正面平视，挂绳的顶端在零件正上方中间（代码要从这一点把它挂到树枝上）。
风格和树一样走真实质感（真实的木纹、玉、丝绳），不要卡通。

### `design/memory/P-tag-s.png` —— 小木牌
```
透明底 PNG。一块小小的长方形木质祈福牌（日本绘马 / 寺庙许愿牌那种），浅色原木，上面一个圆角，顶部一个小孔，穿着一根细红绳往上系成一个圈。牌面空白，没有字。
```

### `design/memory/P-tag-l.png` —— 大木牌
```
透明底 PNG。和小木牌同一种木头、同一种红绳，但更大一些，形状是上端尖起的五边形（绘马的样子），边缘有一圈细细的深色描边。牌面空白，没有字。
```

### `design/memory/P-jade.png` —— 玉牌
```
透明底 PNG。一块椭圆形的白玉牌，温润、半透明，有淡淡的光泽，边缘浅浅的雕花。顶部系着红色丝绳，下面坠着一束红色丝穗。牌面空白，没有字。
```

### `design/memory/P-blank.png` —— 空白牌（没完的事）
```
透明底 PNG。和小木牌一样，但木头颜色更浅，像刚削好、还没用过；红绳已经系好。牌面空白。
```

### `design/memory/P-loop.png` —— 空绳圈（撤回）
```
透明底 PNG。一小段红绳在树枝上系成的空圈，下面什么都没挂，绳尾微微垂着。
```

### `design/memory/P-tassel.png` —— 红穗子（钉住）
```
透明底 PNG。一小束红色丝穗，顶上有一个小小的金色珠子，从上往下垂。
```

### `design/memory/P-lantern.png` —— 小灯笼（特殊日子）
```
透明底 PNG。一盏小小的红色纸灯笼，圆形，上下各有一圈金边，底下坠一束短短的红穗，顶上一根红绳。灯笼里面透出暖暖的光。
```

### 结：`design/memory/K-*.png` —— 六种结（各一张）
```
透明底 PNG。一个用红色丝绳编的小结，正面平视，结的上方留一段绳往上（挂到牌子绳上用）。真实的丝绳质感。
```
每张把最后换成下面一种（文件名照括号里的）：
- 同心结（`K-tongxin.png`，恋人）：两个环套在一起的同心结。
- 蝴蝶结（`K-hudie.png`，暧昧）：红丝绳打的蝴蝶结。
- 吉祥结（`K-jixiang.png`，家人）：七个耳翼的吉祥结。
- 平安结（`K-pingan.png`，朋友）：圆圆的平安结。
- 死结（`K-si.png`，对手 / 敌人）：拉得很紧的死结，颜色偏暗红。
- 单结（`K-dan.png`，其他）：普通的单结。

# 给画图模型的交接单：记忆 App「银河纪」

夜海 / 银河的场景用代码画，不用出图。要出图的只有漂在河里的灯（透明底，抠出来用）。
（之前「念念树」四季树、牌子、结的提示词已经不用了，2026-11-03 作者改成银河纪。）

## 河灯：`design/memory/lantern.png`

用法：在 GPT 里发下面这段（在画过糖果色云朵树的那个对话里发，画风更统一）。画好丢回给 Claude。

```
画一盏河灯的素材图，透明底 PNG（背景必须是真正的透明，不要白底，也不要灰白格子）。

样子：一朵小小的莲花形河灯，从斜上方大约 30 度往下看。花瓣是乳白色、半透明的，像珍珠和磨砂玻璃，花瓣边缘泛着柔和的虹彩，像肥皂泡那样淡粉、淡紫、薄荷绿、浅蓝慢慢渐变。花心里有一团柔和的暖白色光，从花瓣里透出来，整朵花微微发亮，边缘有一圈很淡的光晕。花底下托着一片小小的圆形浅色叶子。

画风：手绘水粉 / 厚涂插画的柔光质感，梦幻、通透，像童话绘本，和一棵糖果色云朵树是同一套画风。
不要传统的红色、橙色灯笼色，不要文字、水印、水面、倒影。灯放在画面正中，四周留一点空。
```

- 太素：加一句「花瓣边缘的虹彩再明显一点，花心的光再亮一点」。
- 想换颜色：把「乳白色」换成想要的颜色（偏淡粉、偏冰蓝……）。
- 画成白底也没关系，Claude 能抠。
- 大小、亮度、漂、倒影、发光都由代码来做，一张就够。

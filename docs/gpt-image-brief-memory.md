# 给画图模型的交接单：记忆 App「银河纪」

夜海的底图（夜里、白天各一张）可以出图；浪头的光、闪烁的光点、打捞的光球由代码叠在上面动。漂在河里的灯也出图（透明底，抠出来用）。
光不只是紫色：像欧泊、肥皂泡那样，薄荷绿、湖蓝、淡粉、薰衣草紫、浅金几种颜色混着。

## 夜海底图：`design/memory/sea-night.png`（先画这张）

```
竖屏 9:19.5（例如 1170×2532）。一片安静的夜海，正面平视，海平线在画面正中偏上一点（从上往下大约 48% 的位置），海面一直铺到画面最下面。
天空：深蓝到墨蓝的夜空，星星很多，一条很淡的银河斜着穿过天空；右上方一弯明亮的月牙，周围一圈柔光。
海：大部分是平静、深色的水面，月光在水里碎成一条长长的光柱。近处的浪很缓，浪的边缘像被点亮了一样，发着柔和的荧光：不是单一的紫色，而是像欧泊石、肥皂泡那样的虹彩，薄荷绿、湖蓝、淡粉、薰衣草紫、浅金交替出现，光点细碎、亮晶晶的；近处的水面上散落着星星点点的反光。
画面最上面和中下部的水面要留得比较空（之后要在上面放标题，还有漂着的灯），不要画灯、船、人。
画风：手绘水粉 / 厚涂插画的柔光质感，梦幻、通透，像童话绘本；颜色饱满但干净。不要文字、水印、人物、动物。
```

## 白天底图：`design/memory/sea-day.png`（把夜里那张一起发过去）

```
完全保持这张图的构图和画风：海平线、月亮、浪的位置和形状都不变，镜头不动，尺寸比例不变。
只把时间换成刚亮不久的白天：天空是很淡的天蓝到奶白、带一点粉的渐变，几缕柔软的云；星星和银河几乎看不见，月亮的位置只剩一弯很淡的白色日间月。海面变成透亮的浅蓝和青绿色，阳光在水面上碎成一片闪光；浪的边缘依然泛着虹彩，但白天像珍珠和彩色泡沫那样柔和（薄荷绿、淡粉、浅金、湖蓝），不刺眼。
```

- 想要单一颜色：把「薄荷绿、湖蓝、淡粉、薰衣草紫、浅金交替出现」换成想要的，例如「像蓝眼泪那样的冰蓝色」「淡金色」。
- 白天那张一定要把夜里那张发过去，两张对得齐，切换日夜时不会跳。
（之前「念念树」四季树、牌子、结的提示词已经不用了，2026-11-03 作者改成银河纪。）

## 河灯：`design/memory/lantern.png`

用法：在 GPT 里发下面这段（在画过糖果色云朵树的那个对话里发，画风更统一）。画好丢回给 Claude。

```
画一盏河灯的素材图，透明底 PNG（背景必须是真正的透明，不要白底，也不要灰白格子）。

样子：一朵小小的莲花形河灯，从斜上方大约 30 度往下看。花瓣是乳白色、半透明的，像珍珠和磨砂玻璃，花瓣边缘泛着柔和的虹彩，像肥皂泡那样淡粉、淡紫、薄荷绿、浅蓝慢慢渐变。花心里有一团柔和的暖白色光，从花瓣里透出来，整朵花微微发亮，边缘有一圈很淡的光晕。花底下托着一片小小的圆形浅色叶子。

画风：手绘水粉 / 厚涂插画的柔光质感，梦幻、通透，像童话绘本，和一棵糖果色云朵树是同一套画风。
不要传统的红色、橙色灯笼色，不要文字、水印、水面、倒影。灯放在画面正中，四周留一点空。
```

- 太素：加一句「花瓣边缘的虹彩再明显一点，花心的光再亮一点」。
- 想换颜色：把「乳白色」换成想要的颜色（偏淡粉、偏冰蓝……）。
- 画成白底也没关系，Claude 能抠。
- 大小、亮度、漂、倒影、发光都由代码来做，一张就够。

## 一、这个 App 是干什么的

三件事都要，按这个顺序做：
1. **真能听歌的播放器**：搜歌、放歌、歌词、歌单。作者天天听，要稳、要好看。
2. **和角色一起听**：和播放器一起做（一起听的界面会影响整体美化）。
3. **角色的歌单 / AI 每日推荐**：第二期。

## 二、音源（不加后端、不部署）

| 要做的 | 怎么做 | 状态 |
|---|---|---|
| 搜歌、拿播放链接、拿歌词 | 照旧插件 X_XPhone：vkeys 搜歌 + Meting 取链 / 歌词 / 歌单，地址能在设置里改 | **要实测**：这两个免费接口在 Tauri 里能不能直连，作者先帮忙测 |
| 放出声音 | 网页放别人家的音乐文件是允许的，不会被跨域拦 | 能做 |
| 逐字歌词 | 网易云有一部分歌带逐字时间：能拿到就逐字亮起，拿不到就整行亮 | 能做 |
| 导入自己的歌单 | 网易云里把歌单（包括「我喜欢的音乐」）设成公开，贴链接进来，不用登录 | 能做 |

| 每日推荐（自己做） | 每天让 AI 按导入歌单的口味 + 最近剧情 + 角色心情挑一组 | 能做（第二期） |

## 三、App 里有什么（2026-11-01 作者定的结构，照网易云）

底部四个标签：**广场 / 搜索 / 笔记 / 我的**；迷你播放条浮在标签栏上面。

1. **广场**
   - **心动模式**：按「我喜欢」里的歌，找风格相似的歌一直放（像网易云的心动模式）。网易云的要登录；我们不找 AI：从「我喜欢」里随机挑几位歌手，搜他们别的歌，和红心歌穿插着放。
   - **角色的歌单**：每个联系人一份。两种都要：
     - AI 生成：按人设想 TA 会听什么，再去搜出来。
     - 手动加：在播放页「加到谁的歌单」。
     - **随剧情加歌**（可以开关，不额外花 API）：正文和手机聊天本来就在生成，暗号里多一种「TA 把某首歌加进了歌单」，顺手加进去。
   - 榜单（飙升 / 新歌 / 热歌 / 原创）。
2. **搜索**：搜歌、歌手；搜过的词留着。
3. **笔记**
   - 播放页长按歌词，选「收进笔记」（可以连着选几句）。
   - 一条笔记 = 歌词 + 哪首歌 + 我写的感悟。
   - 「生成乐评」：照聊天里「生成动态」那个样子，选生成几条、必定出现的人、只让选中的人写。条数比联系人多，多出来的是**路人乐评**。我先写了感悟的话，角色能看到、可以回应。
4. **我的**
   - 头像、名字（跟着小手机「我」的资料）。
   - 我喜欢的音乐、导入的网易云歌单、**本地**（上传自己的 MP3，存在这台设备上）、听歌排行（按听的次数）。

- **热评**：网易云自己的评论接口，网页直接连会被拦（和登录那个一样），Tauri 又没有代理，**多半拿不到**。可以在 Tauri 上试一次；拿不到就用 AI 写的路人乐评。
- **播放页**：
  - 中间是「皮肤」（见第四节），可以换。
  - **整页跟着封面换颜色**：封面放大、模糊铺在最底下，上面盖一层白雾（学酷狗概念版）。
  - 歌词两行，当前这句**逐字亮起**。点歌词进全屏歌词。
  - 一排小按钮：喜欢、一起听、歌词悬浮窗、更多。
  - 进度条；随机 / 上一首 / 播放暂停 / 下一首 / 播放列表。
- **播放列表**、**歌单详情**、**全屏歌词**。

## 四、播放器皮肤（放资源库，可以切换）

骨架（播放、进度、歌词、一起听的逻辑）只有一份；皮肤只是「中间那张脸」：GPT 画好的图抠出来 + 一点点动效。加一个皮肤 = 加几张图 + 几行动效。

### 第一批（4 个，2026-11-01 作者定的）
| 皮肤 | 样子 | 自己听时在动的 | 一起听时 |
|---|---|---|---|
| **唱片**（默认） | 照作者发的网易云截图：一张唱片在转，中间是大大的封面（占唱片大约 2/3），上方正中一支白色的细唱臂，针头落在唱片右上。唱片有两种材质可选：**玻璃**（半透明，带同心纹路）/ **黑胶** | 唱片转；暂停时唱臂抬起、唱片慢慢停下 | 中间封面变成你和 TA 的头像，一边一半 |
| **八音盒** | 复古八音盒，盒子中间一个小摆件在转 | 唱到的字**一个一个从八音盒里飘出来，飘到空中排成一行**，这句唱完慢慢散掉 | 两个小摆件面对面一起转 |
| **下雨天落字** | 作者之后自己设计，到时候按作者的图来 | — | — |
| **热成像** | 学「酸性艺术 + 热成像」那篇：整页黑白，中间物件是 X 光片的样子（磁带 / 耳机仓），**只有歌词是彩色的**（热成像的蓝→绿→黄→红） | 唱到的字像被加热，从蓝烧到黄红；鼓点打一下，物件上亮起一团热斑再慢慢冷下去 | 用耳机仓：你一只、TA 一只，两只耳机都是热的，其余都是冷的黑白 |

八音盒飘字、下雨天、热成像的热斑都要一直画，**看不见就停**（被别的页面盖住、手机收起、切到后台都停）。

### 背景可以自定义
- 默认：跟着封面变色（封面放大模糊铺底 + 白雾）。
- 自定义：选一张自己的图当背景（作者截图里那张海鸥海浪的就是），所有皮肤都能用，在资源库里换。
- 热成像为了保持「只有歌词有颜色」，自定义的背景会自动变成黑白。

### 第一批里拿掉的
透明 CD 盒（假 3D 版）先放到「以后可以加」。

## 五、一起听（和播放器一起做）

- 从聊天里发起 / 接受：发一张「一起听」卡片；正文里的「一起听歌」暗号也能触发（`CLAUDE.md` 里记着的那条）。
- 聊天顶部挂一条小横条「正在和 TA 一起听：歌名」，点一下回播放页。
- 播放页样子（2026-11-02 作者定的，只有这一种，跟皮肤无关）：两个头像挨着、叠住一小块（TA 的压在上面），外侧各塞一只有线耳机（GPT 画的图，左右切成两半往中间挤），耳机线垂到头像底下一点就淡掉；头像上方各一个气泡，写这首歌里重复最多的两句歌词，小三角对着头像；白天白底黑字、夜里（18 点到 6 点）黑底白字；底下一行字「一起听了 X」，没有背景框。头像不动。
- **这个气泡以后做资源库的「气泡」时直接套用**（作者说的）。

## 六、在哪里都能看到

| 位置 | 内容 | 状态 |
|---|---|---|
| **小手机的灵动岛** | 顶部那条：小封面 + 跳动的波形；点开是小播放器（歌名、暂停、上下首）。在小手机的哪个 App 里都在。一起听时带 TA 的小头像 | 能做 |
| **小手机的锁屏** | 一张「正在播放」卡片，能暂停、切歌 | 能做 |
| **歌词悬浮窗**（小手机里） | 一条小歌词浮在小手机的任何页面上，能拖 | 能做 |
| **桌面歌词**（酒馆页面上） | 小手机收起来后，浮在酒馆聊天上面，能拖、能调透明度 | 能做 |
| **系统的「正在播放」**（锁屏、控制中心、灵动岛长按） | 歌名、歌手、封面、暂停、切歌 | 能做 |

### 两个歌词开关
- **歌词悬浮窗**：只在小手机里。小手机收起来就看不到。
- **桌面歌词**：在酒馆页面上。**打开桌面歌词时，小手机里的歌词悬浮窗也一定是开的**。
- 只开歌词悬浮窗、不开桌面歌词 = 只有小手机里有。

  - 雨丝斜着落进水里荡开涟漪；当前这句跟着唱一个字一个字掉下来（外文一个词一块），落在水面上排成一行，落地弹一下、荡一圈水、水里有倒影；翻译小字淡淡浮在下面。下一句来了，上一句沉进水里、往四周化开、变淡，最多同时两句。没歌词就掉歌名。

- **v0.6.92**：下雨天照作者发的粒子雨改：雨丝竖直、头亮带一层淡光、分远近（远的短慢淡、落在水平线附近）；落点闪一下、溅起几粒水花、荡开两圈水纹（近大远小）。
  - 字**提前掉**，唱到那个字时刚好落地；每句唱多久改成按到下一句的间隔和字数估（`P.lineDur`，全部歌词里从左往右亮也用它），日语快歌不再越来越落后。
  - 换句：下一句第一个字开始往下掉时，上一句从左到右一个个「啪」地碎掉（往下一压扁就没了，溅起几粒水珠落回水面），新字落地前就清完，不再叠在一起；也不再先变大。

## 八·五、电台：讲故事（2026-11-07 定了需求，v0.8.168 做了第一版）

上一版的小剧场（幕布、挂件）作者不要了。白噪音不单独做一块，只当讲故事时可开可关的垫底声音。

**样子：兔子洞里的书店**（爱丽丝的味道，但画里不出现任何人物 / 动物，只用东西：怀表、茶杯、扑克牌、钥匙孔小门、「喝我」瓶子、黑白格地板、蘑菇）
- 掉在兔子洞半路上的书店，书架歪着、倒挂着，几本书在半空慢慢往下飘。
- 每一期故事是一本书，按角色分格放在书架上；点一本，书在面前打开，字幕一行行写在书页上，讲到下一段翻一页。
- 切换角色：柜台上的怀表，表盘里是角色头像（用户设的头像，不画），拨一下换人。能看所有角色以前讲过的书。
- 白噪音：柜台上一排「喝我」小瓶子（雨、火、浪、风、白 / 粉 / 棕噪音…），点开的瓶子亮，可叠加、调音量。全部用程序算（雨、火、浪、风、虫鸣也是），不下载录音。
- 素材让 GPT 画（清单见对话 / 下面），代码只负责拼和动。

**故事从哪来**
1. 书店自带：过了版权期的原文，按语言分——中文（古代寓言、成语故事）、日语（青空文库）、英语（古腾堡：伊索、安徒生 / 格林老英译本、彼得兔、爱丽丝）。角色说什么语言先给他看那种语言的书；中文翻译第一次听时让 AI 翻一次存下来；硬要他讲别的语言的书，也是 AI 翻一次存下来。不带感想（感想因角色而异，不能自带），想要点「让 TA 说说感想」（花一次 API，存在这本书里、跟这个角色）。
2. 自己导入：粘贴文字、导入 txt / md。语言和角色不一样时问「让他翻成自己的语言讲（一次 API）」还是「照原文念」。同样可以点按钮生成感想。
3. 随便讲一个：一次 API 写完「故事 + 中文翻译（角色不说中文时）+ 讲完的感想（至少两段，也配翻译）」。故事可以是编的，也可以是各地民间故事、寓言；**语言跟着角色，不跟着故事的国家**。
4. 让角色讲（类型：童话、日常小事、回忆你们之间的事、陪你数羊，或者自己写「想听……」）：一次 API；「回忆」类可以读你们的聊天，讲出来的不存回记忆。

**念**
- 用角色的声音（也可选手机自带的声音，免费）；外语只念原文，字幕下面配中文翻译（像歌词翻译）。
- 感想也用角色声音念，设置里能关掉「念感想」。
- 合成方式设置里选：① 点到那段才合成；② 一次全部合成；③ 自动提前合成后面几段（默认提前 2 段）。中途停止就不再合成后面的；合成过的段存下来，重听不再花。

**存**：每期存成一本书，**跟着酒馆聊天窗口走**（不同窗口角色不同）；能重听、能删。不写进聊天记忆、世界书，不发给酒馆。

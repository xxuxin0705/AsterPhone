# 音乐 App 需求（2026-11-01 和作者定的）

每条后面标着：**能做** / **要实测**（做出来要作者在真机上试）/ **做不到**（网页的限制，写了替代办法）。

---

## 一、这个 App 是干什么的

三件事都要，按这个顺序做：
1. **真能听歌的播放器**：搜歌、放歌、歌词、歌单。作者天天听，要稳、要好看。
2. **和角色一起听**：和播放器一起做（一起听的界面会影响整体美化）。
3. **角色的歌单 / AI 每日推荐**：第二期。

---

## 二、音源（不加后端、不部署）

| 要做的 | 怎么做 | 状态 |
|---|---|---|
| 搜歌、拿播放链接、拿歌词 | 照旧插件 X_XPhone：vkeys 搜歌 + Meting 取链 / 歌词 / 歌单，地址能在设置里改 | **要实测**：这两个免费接口在 Tauri 里能不能直连，作者先帮忙测 |
| 放出声音 | 网页放别人家的音乐文件是允许的，不会被跨域拦 | 能做 |
| 逐字歌词 | 网易云有一部分歌带逐字时间：能拿到就逐字亮起，拿不到就整行亮 | 能做 |
| 导入自己的歌单 | 网易云里把歌单（包括「我喜欢的音乐」）设成公开，贴链接进来，不用登录 | 能做 |
| 登录网易云、看官方每日推荐 | 网易云不让网页直连，要有服务器在中间转；借别人的公共服务器等于把账号交给陌生人 | **做不到**（作者同意用下面这条代替） |
| 每日推荐（自己做） | 每天让 AI 按导入歌单的口味 + 最近剧情 + 角色心情挑一组 | 能做（第二期） |

## 三、App 里有什么

- **首页**：搜索、我导入的歌单、我喜欢、最近播放、榜单（飙升 / 新歌 / 热歌 / 原创）、每日推荐（第二期）。
- **播放页**：
  - 中间是「皮肤」（见第四节），可以换。
  - **整页跟着封面换颜色**：封面放大、模糊铺在最底下，上面盖一层白雾（学酷狗概念版）。
  - 歌词两行，当前这句**逐字亮起**。点歌词进全屏歌词。
  - 一排小按钮：喜欢、一起听、歌词悬浮窗、更多。
  - 进度条；随机 / 上一首 / 播放暂停 / 下一首 / 播放列表。
- **播放列表**、**歌单详情**、**全屏歌词**。

## 四、播放器皮肤（放资源库，可以切换）

骨架（播放、进度、歌词、一起听的逻辑）只有一份；皮肤只是「中间那张脸」：GPT 画好的图抠出来 + 一点点动效。加一个皮肤 = 加几张图 + 几行动效。

### 第一批（5 个，一起上）
| 皮肤 | 样子 | 自己听时在动的 | 一起听时 |
|---|---|---|---|
| **黑胶唱片** | 深色黑胶，细密纹路有高光，金属唱臂 | 唱片转，暂停时唱臂抬起 | 唱片中间的标签变成你和 TA 的头像，一起转 |
| **玻璃唱片**（默认） | 学酷狗概念版：半透明玻璃唱片，边上一圈星屑闪光，透明唱针，中间是封面 | 同上 | 同上 |
| **透明 CD 盒** | Y2K 透明塑料盒 + 镭射 CD + 贴纸；假 3D（网页自带的翻转，不用 three.js） | 盒盖开着，CD 转；手指拖动盒子微微倾斜、反光跟着动 | CD 上贴着你和 TA 的头像贴纸 |
| **八音盒** | 奶白 / 浅木色复古八音盒，盖子内侧有镜子，黄铜滚筒，中间一个小摆件 | 滚筒转、小摆件转；歌词印在打孔纸带上，从侧面慢慢吐出来 | 两个小摆件一起转 |
| **下雨天落字** | 窗边，玻璃上有雨滴和水痕，窗外是虚化的灯光 | 歌词一个字一个字像雨滴落下，落到窗台排成一行，唱完被雨冲掉 | 窗边两个人共撑一把伞（剪影） |

下雨天最费手机：字一直在画，**看不见就停**（被别的页面盖住、手机收起、切到后台都停）。

## 五、一起听（和播放器一起做）

- 从聊天里发起 / 接受：发一张「一起听」卡片；正文里的「一起听歌」暗号也能触发（`CLAUDE.md` 里记着的那条）。
- 聊天顶部挂一条小横条「正在和 TA 一起听：歌名」，点一下回播放页。
- 播放页：两个头像用**一根分叉的耳机线**连着，线跟着节奏轻轻晃；底下一行「和 TA 一起听了 23 分钟」。
- TA 对这首歌说的话，像小纸条一样从旁边冒出来，不挡歌词。
- 每个皮肤的一起听样子不一样（见上表）。

## 六、在哪里都能看到

| 位置 | 内容 | 状态 |
|---|---|---|
| **小手机的灵动岛** | 顶部那条：小封面 + 跳动的波形；点开是小播放器（歌名、暂停、上下首）。在小手机的哪个 App 里都在。一起听时带 TA 的小头像 | 能做 |
| **小手机的锁屏** | 一张「正在播放」卡片，能暂停、切歌 | 能做 |
| **歌词悬浮窗**（小手机里） | 一条小歌词浮在小手机的任何页面上，能拖 | 能做 |
| **桌面歌词**（酒馆页面上） | 小手机收起来后，浮在酒馆聊天上面，能拖、能调透明度 | 能做 |
| **系统的「正在播放」**（锁屏、控制中心、灵动岛长按） | 歌名、歌手、封面、暂停、切歌 | 能做 |
| 系统「正在播放」里的歌词 | 学网易云：每唱到新的一句，就把这一句写进标题 | **要实测**：iPhone 把网页切到后台后会限制网页里的程序，可能换句变慢或停住 |
| 真正浮在所有 App 上的桌面歌词 | 要原生 App 的权限 | **做不到** |

### 两个歌词开关
- **歌词悬浮窗**：只在小手机里。小手机收起来就看不到。
- **桌面歌词**：在酒馆页面上。**打开桌面歌词时，小手机里的歌词悬浮窗也一定是开的**。
- 只开歌词悬浮窗、不开桌面歌词 = 只有小手机里有。

## 七、和别的东西的配合

- **正文朗读时音乐让一让**：作者的正文朗读插件（`xxuxin0705/reading`）开始念时喊一声，音乐渐弱暂停、记住位置；念完喊一声，渐强接着放。手机自己的语音（语音消息、打电话）也一样。两边各加几行代码。**要实测**：iPhone 上「自动接着放」会不会被系统拦（按理说放过一次就允许，但没验证过）。
- **后台播放**：本地酒馆用手机浏览器打开，切到别的 App 继续放（安卓 Chrome、iPhone Safari 都支持）。**要实测**：Tauri Tavern 切后台还能不能放。

## 八、实测清单（做好后作者帮忙试）

1. vkeys / Meting 在 Tauri 里能不能直连（第一件事，决定音源怎么做）。
2. iPhone Safari：切到后台继续放；锁屏 / 控制中心 / 灵动岛显示歌名、封面、能切歌；锁屏歌词会不会跟着换句。
3. Tauri Tavern（作者用的那台设备）：切后台还能不能放。
4. 朗读插件念完后，音乐能不能自动接着放。

# 灵感收藏

作者觉得好、以后做到相关页面时拿出来用的点子。用之前先跟作者确认放在哪。

## 台灯照着选中项（2026-11-01）
- 来源：小红书「有趣的交互小巧思」（屿安 designer）https://xhslink.cn/o/e9aphTBJZO
- 样子：菜单旁边一盏手绘台灯，指到哪项，台灯转过去照着那项，光束跟着移动；被照到的那项底下有一块带颗粒感的亮斑，其余几项半透明。台灯转动有惯性，关节会跟着弯。
- 妙在：用一个会动的小角色代替「选中高亮」，选中效果和画风是一套的。和插线板上小脸的眼睛跟着插头转是同一个思路。
- 搬到手机上要改：手机没有悬停，改成「点了才转过去照」或「手指按着滑过列表，灯跟着照」。
- 可能用在：设置首页、提示词 / 方案这类「挑一个」的列表、锁屏或主屏的手指互动。
- 台灯这种插画用画好的图，不要用代码画（第 11 节：能抠图不自己画）。

## 毛玻璃卡片主题（2026-11-01）
- 来源：小红书「高级玻璃牛逼风格提示词」（Foodhome）https://www.xiaohongshu.com/explore/6a47aa1d000000000f01dd40
- 样子：照片铺满当背景，压淡、压糊、带点雾；中间浮一张大圆角毛玻璃卡片，边上一圈很细的白色亮边，像有厚度的磨砂玻璃（不要像灰色半透明遮罩）；卡片里嵌清晰的照片窗口，上面叠几行很轻的小字；搜索框、圆形「+」、圆形心形按钮也都是同样的玻璃。整体安静、通透、低饱和，Apple / iOS 玻璃那种克制感。
- 作者想用在：**整个小手机的主题**（所有 App 的卡片、弹窗都变成这种玻璃，背景用壁纸）。作者说这个改动大、费 token，先记着，以后想改了再做。
- 做的时候：玻璃用 CSS（backdrop-filter 模糊 + 细白描边 + 很淡的高光和阴影），不用画图；被盖住的页面别一直糊着重算（会卡）；先和作者确认会动到之前定好的哪些设计。

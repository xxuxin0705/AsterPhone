作者觉得好、以后做到相关页面时拿出来用的点子。用之前先跟作者确认放在哪。

## 记忆怎么做（2026-11-03，给第二期「记忆宫殿」用）
- 来源：小红书 Oliscat「Latent·告别换窗焦虑」https://xhslink.cn/o/2UV4z5vzMhT 、「Latent：前端不换窗」https://xhslink.cn/o/3MbDgavQLCB （开源仓库 oliscatt/Latent-memory）；纯情卢关大帝「InternalBeyond V3.0 新记忆系统与 Map」https://xhslink.cn/o/4OyshTDC9iO
- **分三层**：常驻层（人设、相处原则，每轮都带，但不把整个记忆库塞进去）；记忆层（发生过的事，相关时才找出来带上）；接续层（上次聊到哪、现在什么状态、什么没聊完）。和 pages-chat.md 第 10 节的「必读层 / 检索层」对得上，多出来的是「接续层」。
- **只记发生过的，不编**：记事情、原话、当时的状态；没证据的形容词（「TA 很温柔」）不当事实写进去。答不上来就说不知道，不补猜测。
- **每条记忆以「现在的状态」收尾**：过去的事不会被当成正在发生。
- **用到才变重要，不按时间变淡**：被想起的那条权重升高，没被想起的不动；「很久以前」不等于「不重要」。
- **记错了能改**：旧的那条标成撤回，以后找的时候不再出来。
- **找的方法**：关键词（BM25）+ 意思相近（向量）+ 时间（「上周」「七夕那天」），几路结果合在一起排（RRF）。向量是可选的，没配也能用关键词找。
- **攒够了再整理**：后台每隔一阵看一次，攒够几十条或者过了一段时间才整理一次；一次只跑一个，聊天优先；写成功才算数，失败要提醒（和我们「一个功能同一时间只能有一个请求」一致）。整理用便宜的模型。
- **主动想起**：每次发消息前查一下，找到相关的旧事，放一小段在消息前面（约 1KB），TA 就会自己提起来。
- **给人看见每条记忆是怎么进上下文的**（InternalBeyond 的「透视」区）：每轮带了哪几条、凭什么带、常驻占多少字。还有一个好看的「记忆星海」：每条记忆是一颗光点，大小 = 重要、明暗 = 常被想起、金色 = 钉住。
- **搬到 Aster 要改**：Latent 是 Python 本地服务，Tauri Tavern 装不了 → 我们全放在浏览器里（IndexedDB 存，JS 算关键词，向量走「其他」线的接口）。做的时候记得 CLAUDE.md 里「其他」线断线怎么办那条。

## 台灯照着选中项（2026-11-01）
- 来源：小红书「有趣的交互小巧思」（屿安 designer）https://xhslink.cn/o/e9aphTBJZO
- 样子：菜单旁边一盏手绘台灯，指到哪项，台灯转过去照着那项，光束跟着移动；被照到的那项底下有一块带颗粒感的亮斑，其余几项半透明。台灯转动有惯性，关节会跟着弯。
- 妙在：用一个会动的小角色代替「选中高亮」，选中效果和画风是一套的。和插线板上小脸的眼睛跟着插头转是同一个思路。
- 搬到手机上要改：手机没有悬停，改成「点了才转过去照」或「手指按着滑过列表，灯跟着照」。
- 可能用在：设置首页、提示词 / 方案这类「挑一个」的列表、锁屏或主屏的手指互动。
- 台灯这种插画用画好的图，不要用代码画（第 11 节：能抠图不自己画）。

## 毛玻璃卡片主题（2026-11-01）
- 来源：小红书「高级玻璃牛逼风格提示词」（Foodhome）https://www.xiaohongshu.com/explore/6a47aa1d000000000f01dd40
- 样子：照片铺满当背景，压淡、压糊、带点雾；中间浮一张大圆角毛玻璃卡片，边上一圈很细的白色亮边，像有厚度的磨砂玻璃（不要像灰色半透明遮罩）；卡片里嵌清晰的照片窗口，上面叠几行很轻的小字；搜索框、圆形「+」、圆形心形按钮也都是同样的玻璃。整体安静、通透、低饱和，Apple / iOS 玻璃那种克制感。
- 作者想用在：**整个小手机的主题**（所有 App 的卡片、弹窗都变成这种玻璃，背景用壁纸）。作者说这个改动大、费 token，先记着，以后想改了再做。
- 做的时候：玻璃用 CSS（backdrop-filter 模糊 + 细白描边 + 很淡的高光和阴影），不用画图；被盖住的页面别一直糊着重算（会卡）；先和作者确认会动到之前定好的哪些设计。

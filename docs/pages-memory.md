# 岁岁砂（记忆 App，原念念铃）

> **2026-11-14 整个重做，v0.8.353 起改名「岁岁砂」。** 作者点过头的整份方案：https://claude.ai/artifact/RELPxmDrbz9Rb1FjNa7RVr 。下面「现在是什么样」是重做后的；再往下是念念树 / 念念铃时期的方案和改动记录，留着查来龙去脉。

## 现在是什么样（v0.8.353）

- **三页一张画**（`apps/memory/art.js`，纸、墨、一种钴蓝，全代码画，白天夜里两套）：时间 = 沙漏，漏下的那道沙是时间轴；关系 = 轨道，谁都能当中心，越亲离得越近，星后面的小圈是以前的位置；地点 = 迷雾地图，大地方里套小地点，地名能拖、位置记住，指南针指着现在在的地方。
- **关系那页顶上有一排名字**（别的页收起来）：点谁（或把星拖到正中）谁就是中心，别的星慢慢滑到新位置。时间和地点对谁都一样，不分人看（v0.8.354 作者定的）。谁上名字行见 `core/memory.js` 的 `cast()`（联系人、出现在 3 件以上事里的、和我关系变过的；设置里开过关过的以作者定的为准，能拖着排）。
- **记什么**：事件多了时间（几点几分 / 时段）、大标签（`BIG` 九个，能加改删）、小标签（就是以前的故事线：同一个小标签的事想起一件带上另外几件）、谁知道（在场的 + 后来听说的）、原文节选（AI 只标从哪句到哪句，`excerpt()` 从原文里原样剪）、出自第几楼（`fl`）；关系多了亲近度和两边各自的看法；新加地点（一句介绍、归哪个大地方）。行的格式见 `parse()` 上面的注释，四条内置提示词（memSort / memMaybe / memEvery / memChat）跟着改了。
- **什么时候记**：每轮顺手记（正文里的 `<astermem>`，不另外花钱）/ 每隔几轮整理一次（`autoSort()`，另外找一次 AI，这次没成下次一起补；新装默认这个，10 轮）/ 只手动；随时能点「现在整理」。三种导入来源照旧。
- **怎么想起来**（`recollect()`）：向量找出最像的 20 件（「其他」线的向量，硅基流动 BAAI/bge-m3）→ 重排挑最准的（「其他」线的重排，BAAI/bge-reranker-v2-m3）→ 够像的才算（门槛分三档：重要 / 特殊日 / 秘密容易，日常难，其余居中，见 `TH`）→ 同一个小标签只占一个名额。还在这轮上下文里的（`ctxFrom()`）不带；这次说话的 TA 们都不知道的不带。向量没接、没算、连不上、超过 9 秒：退回按词找（原来的 `recall()`）。**门槛的数是估的，没拿真接口校过，要作者实测后调。**
- **向量存哪**：kv 的 `memvec:窗口`，`{ model, v: { 事件 id: Float32Array } }`。新记了事后台自动补；换了向量模型不自动重算，打开岁岁砂会问一次，设置 → 回想 → 向量 也能点。
- **每轮发什么**（`memoryFor()`）：一直带的 = 涉及到的人互相的关系和看法、TA 们知道的关于人的事、没完的事、特殊日子、钉住的；这会儿的 = 现在在哪（一句介绍）、想起的事（带谁知道、原文节选、同一小标签的另外几件）、忽然想起的一件。「来时路」（经历过的事的目录）改成开关，默认关。「刚才想起了什么」里写了这次是怎么找的、两块各多少字。
- **设置页**：人物、标签、导入整理、记录、回想、清空（只清这个聊天窗口的，设置和标签留着）。
- **「其他」线**：多了「重排」一股；「断线了怎么办」加回来了，只有自动重试，没有副 API（换了向量模型存过的向量就对不上，断了岁岁砂自己退回按词找）。

**没用上、等作者同意再删的旧东西**：`apps/memory/scene.js`（铃铛场景）、`memory.css` 里 `.as-mem-tree` 到 `.as-mem-none` 那一段、`assets/memory/` 里的铃铛和天空图（约 1.1MB）、存档里的 `trees`。证据：`scene.js` 只有旧首页引用，旧首页已经换掉；删之前再全局搜一遍 `as-mem-` 和 `assets/memory`。

# 以前的方案：记忆 App「念念树」（2026-11-03 和作者定的）

还没开工。这份是方案，作者看过、同意了再动手；先做「第一步」，用顺了再往后加。

## 一、管什么

让手机里的 TA 记得**过去真发生过的事**：最近几条之外的事，TA 现在一概不知道。
- 记忆**只给小手机用**：正文发生的事 → 变成手机里 TA 的记忆，单向，不写回酒馆。
- 线上模式不受影响；正文联动时也只影响聊天窗口。
- 一律**客观记录**（发生了什么、说了什么原话），不替 TA 下结论（记「TA 回了三条语音哄你」，不记「TA 很爱你」）。
- 答不上来就是「不知道」，不为了凑完整而补猜测。

## 二、记哪些东西

| 一格 | 里面是什么 | 例子 |
|---|---|---|
| **事件**（时间线） | 剧情时间（年月日 + 时段）、谁、在哪、经过、几句原话、标签、情感转折、身份变化、是不是特殊日子、和哪件事有关、重要度 1～5、来源（正文 / 手机 / 导入，第几层） | 2005/12/25 傍晚，原宿，一起拍大头贴…… 标签：约会 · 第一次；重要度 4 |
| **现在**（每个 TA 一张） | 现在是什么关系、什么身份、现在的状态、没完的事（约定、没聊完的话） | 关系：暧昧；没完的事：答应春假去冲绳 |
| **人物网** | 人（名字、别名、是谁）和人之间的关系（从什么时候起、现在怎样）；TA 和 user 的、角色之间的都记 | 夏油杰 —— 五条悟的挚友（2005/04 起） |
| **地点** | 名字、是什么地方、在这发生过哪些事 | 咒术高专·男生宿舍 |
| **特殊日子** | 生日、节日、纪念日，和谁有关 | 2/3 夏油杰生日（也是节分） |

每条事件带一个**「影响」**：这件事过去以后留下了什么（伤、心结、改了的习惯、还留着的东西），没留下就空着（作者 2026-11-03 改：以前每件都写「现在」，过去的事全是「现在」很怪）。TA 现在怎样看关系里的「现在怎样」；以前存的「现在」只在 TA 最近那件事上显示。
- 时间：正文里有剧情时间标签（如 `<Ti>`）就直接读，不用猜；没有就让 AI 按前后文推，标「推测」，**作者能手动改成选好的年月日**。
- 记错了：旧的标成「撤回」，以后不再被找出来（不直接删，能找回）。
- 被想起越多越靠前；**不按时间变淡**（很久以前 ≠ 不重要）。

## 三、什么算「值得记」

判断：**一个月后 TA 要是完全不记得这件事，你会不会觉得奇怪 / 失落？** 会的才记。
- **记**：第一次（约会、牵手、吵架…）；关系 / 情感变了（表白、确认关系、冷战、和好、分手）；身份变了（转学、升职、搬家、受伤）；约定和计划；送了 / 收到什么；新知道的关于 user 的事（喜好、怕什么、过去、家人）；说出口的秘密；新出场的重要人物、新去的地方；生日、节日、纪念日。
- **不记**：没有新信息的日常（吃饭、走路、上课）；已经记过的又说一遍；风景、气氛、心理活动的描写；寒暄、接梗。
- 重要度：表白、分手这种 5，送了本书 3，新知道 user 不吃香菜 2。

## 四、记忆从哪来

1. **一次性整理旧内容**（花一次钱，作者能接受）
   - 来源（可以多选）：
     - **聊天世界书**：选一本，勾要整理的条目（例：Anima 的 chapter_1～3）。
     - **导入文件**：世界书 `.json`、酒馆聊天记录 `.jsonl`、`.txt`。
     - **读当前酒馆这个聊天的全部正文**。
   - **默认先用总结**：有 Anima 这种总结时先整理总结（作者那本 3.2 万字，一两次就整理完）；想要更细再读原文。
   - 读原文时：只留「上下文与世界书」里设好的标签（例：只要 `<content>`），没选中的重新生成（swipes）、变量、附加信息全扔掉；可以选「去掉 user 说的话」「只整理第几层到第几层」。
     - 实测：五条悟那个窗口 593 层、文件 44MB，只留正文约 91 万字（user 的话只占 4%），每批 20 层左右，约 15 批。
   - 分批跑：显示进度（第 3/15 批）、能取消、断了能接着跑；同一时间只跑一个；失败进日志。
   - 整理完只存记忆，不存原文。
   - 和已有的记忆重复的（同一天、同一件事）合并，不记两遍。
2. **跟着剧情自动记**（不另外调 AI）
   - 和「随剧情加歌」一样：正文生成时顺便写一个记忆暗号，手机读到就存。只记上面「值得记」的。
   - 两档：**有值得记的才记**（默认）/ 每轮都记。
3. **手机聊天自动记**（不另外调 AI）
   - 私聊、群聊回复时顺便带一个记忆暗号，规矩同上。
   - 照「可见范围」：私聊的事只进那个 TA 的记忆；动态设了不给 A 看，A 的记忆里就没有。
4. **手动**：长按一条消息 →「记住这条」，直接钉住。

## 九、定好的 / 还没定的

- **暗号跟着 App 走**：记忆有自己的暗号，和音乐「随剧情加歌」的分开。具体长什么样写代码时再定。
- **「怎么找」用星络那种「顺着关系漫开」**（v0.8.71 做了，作者同意的；学自小红书「让 AI 学会触景生情」https://xhslink.cn/o/7FuSPQfl9Xg）。向量以后当可选项。另一篇「记忆家族」（https://xhslink.cn/o/4Lf1RyAN6jj）里能用的是把一条记忆拆成「谁 / 做了 / 什么」几小句，还没用上。
- **「想起」的细节**（v0.8.76）：除了两个字一组，也认单个字（算一半分），先把自己和说话人的名字去掉（不然「桃霁：」会对上所有事），至少对上两处才算。想起的事前面叮嘱 TA：同类的事有好几次要分清是哪一次，没写到的往事和细节不要编。删聊天消息时，这些消息记下的事一起删。
- 单个字只拿最后一句（刚说的话）去对（v0.8.77）：正文几百字里零散的字会把「表白」「大头贴」这种不相干的事带出来。每次想起了什么会进日志。
- **特殊日子**（v0.8.84，作者定的）：`日子：类型｜日期｜什么日子｜和谁有关`，类型只能是生日、纪念日、祭日、节日、其他；老的三段格式当「其他」。纪念日（知道年份的）算满一个月、100 天、半年，满一年后每年一次；生日、节日、其他每年那天；祭日每年那天、知道年份就说第几年。恋人关系的「从什么时候起」是日期的，自动算交往纪念日（已经单独记了同一天的纪念日就不重复）。当天：「今天是特别的日子」可以主动提；7 天内：「快到的日子」先记在心里。碰上这些日子时，把标签是这个类型、或写到这个日子的往事（最近 3 件）一起带上。值得记的纪念日和节日写在提示词里（第一次见面、表白、交往、第一次约会、第一次接吻、求婚、结婚；情人节、白色情人节、七夕、圣诞、跨年……）。
- **自然想起**（v0.8.85，学自玄参「自然浮现式 AI 记忆网关」PDF 和 Scarlett 召回链路）：带给 TA 的分三块——想起的事（对上的，带经过、原话）；忽然想起的（和现在沾边但不够格的里面，约三次抽一件，按分数抽，合适才提）；其他经历过的事（目录，只有日期、地点、标题，最多 60 件，让 TA 自己联想、主动提起，记不清不许编）。记忆块位置不动（作者定的：正文是正在发生的，要放在最近）——v0.8.276 为了缓存改了：这会儿想起的挪到聊天记录后面，见下面「缓存」。原话是事件行的第 11 格。重新整理时，老记忆缺的原话 / 关键词 / 影响、老日子缺的类型 / 年份会补上。
- **了解（画像）**（v0.8.87，学自《AI 记忆体系设计手册》「画像全量 + 事实检索」；作者提醒：每个人知道的不一样）：`了解：谁｜是什么｜谁知道｜以前是怎样（变了才写）`，存在 facts。同一人差不多的一条只记一次，后来知道的人加进「谁知道」；变了时旧的进 hist（带当时谁知道），新的只有这次知道的人知道，其他人还以为是旧的（knownOf）。聊天时每次都带这次说话的 TA 们知道的版本，群里不是人人都知道的写「只有谁知道」。手机聊天里记的，谁知道一律是这个聊天里的 TA 们。
- **改名念念铃**（v0.8.88，作者画的草图）：TA 的页面是一根根细绳往下排，一只铃一件事。一个月一根绳（一根最多 4 只，事多就几根），新的在上面，从左往右、从上往下是从新到旧；月份写在那个月第一根绳上。铃的大小看重要度（1～5 星 40～84px 宽），样子和颜色按事件 id 定（8 种抠好的铃，CSS 转色相；中国结只在红粉紫里换）；图上自带的长绳剪掉，换成随机长短的一截。4 星以上铃下写标题。滑动时看得见的铃跟着晃（滑得越快晃得越大），点铃响一下弹出卡片（带原话）。右上角搜索：标题、经过、地点、标签、关键词、原话、日期里有这几个字的，点一件滑到那只铃、亮一会儿。花瓣、光斑、水面碎光照旧。
- **v0.8.276 五样一起做（作者同意的；参考了谁见 `credits.md`「念念铃参考的想法」）**：
  - **故事线**：事件行多一格 `…｜原话｜故事线`（第 12 格），是这件事属于哪条还在往下发展的事（一场病、一次冷战）。整理时把已有的线告诉 AI，跟着剧情记、手机聊天记的提示词里也带上已有的线名（`{{lines}}`），同一条线照旧名写。想起一件有线的事时，把这条线前后最多 8 件（日期 + 标题）一行带过，同一条线只带一次。时间线页多一组「故事线」，点开按先后列出；改一件事的页面能改线名；搜索也搜线名。
  - **刚才想起了什么**（透视）：念念铃首页一项，列出这次打开手机后最近 20 次带记忆时想起了哪几件、为什么（钉住的 / 日子到了 / 对上了哪些词 / 忽然想起），和上一次一样的标「上次也想起了」。只放在内存里，刷新就没了。
  - **不该想起**（错题本）：在上面那页点一件 →「不该想起」，当时让它想起来的那几个词记在这件事上（`e.no`），以后这几个词不再让 TA 想起这件（别的词还能）。那页底下「不该想起的」能改回来。
  - **等你看**：设置 → 自动记 →「记下的先等你看」（默认关）。打开后，跟着剧情记、手机聊天记下的一批批先放在 `wait` 里，首页出现「等你看 · 几批」，点「留下」才合并进来，点「不要」就当没记；那一楼换了 / 重新生成了，等着的那批也一起换掉。手动整理的不用等。
  - **高光 / 噪声**：改一件事的页面「想起」：一般 / 高光 / 噪声。高光：沾边（分够 .3）时多加 .3 分，更容易想起；噪声：不会被想起、不会忽然想起、特殊日子也不翻它，只在「经历过的事」里有个标题。时间线里高光带星标，噪声变淡、右边写「噪声」。
  - **缓存**：带给 TA 的记忆分两块——「TA 记得的事」（关系、了解、没完的事、日子、钉住的和日子翻出来的、经历过的事目录）不常变，接在 `{{world}}` 里；「TA 这会儿想起的」（聊到的人、想起的事、忽然想起的）每次不一样，是新变量 `{{memory}}`。私聊、群聊的默认提示词改成：人设 → 世界书和记得的事 → 正文 → 聊天记录 → 这会儿想起的 → 现在（时间）→ 要求，前面一样的部分 DeepSeek、OpenAI、Gemini 这类会自动走缓存。目录不再把这次想起的那几件拿掉（不然每次都变）。自己复制的方案里没写 `{{memory}}` 的，想起的照旧接在 `{{world}}` 后面。Claude 渠道开了「提示词缓存」时，提示词从第一处每次都变的地方（聊天记录 / 想起的 / 时间）切开，前面那段打缓存标记。聊天记录只带最近 24 条、每次往后挪，所以聊天记录那段还走不了缓存。

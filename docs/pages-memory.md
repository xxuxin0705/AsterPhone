## 一、管什么

让手机里的 TA 记得**过去真发生过的事**：最近几条之外的事，TA 现在一概不知道。
- 记忆**只给小手机用**：正文发生的事 → 变成手机里 TA 的记忆，单向，不写回酒馆。
- 线上模式不受影响；正文联动时也只影响聊天窗口。
- 一律**客观记录**（发生了什么、说了什么原话），不替 TA 下结论（记「TA 回了三条语音哄你」，不记「TA 很爱你」）。
- 答不上来就是「不知道」，不为了凑完整而补猜测。

## 二、记哪些东西

| 一格 | 里面是什么 | 例子 |
|---|---|---|
| **事件**（时间线） | 剧情时间（年月日 + 时段）、谁、在哪、经过、几句原话、标签、情感转折、身份变化、是不是特殊日子、和哪件事有关、重要度 1～5、来源（正文 / 手机 / 导入，第几层） | 2005/12/25 傍晚，原宿，一起拍大头贴…… 标签：约会 · 第一次；重要度 4 |
| **现在**（每个 TA 一张） | 现在是什么关系、什么身份、现在的状态、没完的事（约定、没聊完的话） | 关系：暧昧；没完的事：答应春假去冲绳 |
| **人物网** | 人（名字、别名、是谁）和人之间的关系（从什么时候起、现在怎样）；TA 和 user 的、角色之间的都记 | 夏油杰 —— 五条悟的挚友（2005/04 起） |
| **地点** | 名字、是什么地方、在这发生过哪些事 | 咒术高专·男生宿舍 |
| **特殊日子** | 生日、节日、纪念日，和谁有关 | 2/3 夏油杰生日（也是节分） |

每条事件都以**「现在的状态」**收尾，过去的事不会被当成正在发生。
- 时间：正文里有剧情时间标签（如 `<Ti>`）就直接读，不用猜；没有就让 AI 按前后文推，标「推测」，**作者能手动改成选好的年月日**。
- 记错了：旧的标成「撤回」，以后不再被找出来（不直接删，能找回）。
- 被想起越多越靠前；**不按时间变淡**（很久以前 ≠ 不重要）。

## 三、什么算「值得记」

判断：**一个月后 TA 要是完全不记得这件事，你会不会觉得奇怪 / 失落？** 会的才记。
- **记**：第一次（约会、牵手、吵架…）；关系 / 情感变了（表白、确认关系、冷战、和好、分手）；身份变了（转学、升职、搬家、受伤）；约定和计划；送了 / 收到什么；新知道的关于 user 的事（喜好、怕什么、过去、家人）；说出口的秘密；新出场的重要人物、新去的地方；生日、节日、纪念日。
- **不记**：没有新信息的日常（吃饭、走路、上课）；已经记过的又说一遍；风景、气氛、心理活动的描写；寒暄、接梗。
- 重要度：表白、分手这种 5，送了本书 3，新知道 user 不吃香菜 2。

## 四、记忆从哪来

1. **一次性整理旧内容**（花一次钱，作者能接受）
   - 来源（可以多选）：
     - **聊天世界书**：选一本，勾要整理的条目（例：Anima 的 chapter_1～3）。
     - **导入文件**：世界书 `.json`、酒馆聊天记录 `.jsonl`、`.txt`。
     - **读当前酒馆这个聊天的全部正文**。
   - **默认先用总结**：有 Anima 这种总结时先整理总结（作者那本 3.2 万字，一两次就整理完）；想要更细再读原文。
   - 读原文时：只留「上下文与世界书」里设好的标签（例：只要 `<content>`），没选中的重新生成（swipes）、变量、附加信息全扔掉；可以选「去掉 user 说的话」「只整理第几层到第几层」。
     - 实测：五条悟那个窗口 593 层、文件 44MB，只留正文约 91 万字（user 的话只占 4%），每批 20 层左右，约 15 批。
   - 分批跑：显示进度（第 3/15 批）、能取消、断了能接着跑；同一时间只跑一个；失败进日志。
   - 整理完只存记忆，不存原文。
   - 和已有的记忆重复的（同一天、同一件事）合并，不记两遍。
2. **跟着剧情自动记**（不另外调 AI）
   - 和「随剧情加歌」一样：正文生成时顺便写一个记忆暗号，手机读到就存。只记上面「值得记」的。
   - 两档：**有值得记的才记**（默认）/ 每轮都记。
3. **手机聊天自动记**（不另外调 AI）
   - 私聊、群聊回复时顺便带一个记忆暗号，规矩同上。
   - 照「可见范围」：私聊的事只进那个 TA 的记忆；动态设了不给 A 看，A 的记忆里就没有。
4. **手动**：长按一条消息 →「记住这条」，直接钉住。

## 五、聊天时怎么带进去

| 每次都带 | 对上才带 | 用向量找最相关的几条 |
|---|---|---|
| 最近的上下文（正文 + 手机聊天原话，现在就有） | 名字对上：人物网、地点 | 过去的事件（正文 + 手机的在一条时间线上） |
| 「现在」那张：关系、身份、状态、没完的事 | 日期对上：今天是生日 / 节日 / 纪念日（按剧情时间） | 底层世界书（剧情总结类） |
| 钉住的几条 | | |

- 向量找的总量有上限（约 1KB），不会把整个记忆库塞进去。
- 世界书里的**设定**（人设、世界规则）照现在的设置该常驻就常驻；只有剧情总结类的放进底层用向量找。
- 手机聊天：最近的原话每次带；更早的整理成事件放底层；改变关系 / 身份、定了约的写进「现在」。

## 六、存在哪、怎么找

- 全放在浏览器自带的数据库（IndexedDB）里，**不要后端，两边酒馆都能用**；能导出 / 导入 JSON 备份。
- 找相关的：
  - 默认**按字面找**（中文两个字一组比对），不花钱。
  - 插线板「其他」线接了向量就**按意思找**，两种结果合在一起排。
  - 向量连不上（Tauri 被拦、断线）就自动退回按字面找，功能不挂。**Tauri 能不能直连硅基流动要实测**：在 Tauri 里点那根线的「测试」。
  - 做的时候记得 CLAUDE.md「以后做到时要记得」里「其他」线断线怎么办那条。

## 七、App 长什么样

**名字：「念念树」**（取「念念不忘」）。中间改过「银河纪」（夜海里打捞），作者 2026-11-03 又改回念念树。

**样子（2026-11-03 改）：水彩花枝下挂满风铃和纸签**（作者给的参考：粉色水彩花树、玻璃风铃、长条纸签、下面一片闪光的水）。夜里花缝里露出银河、水里倒映银河。
- 图在 `phone/assets/memory/`：白天 / 夜里底图、12 个挂件（玻璃风铃、四色纸签、中国结）、花瓣 / 枫叶 / 雪花各 4 片。先做成单独的试验页给作者看。
- 会动的用代码：挂件跟着阵风晃（纸签还会轻轻翻）、玻璃隔一会儿闪一下、春落花瓣 / 秋落枫叶 / 冬落雪（夏天先只有光斑）、落到水上漂一会儿淡掉、水面碎光一闪一闪。
- **一张纸签 / 一个风铃 = 一段记忆**：点它晃一下，打开那一天（日期、地点、经过）。
- **放进来的 TA 自己勾**：联系人里勾了的才在这里显示；同一件事、同一段关系只记一次，写上牵涉到哪些人，每个人那里都看得到。
- 东西太多放不下：场景里只漂这个 TA 最重要、最近的十几盏，是门面；真正翻、改、删、改时间在「时间线」列表里。
- 其余页面：**现在**（关系、身份、状态、没完的事）、**人物网**、**地点**、**特殊日子**、**整理**、**透视**（这一轮想起了哪几条、为什么）。
- **设置**：整理用哪个接口（默认跟聊天那根线，可以换）；跟剧情自动记 开 / 关、两档；「聊天时带上记忆」开 / 关。
- 灯的出图提示词见 `gpt-image-brief-memory.md`。

     - 整理一批 3 万字；读正文时连隐藏起来的楼层（总结插件常把旧楼层藏起来）也读。作者那个窗口只留正文约 72 万字，26 批。

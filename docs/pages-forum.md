# 论坛 App 方案（2026-11-15 和作者定的，还没开工）

给写代码的模型：先读 `CLAUDE.md` 和 `docs/design-system.md`，再读这份。**按第十节的三步做，一步做完、验过、推送了再做下一步**；这份里写了「待定」的不要自己拿主意，问作者。

## 一、是什么

论坛是这个故事世界里的**公开网络**：路人、网友、营销号在议论、吃瓜、传闲话。和「动态」的分工：

| | 动态（聊天 App 里） | 论坛 |
|---|---|---|
| 谁在发 | 只有联系人 | 主要是路人、网友、bot；联系人也会出现 |
| 说什么 | 私事、熟人圈子 | 公开能看到的事、传闻、猜测（可以猜错、传歪） |

**所有人、所有事都属于这个世界**（作者定的）：不认识的路人也是这个世界的居民，聊的是这个世界的事；不出现和世界观无关的现实话题、现实名人、现实品牌。

## 二、作者定下的事（照做）

1. App 叫「论坛」，编号 `forum`。
2. 三个固定版块：**地区、全球、匿名区**；另有一个「关注」页只看关注的人。
3. 自带三套样子：**微博、豆瓣、推特**（只换长相和叫法，数据一套）。别人能照资源库的教程自己写一套（比如小红书）导出分享，我们能导入。
4. 你能发帖、回帖；能起网名；有**小号**。
5. 联系人会出现在论坛里。你能关注 TA；TA 认得你才回关，认不得可能私信问你是谁。
6. 固定有**营销号（bot）**：带 V，各有主题，接受投稿；能关注；能进它的主页看它发的所有内容。
7. bot 的名字要有意韵（见第六节），由 AI 按世界观起；你能增、删、改。
8. 外语：两种显示方式都要（上下对照 / 点了才出中文），你自己选。
9. 帖子可以配图，但不是每条都配。配图先显示画面描述，点一下才生图。
10. 论坛私信只能发文字。
11. 「地区」是哪儿：AI 按正文判断，你能手动改。
12. **全球版混着几种语言**：大约 30% 中文、40% 英文、30% 本地语言（见第八节）。
13. **联系人会在匿名区偷偷发帖**（什么时候匿名、什么时候实名见 5.5）。
14. **能真的转发**：转到自己的论坛主页，也能转到聊天里给某个人 / 群看（见 5.6）。
15. 两个开关：**聊天里的角色知不知道论坛上的事**、**正文知不知道论坛上的事**（见第十四节）。
16. 收藏、拉黑、删除、搜索都要。
17. **能手动指定谁发**：和动态的「生成角色动态」一样，选条数、点头像选「一定会发的人」（见 5.8）。

## 三、页面

底部三个标签：**首页 · 消息 · 我**（照 `apps/chat` 底部标签栏的做法，切标签不重画没变的那页）。

### 3.1 首页（`forum-home`）
- 顶上一排：关注 / 地区 / 全球 / 匿名区（切换只换下面的列表，四个列表各自留着，不重画）。
- 右上角：刷新（找 AI 出一批新帖，加在最上面）、发帖。
- 「全球」最上面有一条**热榜**（最多 10 条，横着滑）；点一个话题 = 按这个话题刷一批帖（一次调用）。
- 帖子卡片：头像、名字、V、时间、（标题）、正文、配图描述、翻译、数据（赞 / 评 / 转）。点头像或名字进主页，点正文进帖子。
- 匿名区的帖子没有头像和名字，只显示「匿名」+ 编号；不能点进主页。
- 空的时候：一句「还没有帖子」+「刷新」按钮。

### 3.2 帖子（`forum-post`）
- 上面是整帖，下面是楼层；楼中楼缩进一层（「回复 某某：」）。
- 底部固定输入栏（照 `holdSize` 的规矩，弹键盘不重排）：左边小头像 = 现在用哪个号，点它能换号；发送。
- 第一次点开、还没有楼层：自动找 AI 出楼层（这一下点击就是那一次调用；能取消；论坛设置里能关掉「点开自动出评论」，关了就显示一个「看评论」按钮）。看过的存着，不重复生成。
- 右上角「…」：再来一些评论、删除（自己的帖）。
- 点楼层 = 回复这一层；点赞是本地的（只改这一个数字和图标）。

### 3.3 主页（`forum-user`）
- 头像、名字、V、一句简介、关注数 / 粉丝数（AI 给的或随机的整数，只是摆设）。
- 按钮一行：关注 / 已关注 · 私信 ·（bot 才有）投稿。
- 下面是这个号发过的所有帖（从存着的帖子里筛）；最下面「看看 TA 还发了什么」= 让这个号再发几条（一次调用）。
- 自己的主页从「我」进，样子一样，按钮换成「编辑资料」。

### 3.4 消息（`forum-inbox`）
- 上面是通知（「某某回关了你」「某某回复了你」），下面是私信列表。有新的，底部标签上挂红点。
- 私信页（`forum-dm`）：只有文字气泡 + 输入栏。你发一句 = 找一次 AI，对方回 1–3 句。

### 3.5 我（`forum-me`）
- 现在用的号（头像、网名、简介、认证开关）。
- 我的号：大号 + 小号列表，点一下切换（只换勾）；新建、编辑、删除小号（大号不能删）。
- 关注列表（`forum-follows`）：bot、熟人、路人都在，点进主页。
- 设置（`forum-settings`）：
  - 地区：名字 + 语言（选项：中文、日语、英语、韩语…照聊天 `room.js` 的 `LANGS`）
  - 外语怎么显示：上下对照 / 点了才显示（分段按钮）
  - 一次刷几条：4 / 6 / 8 / 10（一排数字按钮，照动态的生成弹窗）
  - 点开帖子自动出评论（开关）
  - 营销号：列表，能加、改（名字、主题、头像）、删
  - 熟人：每个联系人一行，两个开关「上论坛」（默认开）「有认证」（默认关）
  - 接口：文字、生图各一项，默认「跟随全局」（照别的 App 在「设置 → 应用管理」里的做法，放那边也行，先 grep `diary` 看现有的放哪）

## 四、数据

### 4.1 跟着窗口走的（加进 `store.js` 的 `SCOPED`，默认值写进 `defaults()`）
```js
forum: {
  region: '', lang: '',          // 地区名、语言（'' = 还没定，第一次刷新时让 AI 定）
  accounts: [{ id: 'main', name: '', bio: '', avatar: '', real: false }],   // 我的号；main 是大号。name 空着就用 myNick()。real = 认证了（别人知道是你）
  cur: 'main',                   // 现在用哪个号
  bots: [],                      // { id, name, topic, bio, avatar, fans }
  users: [],                     // 关注过 / 私信过的路人：{ id, name, bio }（别的路人不存，只在帖子里留名字）
  people: {},                    // 联系人在论坛：{ [联系人 id]: { off, v, name } }；没写就是上论坛、没认证、网名用 c.nick || c.name
  follows: [],                   // 我关注的：'b:id' / 'c:id' / 'u:id'
  back: [],                      // 回关了我的：[{ who: 'c:id', acc: 我的号 id }]
  known: [],                     // 谁知道我哪个号是我：[{ cid, acc }]（认证的号不用记，谁都知道）
  hot: [],                       // 热榜：[{ topic, heat }]
  notices: [],                   // 通知：{ id, text, at, read }
  favs: [],                      // 收藏的帖子 id（收藏的不会被清掉）
  blocked: [],                   // 拉黑的：'b:id' / 'c:id' / 'u:id' / 'n:名字'
  toChat: false, toStory: false, // 聊天里的角色 / 正文知不知道论坛上的事（默认都关）
}
```

### 4.2 帖子和私信（大，放 kv，不放 state；键 `forum:` + `win.key`，照日记 `diary:窗口` 的存法）
```js
{ posts: [Post], dms: { [对方]: [{ id, me: true|false, acc, text, tr, at }] } }

Post = { id, board: 'local' | 'global' | 'anon',
  by: { k: 'bot' | 'c' | 'u' | 'n' | 'me', id, name, no, anon },   // n = 没存的路人（只有 name）；me 时 id = 我的号 id；匿名区显示 no（编号）。联系人匿名发的：k 'c' + id + anon: true，界面上永远只显示匿名
  re,                            // 转发的是哪条帖的 id（转发帖才有；原帖被删了就显示「原帖已删除」）
  title, text, tr,               // title 可以没有；tr = 中文翻译
  img, pic,                      // img = 画面描述；pic = 生好的图（没生就没有）
  sub,                           // 投稿帖：true
  likes, cmts, reposts, liked,   // 数字是 AI 给的摆设；liked = 我点了赞
  floors: null | [{ id, by, to, text, tr, likes, liked, at, st }],   // null = 还没出过楼层；to = 回复哪一楼的 id
  at, st }                       // time.stamp()
```
- 帖子最多留 300 条，超了删最旧的；我发的、回过的、赞过的、收藏的、被转发着的不删。
- 我发的帖、回的楼不丢（省不得的见 CLAUDE.md「不省」那条）。

### 4.3 整部手机共用的
`state.apps.forum = { conn: { text: 'follow', image: 'follow' }, skin: 'weibo', tr: 'both', count: 6, autoOpen: true }`
（`tr`: `both` 上下对照 / `tap` 点了才显示）

## 五、找 AI：三种调用（点一下只调一次）

提示词模板加在 `core/prompts.js`：`PROMPT_CATS` 里新开 `{ app: '论坛', items: [forumFeed, forumThread, forumDm] }`，内置模板只能看和复制；变量说明补进 `VAR_INFO`。组装用 `compose(cat, vars)`，调用用 `generate({ conn: resolveConn('text', 'forum'), system: '', app: '论坛', stop, prompt })`（照 `apps/chat/engine.js` 的 `genMoments`）。上下文用现成的：`storyText()`、`worldText()` / 聊天引擎里的 `worldBlock`、`time.forPrompt()`、`personaOf(c)`。

**三个调用都要：** 能取消（`waiting` / `busy`，signal 传给 `stop`）；一直有动静、带收到多少字（`aiCount`）；结束说结果；同一件事同时只跑一个，AbortController 放在模块里（照 `apps/music/comments.js` 的 `busy` / `live`），退出再进来按钮还是「取消」，结果填到现在开着的页面；AI 没按格式写就报「AI 没有按格式写」并记日志，不吞错。

### 5.1 `forumFeed`：刷一批帖
什么时候用：刷新某个版块 / 点热榜话题 / 主页「看看 TA 还发了什么」/ 刷新「关注」。

变量：
- `{{board}}`：这次刷哪儿（一句话）。地区：「〔地区名〕本地版：当地人用〔语言〕聊当地的事」；全球：「全球版：各地都在看的大事、热门」；匿名区：「匿名区：没人知道谁是谁，爆料、吐槽、怪事、不敢实名说的话」；关注：「只由下面『可以发的号』里的人发」。
- `{{platform}}`：平台语气，见第七节。
- `{{count}}`、`{{world}}`、`{{story}}`、`{{time}}`
- `{{posters}}`：可以发的号。bot（名字｜主题）、上论坛的联系人（真名｜网名｜有没有认证｜人设前 200 字）、关注的路人。匿名区不给这一段。
- `{{pick}}`：这次的额外要求（话题 / 只让某个号发 / 没有就空）。
- `{{lang}}`：语言不是中文时：「正文直接用〔语言〕写，另起一行附 [翻译:简体中文意思]」。
- `{{setup}}`：只在缺东西时才有内容：没定地区 →「先写一行 `地区：地名｜语言`（按正文判断故事发生在哪）」；bot 不到 6 个 →「再写 N 行 `号｜名字｜主题｜一句简介`」+ 第六节的起名要求；刷全球 →「再写最多 10 行 `热榜｜话题｜热度数字`」。

模板要点（写模板时用大白话，别照抄这里的句子顺序也行，但这些意思都要有）：
- 所有人、事都在这个世界里；路人也是这个世界的居民；不出现现实里的名人、品牌、平台名。
- 正文里的事，只写「外面的人看得到 / 听得到的部分」，可以猜、可以传歪；别人不可能知道的私事不能出现。
- 联系人很少亲自发帖，身份合适（公众人物、有认证）才发公开的话；普通人顶多发日常。
- bot 发的是投稿或它那个主题的内容，口吻像小编。
- 大部分帖只有文字，确实有画面才配图。
- 帖和帖之间语气、长短要不一样：有的一句话，有的一小段；有吵的、有玩梗的、有认真的。

输出格式（按行解析，照 `genMoments` 的写法；先去掉 `<think>` 块）：
```
地区：地名｜语言                    ← 只在要求时
号｜名字｜主题｜一句简介             ← 只在要求时，可以多行
热榜｜话题｜热度                    ← 只在要求时，可以多行
===
作者：名字
标题：一行标题                      ← 可以没有
正文（可以多行）
[图片：画面描述]                    ← 可以没有
[翻译：中文意思]                    ← 外语才有
数据：赞 123｜评 45｜转 6
===
（下一条）
```
- 「作者」对上 bot / 联系人（真名或网名）/ 关注的路人就挂到那个号上；对不上就是普通路人（`k: 'n'`）。匿名区一律写「作者：匿名」，手机里给编号。
- 解析要宽：全角半角冒号、竖线都认；「数据」缺了就随机给小数字；一条都解析不出才算失败。

### 5.2 `forumThread`：出楼层
什么时候用：第一次点开帖子 / 「再来一些评论」/ 我回了一楼之后 / 我发了帖之后 / 投稿之后。

变量：`{{post}}`（整帖 + 已有的楼层，每层前面带楼号）、`{{platform}}`、`{{world}}`、`{{story}}`、`{{time}}`、`{{people}}`（可能来回的联系人，同 5.1 的写法；匿名区不给）、`{{lang}}`、`{{count}}`（出几层，默认 6–10）、`{{focus}}`（我刚回的那一句和回的是谁：「被回复的人要回 TA；别人想回就回」；我用的号别人认不认得也写在这里：认证了 / 这些人知道是 TA / 没人知道，只看得到网名「x」）。

输出：
```
名字：这一层的话 [翻译：…]
名字 回复 3：回 3 楼的话            ← 楼中楼；「回复 楼主」也认
```
- 匿名区名字写「匿名」+ 新编号，或者沿用已有编号（「3 号」）；楼主写「楼主」。同一个帖子里同一个人编号不变。
- 楼层里也要有吵架、歪楼、玩梗、认真回的，别都在夸。

### 5.3 `forumDm`：私信
什么时候用：我在私信里发了一句 / 我关注了一个不认得我的联系人（这一下点击 = 一次调用，TA 决定理不理、要不要来问）。

变量：`{{char}}`（对方：联系人用真名 + 人设；bot 写「〔主题〕营销号的小编」；路人写网名 + 简介）、`{{who}}`（对方眼里我是谁：认得 →「这是 {{user}}」+ 用户人设；认不得 →「一个陌生账号，网名『x』，简介『…』，TA 最近发的帖：…。{{char}} 不知道这是谁」）、`{{history}}`、`{{event}}`（「TA 刚关注了你」/ 空）、`{{world}}`、`{{story}}`、`{{time}}`、`{{lang}}`。

输出：每行一句（1–3 句，只有文字）；另外可以有两种单独成行的记号：
- `[认出]`：对话里对方说了自己是谁，而且 {{char}} 信了 → 记进 `known`。
- `[回关]`：{{char}} 决定关注回去 → 记进 `back`，发一条通知。
- `[不回]`：这次不理（比如陌生号关注了 TA，TA 没在意）→ 什么都不显示，提示「TA 没有理你」。

规则写进模板：认不得的时候不能叫出 {{user}} 的名字，不能表现得认识；对方只说一句「我是某某」不一定信，要看说得像不像、有没有只有两个人知道的事。

### 5.4 不找 AI 的
- 关注 bot / 路人、点赞、切换号、认证开关：马上生效，只改那一个元素。
- 关注认得我的联系人（号认证了，或 `known` 里有）：马上回关 + 一条通知。
- 我发帖、回帖：先马上显示我的那条，再找 AI 出别人的回复（5.2）。
- 投稿：在 bot 主页点「投稿」→ 写内容 → bot 马上发一条「【投稿】…」的帖（`sub: true`，作者是 bot，不写我的名字）→ 接着走 5.2 出评论。

### 5.5 联系人：什么时候实名发、什么时候匿名发（写进 `forumFeed` 模板）
先说总原则：**大多数时候不发**。只有最近的正文或手机聊天里，TA 身上真的有事，才轮得到 TA 发；没事就让路人和 bot 发。还要看性格：不上网、嘴很严、活在没有网络的身份里的人，就是不发。

| | 实名发（地区 / 全球） | 匿名发（匿名区） |
|---|---|---|
| 发什么 | 让谁看见都无所谓的：日常、分享、营业、公开表态、转个热闹 | 想说但不能让人知道是自己说的：对 {{user}} 的心事、拿不准的感情（要不要说、怎么道歉、是不是自己想多了）、对身边人的抱怨、丢脸的事、和平时形象不一样的一面、藏着的秘密 |
| 什么时候 | 平常；公众人物多一点 | 刚吵过架、吃醋、心里有话憋着、做了后悔的事、有个决定下不了的时候 |
| 怎么写 | 符合 TA 给外人看的样子 | 会自己打码：不写真名，用「我有个朋友」「对方」「同事」；但习惯、口头禅、只有两个人知道的细节会漏出来，让 {{user}} 看了心里一动 |
| 界限 | 不说私密的事 | TA 不知道 {{user}} 会看到；不会把别人的秘密整个抖出来；真正要命的秘密（身份、犯过的事）不会发 |

- 一次刷新，匿名区里最多有一条是联系人发的，而且不是每次都有。
- 输出时写「作者：匿名（真名）」，括号里的真名手机收着（`by.id` + `anon: true`），**界面上任何地方都不显示**，也不提供「揭晓」。
- 你在这帖下面回复时，楼主用 TA 的口吻回（`forumThread` 的 `{{post}}` 里告诉 AI 楼主其实是谁、人设是什么），TA 同样不知道回帖的是你，除非你在匿名区之外用认得的号。
- 为了让 AI 知道「聊天里刚聊了什么」，刷匿名区时多给一个变量 `{{chats}}`：最近动过的 3 个私聊，每个最后 6 条（用 `getMsgs(chat.id)` + `apps/chat/msgtypes.js` 的 `forAI(m)` 拼成「名字：话」）。别的版块不给，省字。

### 5.6 转发（都不找 AI）
- 帖子的「转」按钮 → `actionSheet`：转到我的主页 / 转给朋友。
- **转到我的主页**：弹一个输入框写一句话（可以空）→ 新建一条我的帖 `{ by: 我, text, re: 原帖 id, board: 原帖的版块 }`，卡片里嵌着原帖的缩略（作者 + 前两行）。原帖的转发数 +1。匿名区的帖不能转到主页。
- **转给朋友**：列出聊天（私聊 + 群，照聊天里转发 / 选人的现成面板，先 grep `apps/chat` 里有没有选聊天的面板）→ 往那个聊天发一条卡片消息。在 `apps/chat/msgtypes.js` 加一种 `post`：`{ type: 'post', title, text, by, board }`；`previewOf` 写「[帖子] 标题或前几个字」；`forAI` 写「[转发了一条论坛帖子｜作者：x｜正文：…（最多 200 字）]」，这样 TA 回你时看得到内容；气泡照「名片」卡片的样子做（`.as-chat-card`），点了打开这条帖。发送用 `sendSpecial(chat, fields)`。`store.js` 的 `CHAT_MSG_TYPES` 和 `injectTable` 里也补上 `post`（默认 true）。
- 转给朋友之后 TA 回不回、怎么回，走聊天自己的流程（你点发送 / 等 TA 回），论坛不多调一次。

### 5.7 收藏、拉黑、删除、搜索
- **收藏**：帖子「…」里；`favs` 里存 id；「我」页多一行「收藏」进列表。只改图标，不重画。
- **拉黑**：主页「…」或帖子「…」→「拉黑 TA」（确认一下）。拉黑后：TA 的帖和楼层都不显示（存着不删）；给 AI 的「可以发的号」里去掉；提示词里加一句「这些名字不要出现：…」。设置里有「黑名单」，能移出。匿名的人不能拉黑。
- **删除**：我的帖、我的楼层能删（确认）；别人的帖「…」里有「不想看这条」，只在本地去掉。删了的帖如果被我转发着，转发卡片显示「原帖已删除」。
- **搜索**：首页右上角放大镜 → 搜索页（`forum-search`）。输入就在存着的帖里找（标题、正文、作者名，本地、马上出）；最下面一个按钮「全网搜『关键词』」= 按这个词刷一批帖（`forumFeed`，`{{pick}}` 写话题，一次调用）。搜过的词记最近 8 个，能点、能清空。

### 5.8 手动指定谁发（不多一种调用，还是 `forumFeed`）
- 首页右上角「刷新」旁边多一个按钮「指定」（图标 `sparkle`）。点「刷新」= 按默认直接刷；点「指定」= 弹出面板。四个版块都有（「关注」页里只列关注的号）。
- 面板照动态的 `openGenerate`（`apps/chat/moments.js`）抄，样式直接用它的 `.as-mo-gen*`：一排数字选条数、头像点着选「一定会发的人」、选了人才出现「只让选中的人发」开关、底下一行小结、「生成」。点选只换勾和小结，不重画。
- 能选的人：上论坛的联系人 + 营销号（地区 / 全球）；匿名区只列联系人（bot 不匿名发）。
- 选了人：`{{pick}}` 写「这些人每人至少发一条：…」或「只能由这些人发：…」（和 `genMoments` 的写法一样）。
- **在匿名区选了人**：TA 就是匿名发（`by.anon: true`），这时不受 5.5「最多一条、不是每次都有」的限制；但写什么还是照 5.5 的界限来。模板里加一句：「被点到的人如果最近真没什么憋着的事，就发一件无关紧要的小事（吐槽、小烦恼），不要硬编大秘密。」
- 在地区 / 全球选了联系人：TA 实名发，内容照 5.5 实名那一栏；性格上不会发帖的人被点到了，就发得很短、很敷衍，符合 TA 的样子。

## 六、营销号（bot）

- 第一次刷新时由 AI 按世界观起 6 个（和帖子同一次调用）。主题跟着世界走：现代都市可以有恋爱、打工、美食；古风、奇幻世界就换成那个世界里会有的。
- 都带 V。不回关。能关注、能私信（小编回）、能投稿。
- **起名要求**（写进提示词）：
  - 名字是**一句话**，不是一个词；像无意中听到的一句心里话，或者半句没说完的故事。
  - **有个说话的人**：多用「我」「你」「她 / 他」。
  - **不直接说主题**，绕着说；看了内容才明白为什么叫这个。
  - 两种味道都要有：一种轻轻的、有点酸有点怅然；一种好笑的：嘴硬、委屈、认怂、撒娇。
  - 6–14 个字，不带「bot」「君」「酱」「小助手」这种后缀；主题另外写在名字旁边的小字里。
  - 用这个世界的东西来写（地名、吃的、日常），不用现实里的品牌和名人。
- 给 AI 看的语气例子（只是语气，写明「不要照抄」；这些都是编的）：
  - 暗恋：「你回头我就假装看风景」
  - 前任：「你的伞还在我这里」
  - 想家：「妈妈说她没有在等我电话」
  - 失眠：「再不睡天就要亮给我看了」
  - 做梦：「醒来就不记得你的脸了」
  - 打工：「收到，但是不服」
  - 贪吃：「明天的我会原谅我的」
  - 没钱：「余额说它尽力了」
  - 怕生：「门铃响了我先不在家」
  - 树洞：「说完这句我就删」
  - 养猫：「它踩过的键盘都是圣旨」
  - 翻车照：「其实本人比这好看一点点」
- **不许用现实里真实存在的账号名**（作者给的参考只学味道）。

## 七、样子：积木 + 样子文件（2026-11-16 作者定的，替换掉原来「三套共用骨架、只换颜色」的做法）

作者要的：**功能只有一套，长相自由度特别高**。微博、豆瓣、推特是三套自带的样子，要和真 App 几乎一模一样；以后别人照教程能做出几乎一模一样的小红书、Ins，导出分享，大家导入就能用。

### 7.1 怎么做到
- 每一页由**积木**拼起来；每条帖子、每层楼把能用的**零件全备齐**（头像、V、名字、来自、小组名、+关注、标题、正文、话题、配图、热门回复、回应数、转评赞…），样子决定显示哪些、怎么排。
- **样子文件**（一个 .json）：
  ```
  { asterphone: 'forumLook', v: 1, name, swatch: [底色, 强调色],
    layout: { tabs: [{ page, feed?, text, icon }], home: [{ feed, text }], discover: [积木…], groups: [积木…], inbox: [栏…], icons: { repost, comment, like } },
    texts: { 'forum.xxx': '叫法' }, css: '…', imgs: { 名字: 图片 } }
  ```
  - `tabs`：底部 2～5 个标签，page 从 `home` 首页 / `feed` 单独一个信息流（再写 feed，比如 `{ page: 'feed', feed: 'anon' }` 就是单独一个「匿名区」标签）/ `discover` 发现 / `groups` 小组 / `inbox` 消息 / `me` 我 里挑；icon 写自带图标名，或者 `img:名字` 用自己的图。没写 home、me 的自动补上。
  - `home`：首页顶上切换的几个信息流，feed 从 `global` 全球 / `follow` 关注 / `local` 本地 / `anon` 匿名 / `all` 各小组混着 里挑。
  - `discover`、`groups`：这一页从上到下放哪些积木：`search` 搜索框、`hot` 热搜块、`boards` 小组 / 版块格子、`chips` 正在讨论（分类小标签 + 帖子列表）。
  - `discover` 第一块是 `search` 时，搜索框放到顶栏（微博、推特那样）。
  - `inbox`：消息页分几栏：`activity` 动态（关注的人新发的）/ `notice` 提醒（评论、赞两行，点进去是收到的评论、被赞）/ `dm` 私信；没有 `dm` 栏时私信列在提醒下面（微博那样）。
  - `icons`：转发、评论、赞用哪个自带图标（微博 share / comment / thumb，推特 repeat / comment / heart）。按钮上有 `data-n`（数字），CSS 可以写 `[data-n="0"]` 时显示「转发」字。
  - `imgs`：CSS 里用 `var(--fo-img-名字)`（已经是 url(...)）。
  - **不能写脚本**（和桌面组件一样，保护存着的密钥）。
- **自带的三套也是样子文件**（`apps/forum/looks/*.js` + 同名 .css），和用户的走同一条路，没有特殊代码。在资源库能「复制一份」改，改出来的就是自己的样子。
- 只有正在用的那套的 CSS 放进页面（`<style id="as-forum-look">`），所以 CSS 不用按样子名区分，直接写 `[data-as-app="forum"] .as-fo-post { … }`；夜间写 `.as-phone[data-mode="night"] [data-as-app="forum"] …`。
- 资源库 → 应用 → 论坛：样子卡片（自带三套 + 自己的），点一下换（只换勾）；导入；每套「…」：复制一份 / 编辑（名字、CSS、布局、叫法、图片）/ 导出 / 删除（自带的只能复制、导出）。

## 八、外语和翻译

- 地区的语言不是中文时，地区版的帖和楼层用那个语言写，AI 同时给中文（`[翻译：…]`，解析照聊天引擎的 `takeTr`，可以把它导出来用，别再写一个）。匿名区默认中文。
- **全球版混着写**（作者定的）：大约 30% 中文、40% 英文、30% 本地语言，一条帖一种语言，楼层跟着各自的人走（不用和楼主同一种）。`{{lang}}` 里写清楚比例和「不是中文的另起一行附 [翻译：…]」。几种特殊情况手机里先算好再写进 `{{lang}}`：本地语言就是中文 → 60% 中文、40% 英文；本地语言就是英文 → 30% 中文、70% 英文；**这个世界里没有的语言不用**（古风、架空世界没有英文，就让 AI 只用这个世界里有的语言，这句也写进模板）。
- `tr = 'both'`：原文下面紧跟一行中文（小一号、淡一点）。
- `tr = 'tap'`：只显示原文，下面一个小字按钮「查看翻译」；点了这一条换成中文，按钮变「查看原文」，再点换回来。只换这一条的字，不重画列表。
- 翻译是同一次调用里一起给的，点「查看翻译」不再找 AI。

## 十三、用什么写（都是项目里现成的，照着用，别新造）

**不加任何库、不加后端。** 原生 JS 模块 + 项目自己的小工具。下面每一行都是查过源码的真实写法。

### 13.1 App 入口
- `apps/forum/forum.js` 导出 `open(opts)`，返回页面元素（`core/main.js` 的 `openApp` 会调 `mod.open(opts)` 再 `nav.openApp(el, r, id)`）。在 `APP_LOADERS` 里加 `forum: () => import('../apps/forum/forum.js')`。
- 整个入口照 `apps/chat/index.js` 第 11–40 行抄：`TABS` 数组（`{ id, label, icon, text, render }`）、`page({ app: 'forum', id: 'forum-home', title: '论坛', large: true, back: true, cls: 'as-fo-root' })`、底部栏 `h('nav.as-chat-tabbar', …)`（直接用聊天的类名，样式就有了）、`switchTab(id, force)`、`P.el._onShow` / `P.el._onLeave`、`applyTexts()`。
- 子页面：`const p = page({ app: 'forum', id: 'forum-post', title, back: true }); …; nav.push(p.el)`。`page()` 返回 `{ el, body, nav, setTitle }`。返回上一页时要不要刷新：给 `p.el._onShow` 赋函数，里面先比一个「签名」（比如帖子数 + 最后一条 id），没变就什么都不做（照 `library.js` 的 `subPage`）。
- 右上角按钮：`navBtn(图标名, 说明, onclick)`；文字按钮：`navText(字, onclick, 主按钮吗)`。

### 13.2 数据读写

### 13.3 找 AI
```js
import { generate, generateImage, resolveConn } from '../../core/api.js';
import { compose, myName, myNick, myAvatar, myPersona } from '../../core/promptstore.js';
import { storyText } from '../../core/context.js';
import { nameOf, personaOf } from '../chat/engine.js';

const raw = await generate({ conn: resolveConn('text', 'forum'), system: '', app: '论坛', stop,
  prompt: compose('forumFeed', { board, platform, count, world, story, time: time.forPrompt(), posters, pick, lang, setup }) });
```
- `resolveConn('text', 'forum')` 会自己去读 `state.apps.forum.conn.text`，是 `follow` 就用全局那根线；所以默认值里一定要有 `conn: { text: 'follow', image: 'follow' }`。
- 世界书和记忆：`apps/chat/engine.js` 里的 `worldBlock(scan, people)` 现在没导出，**给它加上 `export`**（只加这个词），用法 `(await worldBlock(story, 这次出现的联系人数组)).world`。
- 翻译记号：同一个文件的 `takeTr(行)` 返回 `[正文, 中文]`，也**加上 `export`** 来用。帖子正文可能多行，所以先把单独成行的 `[翻译：…]` 那行拿出来再 `takeTr`。
- 去掉思考块：`String(raw).replace(/<think(?:ing)?>[\s\S]*?<\/think(?:ing)?>/gi, '')`（`genMoments` 里就是这句）。
- 语言名字：`import { LANGS, langName } from '../../core/translate.js'`；`state.forum.lang` 存的是 `LANGS` 里的代号（中文是 `'zh-CN'`）。AI 回的「地区：地名｜语言」里的语言是字，用 `LANGS.find(([v, l]) => l === 字)` 对回代号，对不上就当中文。
- 提示词：`core/prompts.js` 里三处：`PROMPT_CATS` 加 `{ app: '论坛', items: [{ id: 'forumFeed', name: '刷帖子', vars: […] }, { id: 'forumThread', name: '出评论', vars: […] }, { id: 'forumDm', name: '私信', vars: […] }] }`；模板对象里照 `moment:` 那条的格式加三条（`{ name, cats: ['forumFeed'], on: true, main: true, text: \`…\` }`）；`VAR_INFO` 里补新变量的说明（`board`、`platform`、`setup`、`focus`、`who`、`event`、`post`）。

## 十四、论坛上的事让谁知道（两个开关，默认都关，在论坛设置里）

先说谁**能**知道什么（两个开关都按这个筛，筛的函数只写一个，放 `apps/forum/engine.js`，叫 `knownTo(cid)`，返回几行字）：
- 我用**认证的号**或 **TA 认得的号**（`known`）发的帖、回的楼：TA 知道是我。
- 我用别的小号、在匿名区发的：TA 不知道是我（最多当成「网上看到一个帖子」，而且只有热帖才会看到）。
- TA 自己实名发的帖、和我的私信、我转给 TA 的帖：TA 当然知道。
- TA 匿名发的帖：TA 自己知道，但不会主动承认。
- 热榜前 3 条：谁都可能刷到。
- 只取最近的：最多 6 行，每行不超过 60 个字。

**开关一：聊天里的角色知道（`forum.toChat`）**
- 开了：TA 在聊天里回你时，提示词里多一段「【论坛上】…」（`knownTo(这个联系人)`）。
- 接法：`apps/chat/engine.js` 的 `buildReplyPrompt` 里，世界书那一段（`wb.world`）后面接上这几行；群聊那边（`requestGroupReply`）同样接，按群里每个人各取、合在一起去重。不新增提示词变量，这样用户自己抄的旧方案也能用上。
- 模板里不用教 TA 怎么用，只在那段开头写一句「这些是 TA 在论坛上看到的，想提就提，不用每次都提」。

**开关二：正文知道（`forum.toStory`）**
- 开了：把「【手机论坛上】…」写进给酒馆正文的那段手机内容里。接法看 `core/sync.js` 第 110–150 行：聊天的事就是在那儿按 `injectTable` 拼好、按 `injectPos` / `injectDepth` 塞给酒馆的；论坛的几行接在同一段后面，位置跟着聊天的设置走，不另做位置选项。
- 内容：我用认证的号发的帖和回的楼、热榜前 3、联系人实名发的帖。匿名的一律不给（正文知道了就等于角色知道了）。
- Tauri 那边：`sync.js` 现有的注入两边都能用，就不用另外处理；如果发现哪边读不到，按 CLAUDE.md 说清楚是哪边。

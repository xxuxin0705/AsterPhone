# 给画图模型的交接单：幕间（跑团 App）

用法和音乐那份一样：在 GPT 里开一个新对话，**先把「总说明」整段发过去**，再一张一张发下面的提示词。
画好的图存成提示词标题里的文件名，丢回给 Claude，Claude 负责抠图、转 webp、拼页面。

分两步，**第一步画完先停**，看风格对不对再往下画：
1. 定调子：桌面（白天 / 夜里）+ 骰子盘 + 档案袋。
2. 其余：桌上别的道具、意象小物件、角色卡底纸、火漆印章、KP 剪影、场景照片、图标。

---

## 总说明（先发这一段）

```
你要帮我画一个手机 App 的素材。App 叫「幕间」，是一个和朋友一起玩桌面推理游戏（克苏鲁跑团、剧本杀）的 App，整体是「复古侦探事务所」的味道。这些图会被放进网页里，所以要画得干净、统一。

画风（所有图都一样）：
- 像 1930 年代的侦探事务所：书桌、台灯、档案、打字机、墨水、放大镜、怀表。
- 质感：手绘插画加一点颗粒感，像旧书插图或者老电影海报，不要过于真实的 3D 渲染。整体低饱和、偏旧，像老照片。不要黑红配色、不要霓虹、不要赛博朋克、不要可爱卡通。
- 光：从桌面左上方来的光，影子柔和。
- 全部不要任何文字、字母、数字、logo、水印（字由代码写）。
- 不要任何真实的人、知名角色、知名品牌。

道具的视角：全部是**正上方垂直往下看**（正俯视），这样代码里可以随意旋转摆放。

颜色我下一条单独发。先不用画，回复「明白」。
```

然后二选一，再发一段颜色（两种都想试就开两个对话，各发一种）：

**画风 A：雨夜伦敦**
```
颜色：
- 主色是雾蓝：灰蓝色的桌布 / 墙面，像下雨天的伦敦。
- 纸是奶白、米白色，不是黄的。
- 金属全部是黄铜：放大镜、台灯、图钉、回形针都是暖黄铜色，是画面里唯一的暖色。
- 木头是深灰褐色，不要红棕。
- 火漆是暗红色，只在火漆上用红。
- 夜里模式整体往深蓝走，台灯是暖黄光。
整体是冷调、干净、克制，暖色只有黄铜和灯光。
```

**画风 B：老侦探小说封面**
```
颜色：
- 主色是暗酒红：酒红色的丝绒桌布 / 桌面，像旧侦探小说的布面封皮。
- 纸是米黄、奶油色，略微泛旧。
- 字和线条是墨黑色（打字机的黑）。
- 金属是旧黄铜，偏暗。
- 木头是深棕近黑。
- 火漆是比桌布更深的暗红。
整体像复古海报：酒红、米黄、墨黑三色为主，颜色压得很沉，有一点点褪色感。不要鲜红、不要粉。
```

```

中央和四周要留出大片空地，之后会往上放别的道具和椅子。
白天：一道从左上方窗户进来的米黄色暖光，桌布上有淡淡的窗格影子，绒布有光打上去的那种绒毛质感。
```

### `assets/interlude/desk-night.png` —— 桌面（夜里）
A / B 同一句：
```
和上一张完全一样的桌子、一样的东西、一样的摆放位置，只改成夜里：
台灯亮了，桌面中心被台灯照成暖黄色，四周渐渐暗下去（A：暗成深蓝；B：暗成深酒红近黑），但暗处仍看得清桌布的纹理，不要全黑。
```

```
A：深灰褐色皮革，盘底是奶白色的绒布。
```

### `assets/interlude/files.png` —— 档案袋
```

一摞叠得略微错开的档案袋，最上面一个用细绳绕着纸扣系着，角上夹一个黄铜回形针。袋子上不要任何字。
```

## 第二步：其余素材

```
透明背景的 PNG（做不到就纯黑背景，四周留足空白）。每张只画一个物件，居中，正俯视，光从左上方来，只保留物件本身的高光和很淡的接触阴影。1024×1024。和前面骰子盘一样的画风。
```

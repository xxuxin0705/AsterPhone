## 一、全局机制（所有页面都遵守）

### 1. 越具体越优先
本聊天 / 本群的设置 ＞ 应用设置（设置 → 应用管理 → 聊天）＞ 全局默认。
适用于：头像、名字、时间模式、外观、API、温度、翻译、输出设定。

### 2. 回复怎么触发
- 发消息不会自动回复。你可以连发好几句。
- 输入框有字 → 按钮是「发送」；输入框空、且有还没被回复的话 → 按钮变形成「让 TA 回复」（胶囊形变动效）。
- 群聊、动态评论同理：点「让大家回复」/「生成评论」才生成。

### 3. TA 的消息从哪来（两种联动模式都有这三条）
1. 你发 → 你点「让 TA 回复」→ TA 回。
2. 正文里写到 TA 给你发了消息 → 通过暗号进入手机（消息旁带小标记「来自剧情」）。
3. TA 主动来找你（见第 6 条）。

### 4. 联动模式（每个聊天 / 每个群单独选）
| 模式 | 正文 → 手机 | 手机 → 正文 |
|---|---|---|
| 跟随正文 | 通 | 默认注入 |
| 仅线上聊天 | 通 | 默认不注入 |

新聊天的默认模式在「设置 → 应用管理 → 聊天」里改。

### 5. 注入正文
- **哪些消息会写进正文**：按「注入默认表」（第八节），可在「设置 → 应用管理 → 聊天」里改。
- **写进去的样子**：整理成旁白，例如「【手机】阿铭给你发来：……」；引用回复会带上被引用的那句。
- **注入位置**：默认插进 Chat History，离最新消息 2~4 层；可改成人设卡 / 世界书附近。在「设置 → 应用管理 → 聊天 → 注入设置」里改。
- **注入条数**：最近多少条（每个聊天可单独设）。
- **手动注入**：长按消息 → 多选 → 「注入正文」。即使是仅线上的聊天也可以。手动注入的消息会被「钉住」，直到你取消。
- **注入记录**：聊天设置里查看本聊天注入了哪些（自动 / 手动钉住分开列），可取消，可「预览」正文 AI 实际看到的文字。
- 撤回：「撤回」提示不写进正文；撤回前正文已经读到的收不回。

### 6. 主动消息
- 私聊、群聊都有，每个聊天单独开关（默认关）。
- **正文触发**（两种模式都有）：正文里刚发生了和 TA（群：这个群或群里的人）有关的事，有时来说几句；不算进每日上限。
- **定时**（只有仅线上聊天）：每隔几小时、早安晚安、很久没回。跟随正文不定时来——手机里的事会写进正文，你没顾上看时自己发一堆会把正文带跑。
- 酒馆页面关着时手机不运行 → 你回来时一次性**补发**「你不在的这段时间」的消息。
- 每个角色单独：开关、频率、每日上限；遵守免打扰时段。
- 所有自动行为（主动消息、补发、自动动态、聊天触发动态）共用一个**每日自动请求上限**（设置 → 应用管理）。

### 7. 暗号
正文和手机之间靠隐藏标签传话：剧情时间、正文里 TA 发的手机消息、（以后）天气地点等。
Aster 自动注入「请按格式输出」的指令，并自动把标签从正文里藏起来；每一条暗号都能在「设置 → 通用提示词」里关掉或改写。
**具体格式待定**，会单独写成公开规范，方便别人的角色卡适配。

### 8. 剧情时间
从正文暗号里读；读不到时用手动设定，并跟着现实时间往前走。时间分隔线、状态栏、续火花天数都按「时间来源」设置显示。

### 9. 翻译（必须免费）
- 走酒馆自带的免费机器翻译接口，不花 API。（TauriTavern 上能否使用待实测）
- 私聊：自动翻译 TA 的消息（开关）；发送前把我的话译成目标语言发给 TA，原文以翻译气泡显示。
- 群聊：两种模式 —— 全群统一一种语言 / 每人跟随自己私聊的语言（没私聊过的人按群默认语言）。
- 动态：发动态和评论可跟随各自私聊的语言；不跟随则默认中文。

### 10. 记忆
- **必读层**（每次都带）：角色人设、最近聊天原文、钉住的记忆、当前剧情时间和 TA 的状态。
- **检索层**（相关时才带）：选中的世界书条目，包括「跟随当前酒馆聊天绑定的聊天世界书」（例如 Anima 生成的那本）。手机读它时默认**按相关性挑几条**，可切换成「全部常驻」。
- 【第二期】Aster 记忆本 / 记忆宫殿 App：自动总结、关键词或向量检索、同步成单独的 Aster 世界书、JSON 导入导出、记忆预算。已注入正文的消息不进 Aster 记忆本（交给正文的记忆插件去记）。设置里有「Aster 记忆 开/关」。

### 11. 可见范围管住 AI
动态设了「不给 A 看」→ A 完全不知道：不会评论，私聊里也不会提。

### 12. 头像手势（全手机统一）
- 单击任何人的头像 → 资料页（资料页里有进 TA 动态空间的入口）。
- 聊天里双击头像 → 拍一拍。
- 群聊里长按头像 → @TA。
- 点自己的头像 → 我的主页。

## 二、消息页 `chat-messages`

- 顶栏：标题「消息」，右上「+」（发起单聊、发起群聊、添加好友）、搜索。
- 筛选：全部 / 单聊 / 群聊。
- 列表按最近聊天排序；置顶的排最上面。
- 每条会话：头像、名字（备注优先）、最后一条消息、时间、未读红点 / 数字、免打扰图标、续火花图标。
- 左滑：置顶、标为未读、删除。
- 长按：同上 + 免打扰。
- 空状态：「还没有聊天」+「去添加联系人」「AI 智能加载」两个按钮。

## 三、私聊

### 3.1 聊天界面 `chat-room`
- **顶栏**：返回（带未读数，如「‹ 3」）、对方名字（备注优先）、名字下一行小字状态（「对方正在输入…」/「一起听：歌名」）、右上「···」进聊天设置。
- **消息区**：
  - 头像（可隐藏）、气泡、时间分隔线（剧情 / 现实时间）、已读标记（可关）。
  - 消息上可以挂 emoji 反应（双方都能贴）。
  - 失败的消息：气泡旁红色感叹号，点一下 → 重试 / 查看日志。
  - 来自剧情的消息：小标记「来自剧情」。
  - 思维链（可关）：TA 消息上方一条折叠的「TA 心里在想…」。
- **输入栏**：语音 / 文字切换、输入框、表情包按钮、「+」按钮、发送 / 让 TA 回复 按钮（变形）。
- **一起听进行中**：顶部挂一条小横条，显示当前歌曲。【音乐 App 第二期，先留接口】

### 3.2 「+」面板 `chat-room`（面板展开状态）
相册 / 拍照、语音通话、转账、红包、位置、一起听、名片（发联系人给对方）、收藏（发我收藏的内容）。

### 3.3 表情包面板 `chat-room`（面板展开状态）
分组标签、搜索、最近使用、「+」导入。

### 3.4 消息类型（我和 TA 都能发，除特别注明）
| 类型 | 说明 |
|---|---|
| 文字 | TA 的回复可拆成多条气泡，一条一条出现 |
| 语音条 | 我：真录音，或打字假装语音；TA：TTS 朗读，或点开看文字。每次回复几条语音见输出设定 |
| 图片 | 我：相册上传；TA：开生图就真生成，不开就是「图片描述卡」，点「生图」才画 |
| 表情包 | |
| 转账 / 红包 | 可收下 / 退还；和钱包余额联动 |
| 位置 | |
| 名片 | TA 聊到某人时发名片，点一下加好友 |
| 聊天记录转发卡 | 点开看被转发的几句对话 |
| 一起听邀请卡 | 歌名、歌手、「加入」 |
| 通话记录 | 「通话时长 05:21」 |
| 系统提示 | 拍一拍、撤回、加好友成功等 |

### 3.5 拍一拍
- 双击对方头像触发。显示「你拍了拍 阿铭 的小脑袋」。
- 后缀：我给自己设一个；每个角色也有自己的后缀（可手填，✚ 也可让 AI 按人设起）。
- 群聊里可以关掉拍一拍。

### 3.6 长按消息菜单 `chat-room`（菜单状态）
- 我的消息：复制、引用、撤回、编辑、删除、收藏、翻译、多选、贴表情。
- TA 的消息：复制、引用、重新生成、编辑、删除、收藏、翻译、多选、贴表情。
- 菜单上方一排常用 emoji，点一下就是贴表情反应。

### 3.7 多选 `chat-room`（多选状态）
每条消息左边出现勾选圈；底部：删除 / 转发（合并成聊天记录转发卡）/ 注入正文。

### 3.8 聊天设置 `chat-room-settings`
- **对方资料**：头像、真实姓名、昵称（网名）、备注、性别、地区、个性签名、拍一拍后缀 → 点进去是联系人资料页（资料的家在那里）。
- **本聊天的头像**：我在这个聊天里的头像、TA 在这个聊天里的头像（情侣头像用）。
- **基础**：置顶、免打扰、已读显示、续火花（开关；按现实 / 剧情天数，默认跟随时间来源）。
- **剧情关联**：联动模式（跟随正文 / 仅线上）、注入条数、注入记录 →、启用哪些世界书、读取哪些正文剧情、聊天世界书读取方式（按相关性 / 全部常驻）、时间模式（默认跟随全局）。
- **AI**：专属 API 模型、专属温度、单独提示词、是否显示思维链。
- **输出设定**：每次回复最少 / 最多几句；最少 / 最多几条语音。
- **互动**：允许 TA 主动发消息（频率、每日上限）、私聊触发群聊（TA 把私聊里的事带到你们共同的群里抱怨、转发聊天记录）、允许 TA 主动发起一起听 / 建议换歌、拍一拍开关。
- **翻译**：自动翻译 TA 的消息、发送前翻译我的话、目标语言。
- **外观**：聊天主题、聊天背景、气泡样式、字号、头像大小、头像形状（圆 / 方）、是否显示头像、头像框。
- **记录**：查找聊天记录、导出、导入、清空。
- 【第二期】查看 TA 的记忆 →（跳到记忆宫殿）。

### 3.9 注入记录 `chat-room-inject`
- 两组：自动注入 / 手动钉住。每条可取消。
- 「预览」：显示正文 AI 实际读到的那段文字，以及总长度。

## 四、群聊

### 4.1 群聊界面 `chat-group`
与私聊相同，区别：
- 顶栏显示「群名(人数)」。
- 每条消息上方显示发送者名字 + 群头衔。
- 「让大家回复」：一次请求生成全群回复。AI 先给每个成员排「去向」：群里说几条 / 转去私聊你 / 不回（剧情里在忙）。
- 被 @ 的人优先回；剧情里实在没法看手机的，之后补回。
- ✚ 正在忙的成员在成员列表里显示「忙碌中」。

### 4.2 群设置 `chat-group-settings`
- **群资料**：群头像、群名、群号、群介绍（只给 AI 看，不显示成公告）。
- **群公告** →：查看、置顶、编辑、删除。
- **成员**：成员头像网格、邀请成员、移出成员；群主、管理员；每人的群头衔；管理员能否改头衔（开关）；每个成员在本群的头像框。
- **我在本群**：我的群名字、我在本群的头像、我的头衔。
- **剧情关联**：联动模式、注入设置、启用哪些世界书和上下文（默认跟随全局）、时间模式。
- **AI**：专属 API、专属温度、是否显示思维链。
- **输出设定**：每轮最多几个人说话；每个成员单独设一次几条消息、几条语音；✚ 每个成员的活跃度（话多 / 话少）。
- **互动**：已读显示、拍一拍开关、群聊触发私聊（TA 看完群里的内容单独来找你）、群里有人转去私聊时的生成方式（默认群请求顺便写好 / 单独生成）、群电话。
- **翻译**：全群统一 / 跟随各自私聊。
- **外观**：主题、背景、我的气泡、对方气泡、是否套用私聊里各角色的气泡样式、字体、头像形状、是否显示头像框。
- **记录**：查找、导出、导入、清空。
- 底部红色「退出群聊」。

## 五、联系人

### 5.1 联系人列表 `chat-contacts`
- 顶部固定入口：新的朋友、群聊、分组。
- ✚ 星标朋友固定在最上面。
- 其余按名字 A–Z 排，右侧字母索引条。
- 搜索（人名、备注）。
- 右上「+」：添加好友、AI 智能加载、从世界书添加。

### 5.2 新的朋友 `chat-contacts-new`
好友申请（来自名片等），「接受 / 忽略」。

### 5.3 群聊列表 / 分组 `chat-contacts-groups`
- 群聊列表：所有群。
- 分组：新建、改名、删除、管理成员。分组会用在动态的可见范围里。

### 5.4 资料页 `chat-profile`
- 头像、网名、备注、真实姓名、性别、地区、个性签名。
- 所在分组、人设来源（角色卡 / 世界书条目 / 手写）。
- TA 最近几条动态的缩略图 → 进 TA 的动态空间。
- 按钮：发消息、打电话。
- 右上「···」：改备注和分组、设为星标、删除联系人。

### 5.5 手动添加好友 `chat-contacts-add`
昵称（必填）、真实姓名、备注、性别、拍一拍后缀、人设来源。头像默认按性别分配。

### 5.6 AI 智能加载 `chat-contacts-ai`
- 方式：全部交给 AI（读角色卡和剧情）/ 我来点名（人数 + 必须包含谁）。
- 默认私聊和群聊一起生成。
- 生成前询问：清空重来 / 保留现有只补缺的（已有的跳过）。
- 每个人生成：真实姓名、网名、备注、性别、拍一拍后缀（头像用默认）。
- 每个群生成：群名、群号、群主、管理员、群公告、群介绍。
- 生成完进**预览勾选页** `chat-contacts-preview`：每人每群一张卡，可勾选 / 取消，卡上内容可以直接改。确认后才加入。
- 完成提示：「新增 6 个联系人、2 个群聊」。

### 5.7 从世界书添加 `chat-contacts-lore`
- 选世界书 → 选条目。
- 一个条目里有好几个人 → 交给 AI 拆成几张联系人卡（一次请求）→ 同一个预览勾选页。
- 人设来源记为「连到原条目」：聊天时读那个条目，并告诉 AI「你只扮演其中的 X」。世界书改了，手机自动跟着变。

## 六、动态

### 6.1 动态页 `chat-moments`
- 顶部封面大图 + 我的名字和头像。
- 右上相机图标：短按发动态；长按 / 菜单：生成角色动态、清空所有动态。
- 顶部消息提醒：「2 条新消息」（谁赞了、谁评论了你）。
- 动态流：头像、名字、文字、配图（九宫格）/ 图片描述卡、位置、时间、可见范围小图标（我自己的动态）。
- 每条右下「··」操作条：点赞、评论、分享、生成评论、编辑、删除（编辑 / 删除仅限自己的）。
- 点赞区 + 评论区：评论支持「A 回复 B」。

### 6.2 发动态 `chat-moments-post`
- 文字、配图（相册上传，可不配）、所在位置、提醒谁看。
- 谁可以看：公开 / 私密 / 部分可见（选人）/ 分组可见 / 不给谁看。

### 6.3 生成角色动态 `chat-moments-generate`（底部抽屉）
- 随机角色 / 指定角色（带搜索和分组筛选）。
- 数量滑块。
- 开关：可以用我发的照片（拿你发给 TA 的照片或你动态里的照片当配图）、可以转载聊天记录（截一段对话发出来吐槽或炫耀）。
- 「开始生成」。

### 6.4 自动动态
- 跟随正文的角色：偶尔自己发。
- 聊天触发：聊着聊着去发一条相关动态（默认开）。
- 都受每日自动请求上限约束。

### 6.5 评论
- 回复某人评论后不自动续写；点「生成评论」才继续，大家会看到你刚才说了什么。
- 一次请求决定谁评论、谁只点赞、谁不理。

### 6.6 角色动态的可见范围
- 角色也会设可见范围：屏蔽你、仅你可见等。
- 屏蔽你的动态：照常生成并保存，打上「对你不可见」标记。你在动态里看不到，但别的角色看得到、会议论（蛛丝马迹）。
- 【以后】「查手机」App：TA 屏蔽你发的动态出现在那里，图标亮红点。
- 和好解除屏蔽后，之前的动态重新出现，提示「你错过了 TA 的 3 条动态」。

### 6.7 动态配图
生图开关（在「设置 → 应用管理 → 聊天」）默认关：显示图片描述卡，点「生图」才真画。

### 6.8 TA 的动态空间 `chat-moments-user`
封面 + TA 的头像名字签名 + TA 的全部动态（只显示你看得到的）。

## 七、我

### 7.1 我的主页 `chat-me`
- 顶栏：网名 + 下拉（切换身份 / 面具）、右上「编辑」。
- 头像 + 4 个数字格（每格可选：动态 / 粉丝 / 关注 / 好友 / 角色 / 消息 / 通话 / 余额 / 自定义 / 隐藏）。
- 名字、@网名、个性签名、兴趣标签。
- 生日、所在地小卡片。
- 关于（人设，默认折叠，「展开更多」）。
- 入口：钱包、收藏、表情包管理、应用背景 → / 聊天背景 →（跳到设置里它们的家）。
- 我的动态：九宫格 / 列表切换。

### 7.2 编辑资料 `chat-me-edit`
- 真名、网名（只改显示，AI 记忆仍按真名认你）。
- 个性签名、生日、性别、兴趣标签。
- 虚拟地点 + 现实映射城市 + 「测试天气」（用免费天气接口拿真实天气）。
- 人设：默认从酒馆人设加载；**没改过就跟随酒馆，改过就独立**（旁边标「已独立」+「重新跟随酒馆」）。只在手机里用，不写回酒馆、不注入正文。
- 绑定世界书。
- 生图外观（文字描述）+ 定妆照（锁脸参考图）。
- 我的声音：TTS 供应商 + 音色（我发语音条时用）。
- 用户连结：无连结 / 同一世界 / 小号。
- 【第二期】立绘（多套服装、表情）。
- 底部：删除此身份（红）/ 保存。

### 7.3 钱包 `chat-wallet`
余额、收支明细（转账、红包记录）。

### 7.4 收藏 `chat-favorites`
聊天里长按收藏的消息，按时间 / 类型筛选。

### 7.5 表情包管理 `chat-stickers`
分组、导入、删除、排序。（表情包识别、搜索必须免费，不调 API）
